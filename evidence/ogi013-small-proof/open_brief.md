FruitStack is a stack of cooperating components: PlumMe (model supply/routing, run budgets, circuit/health state), CherryMe (Brother Mode: blind independent drafts, cross-critique, named replies, closing; a closed-loop controller with weights from verified contributions and an expected-value choice of whether to spend another round), PeachMe (episode/session), MangoMe (work ledger), OrangeMe (memory), PomeloMe (authority/idempotency), AppleMe (assurance), CogC (context compression), and a typed "Code Mode" facade for deterministic chains. The goal "OGI" means organized general intelligence: several models of different lineages (here Luna = gpt-6-luna via Codex, and nemotron-3-ultra via a free gateway) that cooperate so the result is better than any single member.
Evidence so far: (1) A preregistered QA-2D study of the Luna+nemotron duo against single-model controls was closed as infrastructure-infeasible: nemotron supply failed too often (429/502 cooldown refusals, answers leaked reasoning at the length cap), so no claim about cooperation superiority is established. (2) An architecture audit found QA-2D tested a simplified baseline, not the full architecture. (3) Offline, the closed loop is implemented and unit-tested but never run on a real study. (4) Existing exploratory rows: where Luna and nemotron disagreed on multiple-choice items, nemotron was usually right and the duo's final answer matched it; this does not separate cooperation from "pick the better model". (5) Earlier OGI-011/012 studies were blocked by supply problems.
Constraints: zero cash and no paid routes; no Claude as a team member; free/local models only; model-generated code only inside a sandbox; no claims of organizational added value without verified evidence; the owner's weekly quota must not be burned (small tests, hard caps).

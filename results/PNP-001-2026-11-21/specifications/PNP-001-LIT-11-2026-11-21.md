## 1. Chen, Williams - Stronger Connections Between Circuit Analysis and Circuit Lower Bounds, via PCPs of Proximity (CCC 2019)

Source: LIPIcs CCC 2019 paper 19, DOI 10.4230/LIPIcs.CCC.2019.19 (in paper.txt). No arXiv/ECCC copy used.
Local: `SRC/lipics-CCC.2019.19/paper.txt`.
Definitions (L174-175): "We say an algorithm running on n-input circuits is non-trivial if for all c, it runs in
2n /nω(1) time for all circuits of size nc ." [note: 2^n/n^{omega(1)}, size n^c]. CAPP = estimate acceptance
probability within the stated additive error.

Theorem 8 (L305-307): "There is an absolute constant δ > 0, such that if δ-error CAPP for poly(n)-
size THR ◦ THR circuits can be solved in 2n /nω(1) time, then NEXP 6⊂ THR ◦ THR. The same
is true with SAT in place of CAPP." [note: 6⊂ = not subset]

Corollary 10 (L320-323): "There is an absolute constant δ > 0, such that if one of the following holds:
1. CAPP (or SAT) for poly(n)-size THR ◦ MAJ circuits with error δ is in 2n /nω(1) time, or
2. CAPP for poly(n)-size MAJ ◦ MAJ circuits with 1/poly(n) error is in 2n /nω(1) time,
then NEXP 6⊂ THR ◦ THR."

Theorem 1, CAPP part (L184-187): "For any constant δ > 0, If there is a non-trivial CAPP algorithm with error δ
for THR ◦ MAJ circuits of poly(n) size, then there is a non-trivial CAPP algorithm with error δ + 1/n for
poly(n)-size THR ◦ THR circuits."

Theorem 6 (L261-267, NP lower bounds): "There is an absolute constant α > 0, such that for any typical circuit
class C, if there is a constant δ such that one of the following holds: Gap-UNSAT for 2δn -size AND3 ◦ C
circuits with gap α can be solved in 2n−δn time, or CAPP for 2δn -size OR2 ◦ C, ⊕2 ◦ C, or AND2 ◦ C circuits
with error α can be solved in 2n−δn time, then for every k there is a function in NP that doesn't have nk -size
C circuits."

Lemma 25 (L846-855): "(2-query PCPP with constant completeness/soundness gap). For any constant δ > 0 there two
constants 0 < s < c < 1, such that there is a PCP of proximity system for Circuit-Eval with proximity δ,
soundness s, completeness c, number of random bits r = O(log n) and query complexity q = 2. Moreover, [...]
(1) Given the random coins, the verifier computes an OR on the 2 queried bits or their negations, and accepts iff
the OR is true. (2) [...] a proof π can be constructed in poly(|C| + |w|) time that makes V (C) accept with
probability at least c."

## 2. Hatami, Hoza, Tal, Tell - Fooling Constant-Depth Threshold Circuits (FOCS 2021)

Source: ECCC TR21-002 (Revision 1). Local: `SRC/eccc-TR21-002/paper.txt`.
Definition: LTF circuit = circuit of linear threshold gates; "wires" counts edges.

Theorem 1.1 (L186-188): "(PRG for super-linear LTF circuits). For any d ∈ N and δ ≤ 200−d , there exists a
polynomial-time computable e-PRG for the class of LTF circuits of depth d with at most n1+δ wires,
whose seed length is O(n1−δ ) and whose error is e = 2−n ." [note: δ ≤ 200^{-d}; wires n^{1+δ}; seed O(n^{1-δ});
error 2^{-n^δ} - the δ exponent appears alone on L189; abstract L19 says "δ = 2−O(d)"]. L193-194: holds also for
super-constant d (Theorem 6.25).

Theorem 1.2 (L232-234): "(low-error PRG for ANYs ◦ LTF). There exists an e-PRG for ANYs ◦ LTFn that is
computable in time poly(n) with seed length O e n · (s + log(1/e))." [note: Õ(sqrt(n·(s+log(1/e))))]
L237-239: "a PRG with seed length o (n) and error e = 2−n/polylog(n) for the class of LTF circuits with unbounded
depth and at most polylog (n) n gates (see Corollary 6.22)." [note: n/polylog(n) gates]

## 3. Chan - Orthogonal Range Searching in Moderate Dimensions: k-d Trees and Range Trees Strike Back (SoCG 2017)

Source: LIPIcs SoCG 2017 paper 27, DOI 10.4230/LIPIcs.SoCG.2017.27. No arXiv copy used.
Local: `SRC/lipics-SoCG.2017.27/paper.txt`. Dominance: q dominates p iff q_j >= p_j in every coordinate.

Theorem 4 (L516-518): "Let c ∈ [1, 2(1/C1 ) log N ] for a sufficiently large constant C1 . Given N points
in d = c log N dimensions, we can answer N offline dominance range counting queries in
N 2−1/O(log c) time." [note: c ∈ [1, 2^{(1/C1) sqrt(log N)}] - the sqrt sign is on L515; time N^{2-1/O(log c)}]
Context L512-514: Abboud-Williams-Yu Boolean algorithm (derandomized by Chan-Williams) "achieves f (c) = 1/O(log c)";
non-combinatorial (L186-188: "non-combinatorial algorithm").

Combinatorial result, Theorem 1 (L391-396): "Let δ > 0 be any fixed constant and c ∈ [C1 , (1/C1 ) log N/ log2 log N ]
for a sufficiently large constant C1 . Given N points in d = c log N dimensions, we can construct a data structure
in O(N 1+δ ) preprocessing time and space, so that for any query point, we can answer a dominance range reporting
query in N 1−1/O(c log c) + O(K) expected time where K is the number of reported points. For dominance range
counting, we get the same time bound but without the K term." L145-146: "The total time for n queries is
n2−1/O(c log c) [...] The method is purely combinatorial". [note: intro L138-145 shows c log^2 c; log c factor removed
via covering designs, App. A.1, L155]. Offline reporting variant: Theorem 8 (L781-786), N^{2-1/O(c log c)} + output terms.

0-1 ILP application (L198-200): "we can now solve the integer linear programming problem on n variables and cn
constraints in 2(1−1/O(log c))n time, improving Impagliazzo et al.'s 2(1−1/poly(c))n algorithm [17]."
(Ref [17], L680: Impagliazzo, Lovett, Paturi, Schneider, "0-1 integer linear programming ...".)

## 4. Alman, Chan, Williams - Polynomial Representations of Threshold Functions and Algorithmic Applications (FOCS 2016)

Source: arXiv:1608.04355v1. Local: `SRC/arXiv-1608.04355/paper.txt`.
Definition (L320): "THθ (x1 , . . . , xn ) := [|x|/n ≥ θ ]". AC0[d,m] ◦ LTF ◦ LTF[S1,S2,S3]: S3 bottom LTFs, S2
middle LTFs, size-S1 depth-d AC0[m] on top (L240-242).

Theorem 1.1 (L93-96): "For any 0 ≤ θ ≤ 1, there is a probabilistic polynomial for the function THθ of degree
O( n log s) on n bits with error 1/s that can be randomly sampled using only O(log n log(ns)) random bits."
[note: degree O(sqrt(n log s)); sqrt on L94]

Theorem 1.3 (L131-139, probabilistic PTF): degree "O((1/ε )1/3 log s)" [(1/ε)^{1/3} log s], each bullet "with
probability at least 1 − 1/s"; "For the “exact” setting with ε = 1/n, we can alternatively bound the degree by
O(n1/3 log2/3 (ns))."

Theorem 1.8 (L244-246): "For every integer d > 0, m > 1, and δ > 0, there is an ε > 0 and an algorithm for
satisfiability of AC0 [d, m] ◦ LTF ◦ LTF[2n , 2n , n2−δ ] circuits that runs in deterministic 2n−n time."
[note: LTF[2^{n^ε}, 2^{n^ε}, n^{2-δ}], time 2^{n-n^ε}]

Corollary 1.1 (L272-275): "the class ENP does not have non-uniform circuits in AC0 [d, m] ◦ LTF ◦ LTF[2n , 2n , n2−δ ]
[...] for every ε > 0, ENP does not have ACC0 ◦LTF ◦LTF circuits where the ACC0 ◦LTF subcircuit has 2n size and
the bottom LTF layer has n2−ε gates." [note: 2^{n^{o(1)}} size]

Theorem 1.9 (L300-305): "randomized satisfiability algorithm for MAJ ◦ AC0 ◦ LTF ◦ AC0 ◦ LTF circuits of depth d
running in 2n−Ω(n ) time [...] the top MAJ gate, along with every LTF on the middle layer, has O(n6/5−ε ) fan-in,
and there are O(2n ) many AND/OR gates (anywhere) and LTF gates at the bottom layer." [note: 2^{n-Ω(n^δ)},
O(2^{n^δ})]

## 5. Ilango - Constant Depth Formula and Partial Function Versions of MCSP are Hard (FOCS 2020)

Source: ECCC TR20-183 (downloaded 2026-11-21 from https://eccc.weizmann.ac.il/report/2020/183/download).
Local: `SRC/eccc-TR20-183/paper.txt`. MCSP input: truth table of length N = 2^n plus size bound s (L98-99).

Statement (L107-109, informal highlight in intro, not a numbered theorem):
"If MCSP with a fixed size parameter s = poly(n) does not have circuits of size Õ(N ), then NP 6⊆ P/poly [28]."
[note: 6⊆ = not subset]

Reference [28] (L3321-3323): "Dylan M. McKay, Cody D. Murray, and R. Ryan Williams. Weak lower bounds on resource-
bounded compression imply strong separations of complexity classes. In 51st Annual ACM SIGACT Symposium on Theory
of Computing (STOC), pages 1215–1225, 2019." (local copy: `SRC/mmw19/paper.txt`).

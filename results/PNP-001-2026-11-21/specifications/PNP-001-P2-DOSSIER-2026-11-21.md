# PNP-001 P2 dossier - exact statements per priority question (director 2026-11-21, owner order)
Every P2 question is listed with: theorem statement, threshold parameters, computational model, missing hypothesis, proven transfer.
Barrier remarks are given ONLY where a specific theorem justifies them; nothing here is a universal necessity claim.
N = 2^m is the truth-table length; m the number of input variables of the function in the truth table.

## A Theorem R route (R-MCSP) - questions Q-142b3d067f (property P), Q-e7ea75fd10 (candidate-P falsification), Q-28f70474ce
   (elimination calculus), Q-7b120ba811 (HIW23 sharing), second-lever question (fixed-threshold formula exponent)
- Formula lower bound used: Chen-Jin-Williams (ECCC TR20-065) Thm 1.6: for every alpha in (0,1) and eps > 0, MCSP[n^alpha] has no
  probabilistic formulas of size n^{2+alpha-eps}; n = truth-table length (Def. 2.1), size = number of leaves (sec. 2.1).
- Thresholds: s = N^beta, beta < beta_0 (small, fixed).
- Model: fan-in-2 Boolean circuits (size S, r = gates of fan-out > 1) and De Morgan formulas (leaf count L).
- MISSING HYPOTHESIS R-MCSP: there are C > 0, 0 <= c < 1, beta_0 > 0 such that for every fixed beta in (0, beta_0) every circuit for
  MCSP[N^beta] has an equivalent formula with at most C S (r+1)^c leaves (for the transfer only L <= C CC^{1+c} is used).
- PROVEN TRANSFER (Theorem R, internally reviewed): R-MCSP + CJW20 Thm 1.6 => CC(MCSP[N^beta]) >= N^{1+eps} with eps independent of beta
  => (McKay-Murray-Williams STOC'19 Thm 1.4, in the restated form of Chen-Jin-Williams TR19-118) NP not in P/poly => P != NP.
- Second lever: a fixed-threshold bound L(MCSP[N^beta]) >= N^{a(beta)} with a(beta) > 2+beta uniformly relaxes the hypothesis to c < a-1.
  It has no transfer of its own; it only weakens R-MCSP.
- Theorem-specific barrier remarks:
  * relativization: MMW19 Thm 1.4 is stated for MCSP^A for every oracle A; there are oracles A with NP^A in P^A/poly (e.g. a
    PSPACE-complete A). A proof of the hypothesis that holds uniformly for MCSP^A for every A would therefore prove a false statement -
    a proof must use something that fails for some oracle.
  * locality: McKay-Murray-Williams Thm 1.1 gives circuits for MCSP^A[s] of size O~(N s^2) with Sigma3SAT^A oracle gates of fan-in O~(s^2).
    Whether R-MCSP must fail for such oracle circuits depends on whether the CJW20 formula bound also holds for formulas with such
    oracle leaves - NOT established here; so non-localization is a CONDITIONAL requirement for this route.
  * natural proofs: R-MCSP concerns one explicit function; no theorem-specific natural-proofs obstruction is established.

## B One-tape route - question Q-5226caddf1
- Transfer theorem: Cheraghchi-Hirahara-Myrisiotis-Yoshida (STACS 2021, ECCC TR20-103) Thm 1 (corollary of MMW19 Thm 1.3 + Lemma 9):
  there is mu > 0 such that MCSP[2^{mu n}] not in DTIME1[N^1.01] implies P != NP.
- Model: DTIME1 = Turing machine with a one-way read-only input tape and one two-way read/write work tape.
- Threshold: s = 2^{mu n} = N^mu, the specific small constant mu from the proof (depends on the MMW polynomial).
- Known: CHMY Thm 2: MCSP[2^{mu n}] not in BPTIME1[N^1.99] for some mu < 1 close to 1 (authors: the gap is the size parameter).
- MISSING HYPOTHESIS: MCSP[2^{mu n}] not in DTIME1[N^1.01] for the small mu of Thm 1.
- Candidate mechanism: a local PRG fooling q-state time-t one-tape DTMs with seed below N^{mu'}; known seed O~(sqrt t + log 1/eps) * log q
  (CHMY Thm 20, Forbes-Kelley via Viola's decomposition into ROBPs of width exp(O(sqrt t log tq))).
- Theorem-specific barrier remark: CHMY Thm 3 shows their technique extends to oracle machines with queries of length N^{o(1)};
  MMW19 Thm 1.2 + Lemma 9 give MCSP[2^{mu n}] in one-tape time N^{1+O(mu)} with a Sigma3SAT oracle and queries of length N^{mu+o(1)}.
  A technique that also lower-bounds one-tape machines with queries of length N^{mu+o(1)} at that time bound would prove a false
  statement; with seed ~ log q this is avoided automatically when oracle answers are absorbed into states.

## C Streaming route - question Q-156fa9c912 (connection test EXT vs H_C)
- Transfer theorem: McKay-Murray-Williams STOC 2019 Thm 1.3: if there is some time-constructible s(n) >= n and A in PH such that
  search-MCSP^A[s(n)] is not solvable by a poly(s(n))-space streaming algorithm with poly(s(n)) update time, then P != NP.
- Model: one-pass streaming, space and update time both polynomial in s.
- MISSING HYPOTHESIS: such a streaming lower bound for one fixed s and A in PH, excluding every polynomial budget.
- Known limit: Lemma FB2 (reviewed): state-count / Myhill-Nerode arguments give at most O(s log(n+s)) bits of memory - inside the
  poly(s) budget, so the missing statement must bound the UPDATE TIME.

## D Kolmogorov / one-way-function route - question Q-a6fdbb66ba
- Theorem: Liu-Pass (ITCS 2026, LIPIcs 362 97, ECCC TR25-202) Thm 1.2: one-way functions exist IF AND ONLY IF boundary-MINrK^poly is
  not in ioBPP.
- Model: probabilistic polynomial time, infinitely-often (ioBPP), promise problem boundary-MINrK^poly (definitions: spec LIT-9).
- MISSING HYPOTHESIS: boundary-MINrK^poly not in ioBPP.
- PROVEN TRANSFER: hypothesis <=> one-way functions exist => P != NP (one-way functions imply NP not in BPP, hence P != NP).
  CORRECTION (owner 2026-11-21): the converse (P != NP => one-way functions) is NOT established; the hypothesis is equivalent to the
  existence of one-way functions, which is at least as strong as P != NP and not known to be equivalent to it.

## H Exact transfer statements (owner source check 2026-11-21)
- Oliveira-Pich-Santhanam, "Hardness Magnification Near State-of-the-Art Lower Bounds" (Theory of Computing 2021, journal version), with
  N = 2^m and a universal constant c: if there is eps > 0 and beta_0 > 0 such that for all beta in (0, beta_0)
  GapMCSP[2^{beta m}/(c m), 2^{beta m}] is not in SIZE(N^{1+eps}), then NP not in P/poly. The quantifiers matter: one fixed beta is not enough.
  The EXACT-MCSP variant (McKay-Murray-Williams) must be recorded separately; its parameters are not those of the gap theorem.
- McKay-Murray-Williams STOC 2019 Thm 1.3 concerns SEARCH-MCSP^A[s(m)] (output a small circuit, oracle gates of A allowed) against
  deterministic one-pass streaming with poly(s) space and poly(s) update time. CORRECTION (owner 2026-11-21): a lower bound for the DECISION
  version of the same MCSP^A suffices a fortiori (every search algorithm decides); the search version is the weakest sufficient target.
  Verbatim (local mmw19/paper.txt l.115-118): "If there is some time-constructible s(n) >= n and an A in PH such that search-MCSP^A[s(n)] is not
  solvable by a poly(s(n))-space streaming algorithm with poly(s(n)) update time, then P != NP." (streaming algorithms need not read a fresh bit
  each step). Space alone cannot reach it: O(s log s) bits suffice with unbounded update time (Lemma FB2) - only update time is open.
  The target is logically at least as strong as P != NP and very likely true (it follows from subexponentially secure one-way functions for
  s = m^c, c large - standard argument, not written out): it asks to prove a consequence of cryptography without its assumption.
- Locality (Chen-Hirahara-Oliveira-Pich-Rajgopal-Santhanam, ITCS 2020): a method that would also prove the lower bound for circuits with the
  local oracle gates of their upper bound is unsound. Using this needs the formal oracle model, the upper bound, and an analysis of the
  concrete proof step in that model - a heuristic "a local oracle shortcuts it" is not a verdict either way.

## I Direct MCSP circuit route (Q-10bbdfaf2a) = target statement 4 (owner 2026-11-21)
- Ilango (FOCS 2020), citing McKay-Murray-Williams STOC 2019 Thm 1.4: a circuit lower bound above ~O(N) for MCSP with a FIXED polynomial
  threshold s(m) implies NP not in P/poly. Reason: NP in P/poly gives small circuits for search-MCSP; a search circuit also decides
  (compute the candidate's truth table and compare), total size N * poly(m) = N (log N)^{O(1)} for s = m^c.
- PROOF OBLIGATION: for some fixed c >= 1, MCSP[m^c] has no circuits of size N (log N)^k for EVERY fixed k (N = 2^m) - against GENERAL
  Boolean circuits (formula / monotone / local-oracle models do not suffice). Then NP not in P/poly, hence P != NP.
- This route does not need the streaming update-time formulation. (Exact source sentence: spec LIT-11 once extracted.)
## J Risk of the streaming route (owner 2026-11-21)
- MCSP in P rules out one-way functions (Kabanets-Cai). A fixed-threshold s = poly(m) solver reads the whole table (time 2^{O(m)}) and only
  breaks PRFs with circuits of size <= s and security beyond 2^{O(m)}, i.e. SUBEXPONENTIALLY secure ones. So the streaming target may be FALSE
  although P != NP (a world without sufficiently secure one-way functions has not been excluded): proving it is a bet on cryptographic hardness.
- Hirahara's worst-case = average-case equivalence (ECCC TR18-138, Thm 6.7) is for Gap-MCSP with factor ~ 2^{(1-eps)m}, not exact MCSP.
- The bottleneck of the streaming route is UPDATING a compressed description, not space (Lemma FB2). MMW's Stream-Merge does it with
  Sigma-level oracles; a lower bound for that implementation alone is not a lower bound for all streaming algorithms. Restricted update
  classes (linear, constant depth) give verified mathematics, never P != NP progress without a transfer to arbitrary poly-time updates.

## K. Uniform magnification target (director 2026-11-21, source-checked in local arXiv:2503.24061 paper.txt lines 234-255)
Atserias-Mueller Theorem 11 (verbatim modulo typesetting): P != NP^{(+)P} if there exist a real eps > 0 and a function sigma(l) <= 2^{o(l)}
such that n^{-eps}-MCSP[sigma] is not in P-uniform-SIZE[n^{1+eps+o(1)}].
- Conclusion is P != NP^{(+)P} - weaker than P != NP (does not imply it). Exploration level, not P!=NP progress.
- Authors: "seems to sidestep the localization barrier" because the matching known uniform lower bound (Santhanam-Williams: P not in
  P-uniform-SIZE[n^c] for every c) does not seem to localize. Their open questions: (1) a constructive Santhanam-Williams proof with an
  explicit hard problem in P; (2) a general uniform magnification threshold for any 2^{n^{o(1)}}-sparse problem. No 2026 follow-up found
  (one web search, 2026-11-21).
- Theorem 10 (unconditional): n^{-eps}-MCSP[2^{sqrt l}] not in PFML[n^{2eps-delta}] for all 0 < eps, delta <= 1.
NEW OBLIGATIONS (intermediate goals, lane target 4 / Q-10bbdfaf2a):
- K1: an explicit (constructive) problem in P without P-uniform circuits of size n^c - Santhanam-Williams made explicit. Verified mathematics.
- K2: n^{-eps}-MCSP[sigma] not in P-uniform-SIZE[n^{1+eps+o(1)}] for SOME eps > 0, first for a restricted uniformity (e.g. LOGTIME- or
  DLOGTIME-uniform, or uniform formulas) - each restricted version is a closed intermediate theorem; the full statement gives P != NP^{(+)P}.

## L. Owner deep research 2026-11-21 (MCSP lower bound) - director check
- L1 QUANTIFIERS of target 4 (section I) made explicit: it suffices that EXISTS c >= 1 FORALL k FORALL m0 EXISTS m >= m0:
  CC_B2(MCSP[m^c]) > 2^m m^k (infinitely many hard lengths per k). Reason: NP in P/poly gives circuits of size N poly(m) for ALL large m.
  "No circuits of size ..." in section I always means this infinitely-often form. The fixed c and the FORALL k stay mandatory.
- L2 LEMMA (proved, folklore, verified mathematics, no novelty claim): MCSP[s] is constant 0 on a subcube of dimension N - O(s log(m+s)).
  Proof: |YES| <= 2^{O(s log(m+s))}; on q = ceil(log2|YES|)+1 fixed positions some pattern has no YES instance; fix it.
  Consequence: MCSP is not an affine / bit-fixing disperser at that dimension - disperser-based gate elimination (e.g. Mishra-Santhanam
  4n - O(log n), ECCC TR26-260 rev. 1, owner-supplied, NOT source-checked here) does not transfer with MCSP as the hard function.
- L3 COUNTEREXAMPLE TO A PROOF STRATEGY (proved): H(T) = [|T| <= t], t = Theta(m^{c-1} log m), has log2|YES| = Theta(m^c log m), depends on
  all N bits, is fully symmetric - and has O(N) circuits (adder tree + comparison). So sparsity + symmetry + full dependence cannot give a
  superlinear bound; a proof must use which truth tables are computable.
- L4 Chen-Li-Yang 2022 Thm 1.2 (owner-supplied, not source-checked): ~2N + O(N/loglog N) lower bounds against probabilistic B2 circuits for
  sparse NP languages give NP not in SIZE(n^k) for every k - NOT NP not in P/poly, NOT P != NP. Exploration only; never a P!=NP step.
- L5 Locality: MMW give small Search-MCSP circuits with local PH-oracle gates; any claimed proof of target 4 must fail for such oracle
  circuits (state where B2 gates differ from local oracle gates). Atserias-Mueller (section K) gives P != NP^{(+)P}, not P != NP.
- PRIMARY OBLIGATION unchanged (section I, form L1): a lower-bound invariant valid for arbitrary B2 DAGs (fan-out reuse allowed) that
  (1) holds for all B2 circuits, (2) exceeds 2^m m^k for every fixed k on infinitely many m, (3) fails for local-oracle circuits.
  Finite computation tests candidate invariants and searches counterexamples (L2/L3 style); it never counts as the asymptotic proof.

## title

Exact residual-state characterization for finite prefix languages

## mathematical_statement

Let L be a finite set of binary strings, and for every prefix p let R_p={z in {0,1}*: pz is a prefix of some word in L}. (1) Any deterministic streaming machine whose state after p determines, for every suffix z, whether pz is a prefix of a word in L must place p and q in different states whenever R_p != R_q. (2) Assigning one state to each distinct set R_p, with a rejecting sink for strings that cease to be prefixes, gives a deterministic machine recognizing the prefix language of L. (3) Hence the minimum number of states is exactly the number of distinct residual sets, with the sink included when needed. Applied to L=Im(Eval) for size-at-most-s circuits these residuals are the completion sets relevant to EXT; the record asserts no bound on real-gate transition cost.

## original_proof

proved_step: LEMMA (exact residual-state characterization for finite prefix languages). Let L be a finite set of binary strings, and for every prefix p define R_p={z in {0,1}*: pz is a prefix of some word in L}. Any deterministic streaming machine whose state after reading p determines, for every suffix z, whether pz is a prefix of a word in L must place p and q in different states whenever R_p != R_q. Conversely, assigning one state to each distinct set R_p (and a rejecting sink for strings that cease to be prefixes) gives a deterministic machine recognizing the prefix language of L. Hence the minimum number of states is exactly the number of distinct residual sets, with the sink included when needed. Proof: If R_p != R_q, choose z in their symmetric difference. The required answers after p and q on continuation z differ. A deterministic machine in the same state after p and q would, on the same continuation z, produce the same answer, contradiction. For the converse, after reading bit b from residual R_p, the residual becomes R_{pb}={z:bz in R_p}; this is determined by R_p and b. If R_p is empty, transition to the sink. Acceptance is determined by whether the empty suffix belongs to the residual. This proves the transition and acceptance rules are well-defined. Applied to L=Im(Eval) for size-at-most-s circuits, these residuals are precisely the completion sets relevant to EXT. This characterizes required information but asserts no bound on real-gate transition cost.

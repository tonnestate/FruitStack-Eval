## title

Residual-language quotient gives minimum layer width

## mathematical_statement

Let F be any subset of {0,1}^N. For t<=N and prefix p in {0,1}^t define R_p={u in {0,1}^(N-t): pu in F}. (1) In any deterministic layered streaming automaton accepting exactly F, two length-t prefixes with R_p different from R_q lead to different states. (2) The residual sets at each layer form a deterministic layered automaton with transitions R -> {v in {0,1}^(N-t-1): bv in R} on input bit b, initial state F, and acceptance at layer N iff the empty string lies in R. (3) Hence the minimum number of states at layer t equals the number of distinct residual sets {R_p: |p|=t}. Scope: all finite binary languages F and layered automata reading exactly N bits; no bound on transition circuit cost or on simulation through arbitrary MCSP decision circuits.

proved_step: statement: Residual-language quotient lemma. Let F be any subset of {0,1}^N. For each t≤N and prefix p∈{0,1}^t, define R_p={u∈{0,1}^{N-t}: pu∈F}. Conversely, the residual sets at each layer form a deterministic layered automaton with transitions R ↦ {v∈{0,1}^{N-t-1}: bv∈R} on input bit b, initial state R_empty=F, and acceptance at layer N iff the empty string belongs to R. Thus the minimum number of states at layer t is exactly the number of distinct residual sets {R_p:|p|=t}. Proof: If R_p≠R_q, choose u in their symmetric difference. Then exactly one of pu,qu is in F. If the automaton had the same state after p and q, its deterministic processing of the same suffix u would have the same acceptance outcome, contradiction. For the converse, after prefix p the stored state R_p updates on bit b to R_pb by the definition of residual and concatenation; induction on prefix length gives exactness, and final acceptance is exactly membership in F.
scope: All finite binary languages F⊆{0,1}^N and deterministic layered streaming automata reading exactly N bits. It characterizes minimum state width layer by layer; it gives no bound on transition circuit cost or construction time, and no simulation through arbitrary MCSP decision circuits.

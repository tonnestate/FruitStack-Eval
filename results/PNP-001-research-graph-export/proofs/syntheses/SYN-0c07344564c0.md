## title

Explicit-family EXT update with n+M state bits

## mathematical_statement

Let F=(C_1,...,C_M) be a fixed list of Boolean circuits on n inputs, each with at most s fan-in-two gates, with streamed bits the truth table of length 2^n in binary input order. There is a deterministic exact EXT-prefix update representation using n+M state bits and at most O(n+M(s+1)) fan-in-two AND/OR/NOT gates per update. The state stores the next index i in n bits and a candidate mask a in M bits; on next bit b, evaluate each C_j at i, set a'_j=a_j AND [C_j(i)=b], and increment i modulo 2^n. After k updates a_j=1 exactly when C_j agrees with all k streamed bits. M may be exponential, so this does not bound the implicit family of all size-s circuits by poly(s,n).

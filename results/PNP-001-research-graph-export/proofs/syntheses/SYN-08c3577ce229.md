## title

Explicit candidate-filter update of size O(K(s+n)+n)

## mathematical_statement

Fix n and a finite list C_1,...,C_K of Boolean circuits, each with n inputs and at most s fan-in-two gates. Stream the truth table in binary input order, maintaining an n-bit index i and K live bits a_j, where a_j=1 exactly when C_j agrees with every streamed bit so far. On receipt of bit b, the exact update can be implemented by a fan-in-two Boolean circuit with O(K(s+n)+n) gates: each e_j = a_j AND [C_j(i)=b] and the index increments modulo 2^n. The bound does not give a polynomial-in-s update for the full circuit list nor a bound for arbitrary MCSP decision circuits H_C.

## original_proof

proved_step: statement: Let V_i = span(v_i) in GF(2)^(N+1) for occurrences i in a finite index set I (each bundle is a single augmented equation, coefficients in (x,z), right-hand side last), t = (0,...,0,1). For S subset of I, the system {equations of i : i in S} is inconsistent iff t lies in span{v_i : i in S}. The minimal inconsistent occurrence sets are exactly the sets C minus {t}, where C ranges over the circuits of the binary vector matroid on {v_i : i in I} plus {t} that contain t.
derivation: (1) Fredholm alternative for GF(2) affine systems: a system with augmented rows v_i (right-hand side last) is unsolvable iff some GF(2)-combination of its rows is 0 = 1, i.e. iff t in span{v_i : i in S}. (2) If S is minimal with t in span(S), then S is independent (otherwise a proper subset already spans) and S union {t} is dependent with a unique expression of t; hence S union {t} is a circuit containing t. (3) Conversely, a circuit C containing t gives S = C minus {t} with t in span(S), and minimality follows because a proper subset of S spanning t would yield a smaller dependent set containing t, contradicting circuit minimality. Zero vectors v_i = 0 (trivially satisfiable equations) are in no circuit and are excluded. Case v_i = t gives the singleton circuit {i, t}, i.e. S = {i}, consistent with the statement.
scope: Rank-1 bundles only (each occurrence contributes one linear equation). Finite, exact. Does NOT cover bundles of rank >= 2, and does NOT cover shared auxiliaries in the rank >= 2 setting (counterexample cm-c960a57e095a4e0e shows the interface identity fails there).

# PNP-001 QE* research report

**Scope.** This report audits the current QE* proof state against the local primary-source corpus named in the contracts. Bracketed statuses apply to each finding: `[PROVED]`, `[REFUTED]`, or `[OPEN]`. A cited source statement includes an absolute file path and line number(s). “Proved” here means established under the stated model and assumptions; it is not a claim that P differs from NP.

## I. Recovered proof state

- [PROVED] MMW define search-MCSP^A as a total search task: on an N=2^n-bit truth table, output an A-oracle circuit of size at most s(n), or report that none exists. The output convention matters: a decision procedure or an algorithm correct only on yes-instances is not the theorem’s task. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:30-36`; total-output implementation also `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:7-10`.)
- [PROVED] MMW Theorem 1.2 states that for every time-constructible s(n)≥n and arbitrary oracle A, search-MCSP^A[s(n)] has a one-pass algorithm using O~(s) space, O~(s²) update time, O~(s) total time per input bit up to the stated 2^n·O~(s) total bound, and Σ₃SAT^A queries of length O~(s). In the paper’s theorem notation the update bound is O~(s²); constants/polylog factors are suppressed. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:100-105`.)
- [PROVED] MMW Theorem 1.3 says: if there exists a time-constructible s(n)≥n and A∈PH for which search-MCSP^A[s(n)] is not solvable by any poly(s)-space streaming algorithm with poly(s) update time, then P≠NP. The model permits work between consecutive fresh input-bit reads. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [PROVED] MMW’s theorem is an implication from a uniform streaming lower bound to P≠NP; it is not itself a proof that the lower-bound premise holds. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [PROVED] The recovered local state records QE* and QE(2,3) as conjectures, property P as open, and no complete QE* proof; its counting lemma does not establish the target corollary for minimal layered automata, and its cell-probe lemma gives only the trivial O(S/w) ceiling. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:20-31`.)
- [PROVED] The corrected Lambda_S state model allows time-varying transitions, redundant physical codes, a surjection from reachable codes to semantic Nerode classes, and a decoder; Lambda_S counts transition circuit complexity plus decoder cost when specified. The model is nonuniform, unlike MMW’s uniform algorithm. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:4-6`.)
- [OPEN] No local source establishes QE* for ordinary fan-in-two updates, nor a general lower bound that survives arbitrary redundant/time-varying representations and deferred work. The recovered state explicitly leaves these conjectures and bridge questions open. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:20-31,48-57`.)
- [OPEN] Claims attributed to Sharma–Velusamy ESA 2026 are not source-checked here; that source is not among the local primary sources. (`/root/contracts/PNP-001-QE-STAR-CONTRACT-2026-11-21.md:20-32`.)

## II. Formal target and model corrections

- [PROVED] Fix A=SAT, which is admissible because SAT∈NP⊆PH. The task is exact total search-MCSP^SAT[s(n)], not ordinary search-MCSP: on every truth table it must return a SAT-oracle circuit of size ≤s(n) when one exists, and otherwise return a valid “none” report. The general definition and total output requirement are in MMW; the selection A=SAT is a definition for this audit. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:30-36`.)
- [PROVED] For the central magnification premise, take any fixed time-constructible s(n)≥n. The required resource quantifiers are separate polynomials: there must be no deterministic one-pass algorithm with workspace ≤p(s(n)) and worst-case between-read update time ≤q(s(n)) for any fixed polynomials p,q. Refuting only one exponent pair does not refute the theorem’s premise; the theorem says “a poly(s)-space streaming algorithm with poly(s) update time.” (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [PROVED] “One-pass” does not mean one unit-cost operation per input bit. The machine may perform work after a bit arrives and before it requests the next bit. Update time is worst-case work in that interval, and output is produced at the end. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:121-124`; output-at-end convention `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:7-10`.)
- [PROVED] The ordinary Boolean transition representation has F_t:{0,1}^S×{0,1}→{0,1}^S, fan-in two, with time-dependent F_t allowed; redundant reachable codes represent semantic states through a surjection. The total circuit cost is Σ_t CC(F_t) plus CC(Dec) if decoder cost is included. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:4-6`.)
- [PROVED] For exact search, future-equivalence at a cut identifies prefixes p,p′ precisely when every common continuation q forces the same required output behavior: both must produce a valid circuit for their respective completed truth tables, or both must report no circuit. Distinct live prefixes cannot share a state: append a continuation completing one prefix to a yes-instance; the other completion is either a different table requiring a different correct output or a no-instance requiring bottom. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:12-17`.)
- [PROVED] The live/dead distinction is essential for total search. A dead prefix cannot share a state with a live prefix, and distinct live prefixes must be distinguishable; the recovered proof corrects the argument to cover the case where the second completed table is also a yes-instance. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:12-17`.)
- [PROVED] An exact width-S one-pass computation unrolls into an ordinary circuit of size Σ_t CC(F_t)+CC(D_N), with online cut-width at most S. This statement includes time-dependent encodings, redundancy, shared gates, and deferred computation. Thus a lower bound for that circuit class is representation-invariant, but no such useful QE* lower bound is supplied by this observation. (`/root/contracts/STATE-RECODING-BOUNDS-CHECK-2026-11-21.md:68-75`.)
- [OPEN] Representation completeness and resource transfer are distinct obligations: (B) every admitted algorithm/encoding must map into the proposed representation class; (E) a lower bound in that class must imply a worst-case uniform update-time lower bound in the MMW model. Neither follows merely from a hard canonical state representation. (`/root/contracts/PNP-001-ORACLE-ELIMINATION-CONTRACT-2026-11-21.md:50-69`; model distinction `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:4-10`.)

## III. Inference and locality audit

### MMW Stream-Merge reconstruction

- [PROVED] In MMW’s Stream-Merge construction, the block length is t=100s log s, and the output for a block is the lexicographically first minimum-size circuit consistent with the specified earlier input points and the new block, or an all-zero t-bit sentinel if no such circuit exists. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:517-533`.)
- [PROVED] The related Theorem 4.1 parameter is t=200s log s; it should not be silently substituted for the 100s log s block in Stream-Merge. It outputs bits of a truth table computable in PH, has one-pass O(N) total time and O(t) space, and uses B_n-oracle queries of length t. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:561-565`.)
- [PROVED] MMW bound Stream-Merge’s worst-case update time by O~(t²), its space by O~(t), and its sequence of Σ₃ queries by O(t) queries of length O~(t) per update; total time is N·O~(t). The oracle hides the cost of answering these queries. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:536-551`.)
- [PROVED] A compact state or a canonical minimum-circuit selector being hard does not establish hardness against every legal streaming algorithm: MMW’s theorem is universal over algorithms, while Stream-Merge is one construction and its update uses powerful oracle queries. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:517-551`; target quantifiers `/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [OPEN] The complete continuation set V(C,p,y), its exact prefix-consistency check, and local-time cost of canonical witness selection do not yield a source-backed lower bound against alternative state encodings in the reviewed corpus. The oracle-elimination contract treats the universal transfer as the research question, not as an established lemma. (`/root/contracts/PNP-001-ORACLE-ELIMINATION-CONTRACT-2026-11-21.md:1-16,50-69`.)

### Independent re-derivation of framing facts F-1..F-3

- [PROVED] F-1, conditional implication: choose any fixed time-constructible s≥n and A=SAT. If the corresponding uniform poly(s)-space, poly(s)-worst-case-update lower bound holds, it instantiates every premise of MMW Theorem 1.3, hence implies P≠NP. This is the derivation of “at least as hard”; the premise remains open. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [PROVED] F-2, relativized version: Theorem 1.2’s construction uses Σ₃SAT^A queries. In a model where these query answers are available at polynomial cost relative to B and P^B=PH^B, the queries become P^B-computable; substituting those computations preserves polynomial-in-s resource bounds because query lengths are O~(s), and gives a relativized streaming algorithm with poly(s) workspace/update. Thus a lower bound against that relativized oracle-gate model is false. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:100-105,561-565`.)
- [REFUTED] F-2 would be too strong if read as refuting ordinary fan-in-two QE*: MMW’s counterexample uses B_n oracle queries (and the related construction uses PH-computable output bits), not ordinary fan-in-two transition circuits shown to simulate those queries. The ordinary QE* statement and its relativized oracle-gate analogue are different claims. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:561-565`; ordinary fan-in-two conjecture `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:20-25`.)
- [PROVED] F-3, nonuniform consequence: Assume NP⊆P/poly. For any NP-with-polynomial-advice computation, form the ordinary NP language whose input contains both the advice string and the instance, and whose verifier runs the advised computation. By the assumption that language has polynomial-size circuits; fixing the actual advice bits gives polynomial-size circuits for the advice computation. Hence NP/poly⊆P/poly. Iterating this simulation through the fixed finite number of quantifier levels in any PH language yields PH⊆P/poly. This supplies the circuit families needed for the queries below; the implication is an independent derivation, not an assumption about uniformity.
- [PROVED] Under that assumption, each length-O~(s) query to Σ₃SAT^A for fixed A∈PH has a polynomial-size circuit family. Substituting these nonuniform circuits into MMW’s Theorem 1.2 algorithm replaces its oracle calls at each update by polynomial(s)-size ordinary computations, while its workspace stays O~(s); the O~(s²) base update plus polynomially many polynomial-size query evaluations is still poly(s). This yields nonuniform poly(s)-size updates for the constructed algorithm. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:100-105`.)
- [PROVED] Therefore the exact nonuniform QE* statement (ranging over total-search algorithms and counting its output decoder) implies NP⊄P/poly by contraposition. This does not establish the uniform MMW premise and does not imply P≠NP on its own. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:30-36,100-105`; nonuniform Lambda_S definition `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:4-6,20-25`.)

## IV. Strongest established result and exact missing lemma

- [PROVED] The strongest unconditional structural result in the local state is the unrolling theorem: exact one-pass realizations with S-bit memory map to ordinary circuits whose size is the sum of transition and decoder costs and whose online cut-width is at most S. This handles changing encodings and shared gates without assuming a canonical state. (`/root/contracts/STATE-RECODING-BOUNDS-CHECK-2026-11-21.md:68-75`.)
- [PROVED] The strongest published implication relevant to the goal is MMW Theorem 1.3: an exact uniform total-search lower bound at one admissible s and A∈PH would imply P≠NP. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`.)
- [OPEN] The smallest decisive missing statement is: for some fixed time-constructible s≥n and fixed A∈PH (e.g. SAT), prove that every deterministic one-pass algorithm for total search-MCSP^A[s], including redundant/time-varying encodings and arbitrary allowed work between reads, requires super-polynomial workspace or worst-case update time. This is exactly the unproved universal premise of MMW Theorem 1.3, not merely a lower bound for Stream-Merge. (`/root/fruits/research/PNP-001/literature/sources/mmw19/paper.txt:115-124`; representation scope `/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:4-10`.)
- [OPEN] Any proof via online cut-width must independently establish a lower bound for the exact MCSP search function in that circuit class and complete the representation/resource transfer; unrolling alone proves neither. (`/root/contracts/STATE-RECODING-BOUNDS-CHECK-2026-11-21.md:68-78`; transfer obligations `/root/contracts/PNP-001-ORACLE-ELIMINATION-CONTRACT-2026-11-21.md:50-69`.)
- [OPEN] The counting argument does not close this gap: its generic algorithm count depends on decoder size, and the proposed minimal-layered-automata counting corollary is explicitly left unwritten/open; succinct descriptions of MCSP are another stated limitation. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:20-24`.)
- [OPEN] The cell-probe observation does not close it either: scanning all S/w cells gives only O(S/w) probes per update and no stronger information-transfer bound is established. (`/root/contracts/PNP-001-STREAMING-LAMBDA-S-CHECK-2026-11-21.md:25-26`.)

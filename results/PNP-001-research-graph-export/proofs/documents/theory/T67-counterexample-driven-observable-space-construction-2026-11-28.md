## 1. Setting
X = {0,1}^n, F : X -> X given by a circuit of size |F|, g : X -> K a circuit-computable observation (K = F_q; arithmetic in K is cheap, field case first).
V_g = span_K { g∘F^k : k ≥ 0 } (functions X -> K), d = dim V_g. Facts [U] (T38 O1): log_q N ≤ d ≤ N (N = number of exact state classes); d can be exponential for trivial dynamics (T38 O2, counter MSB: d = 2^{n-1}+1).

## 2. Theorem A (the owner's construction; correct) [U, given an equivalence oracle; [H] gives the oracle]
Oracle EQ(C): given a circuit C (of the form h − Σ c_j f_j), return an x with C(x) ≠ 0 or "none". Under H this is one SAT-search call.
Algorithm. Keep functions f_1..f_r (as one circuit chain, f_j = g∘F^{j−1}) and reference states x_1..x_r with E_ij = f_j(x_i) invertible. Start: f_1 = g, x_1 with g(x_1) ≠ 0 (one EQ call on g; g ≡ 0 ⇒ d = 0).
For i = 1,2,…: h := f_i∘F; c := E^{-1}(h(x_k))_k (Gauss); call EQ(h − Σ c_j f_j).
 * none ⇒ h = Σ c_j f_j on all of X: row i of M is c.
 * x* ⇒ append f_{r+1} := h, x_{r+1} := x*; row i of M is e_{r+1}.
Stop when i > r. Result: Φ = (f_1..f_r), Φ∘F = MΦ exactly, r = d, exactly **r+1 = d+1 EQ calls** (each call advances i by one, and i ranges over 1..r).
Proof. (a) Invertibility is preserved: extended matrix [[E, v],[w^T, h(x*)]], v_k = h(x_k), w_j = f_j(x*). Its Schur complement is s = h(x*) − w^T E^{-1} v = h(x*) − Σ c_j f_j(x*) ≠ 0 because x* is a counterexample and c = E^{-1}v; a block matrix with invertible E and nonzero scalar Schur complement is invertible. (b) At the end W = span{f_j} is Koopman-closed (each f_i∘F ∈ W by construction) and contains g, so W ⊇ V_g; each f_j = g∘F^{j−1} ∈ V_g, so W = V_g and r = d. (c) The f_j are independent (the matrix E is invertible), so r = dim. (d) Exactness of M: the "none" answer is a statement about ALL x ∈ X. ∎
Cost [H]. All f_j are one chain of size |g| + d|F|; the identity circuit has size N_c = O(|g| + d|F| + d²) over F_2 (O(d) XORs with coefficients). Total (d+1)·N_c^κ + O(d³) for the Gaussian eliminations. Evaluation of g(F^T x) afterwards: compute Φ(x) in |g|+d|F|, then M^T Φ(x) in O(d^ω log T), then read g = e_1·Φ: **Õ(d^ω log T + d|F|)**, independent of T otherwise. If d would exceed a given r_max the procedure stops and reports it (the oracle calls stay bounded by r_max+1). [V] `verify-T67/ce_basis.py`: counter n=3..7, LFSR n=5,7,8, random permutations n=4,6,8 over F_2: found r = true d (via the rank of all orbit functions) in every case, M exact on all x, queries = d+1 ≤ 2d+1; the brute-force oracle stands in for SAT (finite check of the algorithm, not of H).
Relation to the literature [R, not opened here]: this is the equivalence-query learning of multiplicity automata (Beimel–Bergadano–Bshouty–Kushilevitz–Varricchio, J. ACM 2000), with the SAT-search as the equivalence oracle and F deterministic; the counterexample-extends-the-Hankel-basis step is their Hankel-matrix argument. Not new mathematics. What is new here is only its use inside the contradiction proof (see §3).

## 3. What the equality assumption does and does NOT supply
**Supplied [H]**: PH collapses, so every Σ2 statement "∃ structure Φ (size ≤ s) ∀x: specification(Φ,F)" is decided AND its witness found in time poly(s,|F|)·N^κ (Σ2 search ⇒ search by self-reduction). Hence not only linear spaces: any structure class whose members have poly-size descriptions AND whose correctness is a coNP identity can be *constructed* by the same counterexample/CEGIS loop or directly by Σ2-search: Φ with Φ∘F = G∘Φ and g = π∘Φ for G in a class with cheap iteration (linear over F_q, affine over a ring, triangular shear towers T66 §10), and π a cheap output map.
**Not supplied [U, accounting]**:
 1. Existence. The oracle finds a structure of size ≤ s if one exists; it does not create one. For general F the iteration F^{2^n} is PSPACE-complete (succinct reachability); P = NP does not imply P = PSPACE, so no theorem "H ⇒ every F has a small structure" can hold without a further collapse. Any contradiction must come from a RESTRICTED family (e.g. T = n^k, F poly-size) together with an existence argument.
 2. Global versus trajectory. The identity "h = Σ c_j f_j on all x" involves only poly-size circuits (f_j = g∘F^{j−1}, j ≤ d) **because the dimension is that of the whole state space (global d)**. A single-trajectory construction would need identities over times t ≤ T, i.e. circuits containing F^t (size t|F|): exponential. So the construction compresses exactly when the GLOBAL d is poly; T66 Thm 7.1b (r_g = max_x r_x ≥ every trajectory rank) is the relevant relation: the owner's oracle cannot see trajectory-only structure.
 3. Hierarchy. By T66 Thm 10.6 [H]: if a hierarchy-hard family had a structure of size T^{o(1)}, then H finds it and evaluates the family in time T^{1−ε}, contradicting the deterministic time hierarchy. So **under H hierarchy-hard families have NO small structure of any Σ2-checkable kind**. The contradiction therefore needs the opposite statement for one family (existence of a small structure), which cannot be obtained from the oracle alone.

## 6. Update (owner 2026-11-28, checked by the PI): module generators over R = Z/2^w close obligation O1 of §4 — no unit pivot needed [U + V]
**Construction (owner).** Replace "linearly independent functions with an invertible evaluation matrix" by "module generators f_1..f_k". Membership test for h: for a finite state set S ⊆ X put C_S = {c ∈ R^k : Σ c_j f_j(x) = h(x) ∀x ∈ S}. Pick c ∈ C_S, ask the oracle for x* with h(x*) ≠ Σ c_j f_j(x*); add x* to S. C_S = ∅ certifies h ∉ module (the state set S itself is the poly-size certificate of non-membership); "none" certifies h = Σ c_j f_j on all of X.
**Prop 6.1 (query bound) [U, checked].** Each nonempty C_S is a coset of K_S = {c : Σ c_j f_j(x) = 0 ∀x ∈ S}. If x* is a counterexample then C_{S∪{x*}} ⊊ C_S, and a coset contained in a coset of the same subgroup is equal, so K_{S∪{x*}} ⊊ K_S, an index ≥ 2, so |C| at least halves. |C_∅| = 2^{wk}; hence at most wk + 1 oracle calls per membership test. Closure: a generator is added exactly when its transform is not in the current module; the chain of modules is strictly ascending, so the number of generators is at most the length ℓ(V) of the final module V (ℓ(V) ≤ w·μ(V), μ = minimal number of generators = dim_{F_2} V/2V). **Total oracle calls ≤ ℓ(V)(w·ℓ(V) + 1).** The same halving argument works for every finite coefficient module (field F_q: k·log_2 q + 1 per test).
Then Φ(F(x)) = MΦ(x) with M over R (not unique), Φ(F^T x) = M^T Φ(x), g = e_1·Φ.

**Two honest limits of §6 (PI).**
 (i) The dimension that counts is ℓ(V), the length of the module generated by the orbit of the CHOSEN starting function. The choice of the starting generators is a search problem: for the counter with g = MSB (a bit-valued function) V is large (field dimension 2^{n−1}+1, T38 O2), with the numeric value ψ(x) = Σ x_i 2^i as starting generator the module has length O(w).  (ii) Existence of a small ℓ(V) for hierarchy-hard families is NOT proved (T68 Cor 3: any derivation from H proves not-H).

## 7. COMPRESS-J: closure of the representation class under the diagonal computation (PI, 2026-11-28) — an explicit obstruction and its repair target
**Prop 7.1 (universal step functions have exponential global dimension) [U, checked].** Let F_U be the step function of a machine that can run a counter-to-j program (config = (j, c, acc), j,c < 2^m, N = 2m+1 bits: acc set when c = j, else c ← c+1, acc absorbing) and g = [acc]. Evaluate the orbit functions h_k = g∘F^k at the states x_j = (j,0,0): h_k(x_j) = [k ≥ j+1], a triangular 0/1 matrix, so d_global ≥ 2^m = 2^{(N−1)/2} over EVERY field (T66 Thm 9.3 transfers); over Z/2^w the module length is likewise ≥ 2^m. [V] m = 2..5: rank 5, 9, 17, 33 (F_2). Any step function that can simulate programs with counters inside its configuration space (every universal machine, hence the diagonal machine D) therefore has exponential GLOBAL observable dimension, whatever ring or field is used.
**Consequence for the closure question [U].** The class C_r of computations with global observable dimension ≤ r(|F|) does NOT contain D (the diagonal machine that runs the construction and complements the result) for any polynomial r: closure under output complementation is irrelevant, because D already violates the dimension condition before complementation. The T61 self-reference route is therefore blocked in the global-module form for an explicit reason, not merely unresolved.
**Repair target (constructive, not yet achieved) [?].** Restrict the identity "h = Σ c_j f_j" to an invariant DOMAIN X_0 ⊆ X: X_0 must be (a) closed under F, (b) membership in X_0 decidable by a polynomial circuit (so that the oracle query "∃x ∈ X_0 ..." stays Σ1), (c) contain the trajectory of D on ⟨D⟩. The obstruction: the trajectory is a single exponentially long orbit (T67 §3.2); a poly-checkable invariant superset of it must be described by local tableau-type consistency, whose configuration set again contains arbitrary counters. The repair question is whether a poly-checkable F-invariant X_0 ⊇ trajectory exists on which the observable module of D has polynomial length. This is the exact form in which the self-reference route survives; it is equivalent in strength to T68's sandwich invariant (R ⊆ C ⊆ W, with C the characteristic set of X_0).

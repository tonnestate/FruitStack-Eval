# T71 — Recursive SAT certificates and uniform subroutine composition (owner order 2026-11-28; PI analysis). Tags [U] [H] [V] [?]; checks `verify-T71/sat_recursion.py`.
Notation: S(F,p) = [F restricted by the prefix p is satisfiable]; p0, p1 extend p by the next variable.

## 1. Recursion identity [U, V]
(R) S(F,p) = S(F,p0) ∨ S(F,p1), over F_2: q(F,p) = S + S0 + S1 + S0·S1 = 0; (B) p complete: S(F,p) = F(p).
**Prop 1.** (R)+(B) determine S uniquely (backward induction on the number of unassigned variables); any function T on prefixes satisfying them equals S. [V] n ≤ 5, 200 random 3-CNF: identity holds, and every single-value perturbation violates a local identity.
Remark: (R) is downward self-reducibility of SAT; it is a property of the TRUTH, not of any solver. A circuit S' of size s decides SAT_N iff it satisfies (R),(B) on all (F,p) with |F| ≤ N: a Π1 statement, checkable in polynomial time under H.

## 2. The uniform certificate relation [U, V]
C(F,p,b) :⇔ [S(F,p) = b]. Local closure conditions: (B) p complete: C ⇒ F(p) = b; (E) b = 1, p partial: C(F,p,1) ⇒ C(F,p0,1) ∨ C(F,p1,1); (U) b = 0, p partial: C(F,p,0) ⇒ C(F,p0,0) ∧ C(F,p1,0).
**Prop 2 (exact equivalence).** (a) Every relation C closed under (B),(E),(U) is contained in {S(F,p) = b} (backward induction); the greatest closed relation EQUALS {S = b} [V, same instances]. (b) A circuit C of size s that is closed AND contains the true pairs at p = ∅ (certifies every F in the correct direction) yields a circuit for SAT_N of size s + O(1): S(F) = C(F,∅,1). Conversely a circuit S for SAT_N gives the closed relation [S(F,p) = b] of size |S| + O(N).
So: compact uniform certificates for the exponentially large SAT check trees exist ⇔ SAT ∈ P/poly-type circuits exist. Under H the right side holds, hence the certificates exist; without H the statement is equivalent to its negation failing. This is an exact reformulation of H, not a consequence of H that was not already used: under H the "search tree" is a semantic object only, S evaluates in polynomial time.

## 3. Uniform subroutine composition [U, V]
Outer alternating computation O with SAT calls as atomic transitions (state z, formula F_z, successor chosen by the true result b). Expanded game E: at a call, Exists announces b; Forall chooses CHECK (play the SAT game (F,∅,b): for b = 1 Exists picks an assignment bit by bit, for b = 0 Forall does, final test F(p) = b) or CONTINUE with b.
**Thm 3 (semantic equivalence) [U, V].** Exists wins E from z iff Exists wins O from z. (⇐) announce the true b: CHECK is won by Prop 2(a)/(R), CONTINUE is won by the outer strategy. (⇒) a wrong b loses CHECK (b = 1 on an unsatisfiable F: Forall refutes by (U)-type play; b = 0 on a satisfiable F: Exists is exhibited a satisfying assignment). [V] 300 random acyclic games with SAT calls: winning regions of O and E coincide.
**Thm 4 (invariant transport) [U, V].** (i) If I is an inductive accepting invariant of O and C is a closed relation containing the true pairs (exists under H), then I' = I ∪ {(z,F,b): I(z) ∧ [S(F,∅) = b]} ∪ {check states C} is an inductive accepting invariant of E, of size |I| + |S| + poly, with one shared circuit S for all calls and a phase tag. (ii) Conversely, if I'' is an inductive accepting invariant of E, then J(z) = ∃b I''(z,F_z,b) is an inductive accepting invariant of O: inductivity of I'' on the check states forces b to be true (Prop 2(a)), so continuing with the announced b is continuing with the true b; |J| ≤ |I''| + O(1). (ii) needs no H. Hence existence of compact invariants of O and E is equivalent, uniformly over exponentially many calls with polynomial-size formulas (the same circuit serves every call).

## 4. What this buys, and what it does not [PI assessment]
- The outer-versus-expanded separation is genuine and now proved. But it separates nothing about hardness: under H, SAT is in P, so a SAT call is a polynomial-size sub-circuit of the transition function. The T68 accepting-subgraph certificate for D already treats such a transition as part of F. The growth of certificates in T68 never came from the SAT calls; it comes from the exponential clock and the alternation. Thm 4 therefore discharges an obligation that was never the bottleneck; the table row "SAT trees: constructed under H" is correct and equals the content of H itself (Prop 2).
- Remaining obligation, stated precisely: a poly-size inductive accepting invariant I_D for the OUTER control of D = the alternating poly-space machine M_D (configuration = clock, control, poly work tape, formulas as data) whose SAT calls are atomic. This is T68's C for M_D (O1–O4); T67 §7 shows that no global-module class contains it, T69/T70 show that masked-affine and chart classes contain it iff a small circuit invariant exists.
- Non-relativization: nothing in §1–§3 uses gate structure. (R),(B), the greatest-closed-relation argument and Thm 3/4 hold verbatim for SAT^A with any oracle A (SAT^A is downward self-reducible; formulas with oracle gates are admitted as data). The existence of S under H^A is the relativized hypothesis. So these results relativize and cannot remove the barrier of T68 Prop 4. Gate-level representations alone do not change this: a non-relativizing step must use a property of the circuit S that an oracle gate lacks AND must be needed for the invariant of M_D; (R) is such a property only in the weak sense that S evaluates three times on related inputs, which an oracle would also do.
- Candidate for a genuinely gate-level mechanism [?]: the residual q(F,p) = 0 as a polynomial identity in the wire variables of the circuit S evaluated at (F,p), (F,p0), (F,p1) (three copies of one circuit, Phi_S-chart of T70): a degree-2 relation between three copies. Whether a global residual for M_D can be assembled from this family with polynomial-size transport matrices M_i (T70 Prop 4) is not known.

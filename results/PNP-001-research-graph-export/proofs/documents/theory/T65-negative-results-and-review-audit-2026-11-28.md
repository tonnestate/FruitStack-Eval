## B. Early hypotheses (entries 26, 27, 35, 36, 37) and entry 52

- **27** (symmetry of clause tensors preserved under variable elimination): ill-defined as stated; for a clause (a∨b∨c) eliminating c against (c∨d) gives 1 + [a∨b]·d, symmetric only under a↔b: the full symmetry group is not preserved. Class: false as the natural reading, otherwise ILL-DEFINED.
- **35** (cut rank = minimum size of a clause set whose union implies a variable assignment): for F = Π_{i≤m}(x_i∨y_i) the cut rank across {x}|{y} is 2^m (Kronecker power of [[0,1],[1,1]], rank 2 each) but no clause set implies any assignment. REFUTED (counterexample m=2, rank 4).
- **36** refuted by 46 (valid).
- **37** (∃ satisfiable F, n ≤ 12, tensor rank > 2 "across any cut"): with "every cut" it is false for every F (a cut isolating one variable has a 2-row matrix, rank ≤ 2); with "some cut" it is trivially true ((x1∨y1)(x2∨y2), rank 4). Class: ambiguous quantifier; neither reading is a research result.
- **52** (grouping inclusion–exclusion terms needs exactly r_i classes): correct only for exact representation of the whole function f_F (T1 Satz 1). It is not a lower bound for computing the scalar #F: F = Π(x_i∨y_i) has cut rank 2^m, #F = 3^m. T1 §1 header and scope corrected in this audit (T1 now states the scope). Whether other documents used "rank = compression of the count" as a barrier: T10 (rank barriers) concerns arithmetic-circuit lower bound methods, not this statement; not affected.

**R4-2 (row 16768 / 17150).** The consequence "every PRG/correlation mechanism needs seed ≥ γ" does not follow from D5. Row 17150 (SEED-FLOOR) proves, for a distribution of support ≤ M, an AND of ⌊log₂M⌋+1 literals with bias ≥ 2^{−t}, hence log₂M ≥ log₂(1/δ) − 1; so the seed floor is a function of the REQUIRED error δ. In D4/AF δ = 2^{−r−2} because the decomposition sums over 2^r assignments of the r surviving reused gates. If the assignment map b_K: x ↦ (values of the K reused gates) has image A = Im(b_K) on the supports of both distributions, the decomposition C(x) = Σ_{a∈A} 1[b_K(x)=a]·F_a(x) has |A| terms, so the union-bound loss is |A| ≤ 2^K and the required error is δ ≈ 1/|A|, seed ≥ log₂|A| − O(1) — not ≥ K. Further, assignments a, a′ may be merged when F_a = F_{a′} on {b_K ∈ {a,a′}} (behavioural congruence, the same quotient construction as T38 O4*), so the cost is the number of residual-function classes q ≤ |A| ≤ 2^K. The seed floor is therefore log₂ q-type, and 17150's conclusion "covers ≤ N^{β+o(1)} reused gates" holds only when the image is full (2^r). Recovered: a reuse budget in terms of log₂|Im b_K| rather than γ. Not available: any bound on |Im b_K| for Gap-MCSP circuits; parity tree and prefix-parity circuits have full image (b_K onto), so no gain there. T38's theorem is for a different model (tagged aliases); the connection is the quotient, not a transferred theorem.
**R4-3 (row 11359) D1 one-step drop.** Fan-in-2 gates with arbitrary 2-input truth tables; x_i with fan-out 1 into g = o(x_i, y); set x_i = b. Then g becomes a constant, y or ¬y. Cases: (a) g not output: replace g by the constant/wire, adjust the truth tables of g's successors (arbitrary tables absorb ¬ and constants): size ≤ s−1. (b) g is output and y an internal gate: g's output is the constant, y or ¬y; complement y's table and those of y's other successors when ¬y: size ≤ s−1. (c) g output, y an input x_j: a minimal circuit has no dead gates, so s = 1 and f|_{x_i=b} ∈ {const, x_j, ¬x_j}. Free wires in the Lean model: inputs and constant false only (Wire = Fin n ⊕ Nat; getD default false). Then size(f|) = 1 = s exactly when f| ∈ {true, ¬x_j}, else 0. Repaired lemma: size(C|_{x_i=b}) ≤ s−1, except for s = 1 where it is ≤ s = 1 (f| = true or ¬x_j); in a model with free complemented inputs and both constants (M2) the bound s−1 holds without exception. The refuted instance g = x ∧ ¬y (s = 1, f| = ¬y) is exactly case (c). Hand proof; the Lean statement/proof for the repaired lemma is NOT yet written or kernel-checked.
**R4-4 (row 18299) selector coupling.** The implication "if the structure forced FL construction then P = L" shows the coupling would be strong; it is not a refutation (the row's own wording "refuted as a route" is withdrawn). Precise statement: let SEL be the function (C, x) ↦ (g_1(x),…,g_s(x)), the complete gate-value vector of a fan-in-2 circuit C. SEL ∈ FL (log-space transducer, write-only output tape) ⟺ P = L. (⇒) g_s is the circuit value; CVP is P-complete under log-space reductions, so CVP ∈ L ⇒ P = L. (⇐) P = L ⇒ CVP ∈ L; for j = 1..s run the L-algorithm on (C truncated at gate j, x) and write its bit, keeping only the counter j (O(log s) bits) and the subroutine's workspace; the output is never stored. [DED] This is an equivalence for the universal evaluation problem; for a FIXED uniform circuit family the equivalence is not claimed. Whether the selector of T60/18290 is exactly SEL is not verified here (the row states properties, not the function).

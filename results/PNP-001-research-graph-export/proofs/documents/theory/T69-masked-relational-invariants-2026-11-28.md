# T69 — Masked relational invariants (owner order 2026-11-28; PI analysis). Tags: [U] unconditional, [H] under H, [?] unproved, [R] recalled, [V] finite-checked (`verify-T69/masked_hull.py`).
Representation: partition M_1..M_k of F_2^n (circuit masks m_i, covering), affine sets H_i = {A_i z = b_i} (or empty), C(z) = OR_i [m_i(z) AND A_i z = b_i]. Certificate size Σ|m_i| + k·n².

## 1. Fixed partition: least inductive representable overapproximation
Let F: F_2^n -> F_2^n (poly circuit), Init. Algorithm: H_j = aff(Init ∩ M_j); while ∃z ∈ H_i∩M_i with F(z) ∈ M_j \ H_j: H_j := aff(H_j ∪ {F(z)}).
**Thm 1 [U, V].** (a) Each extension raises dim H_j by exactly 1 (empty counts as −1), so ≤ k(n+1) extensions; with one global violation query "∃z,i: C(z) ∧ ¬C(F z)" per round, ≤ k(n+1)+1 oracle calls; each query is Σ1 (SAT) and each hull update Gaussian elimination, so under H the whole run is polynomial [H]. (b) Correct: at termination Init ⊆ C and C inductive (no violation). (c) Least: let S = C(H') be ANY representable inductive set ⊇ Init (H' any tuple representing it). Induction over the steps: H_j ⊆ H'_j. Base: Init∩M_j ⊆ S∩M_j ⊆ H'_j. Step: z ∈ H_i∩M_i ⊆ H'_i∩M_i = S∩M_i, so F(z) ∈ S, F(z) ∈ M_j gives F(z) ∈ H'_j, hence aff(H_j ∪ {F z}) ⊆ H'_j. So the result is componentwise least and C(H) ⊆ S. (d) Confluence: the result does not depend on the order of counterexamples (it is the unique least element).
[V] n = 3, k = 2 and 3: random F, masks, Init; 25+3 instances; the least tuple coincides under 8 random counterexample orders each, and every one of the 52^k tuples of affine sets that is inductive contains it componentwise; max extensions 6 ≤ k(n+1).
**Limit (precision, not reachability).** The hull is closed under F on all of H_i∩M_i, not only on reachable states: C ⊇ Reach, in general strictly (Karr's loss). Minimality is within the class, not toward Reach.

## 2. Alternating computations
Nodes existential/universal; universal node: all successors F_u(z), u ∈ {0,1}; existential node: successor F_{σ(z)}(z) for a selector σ.
**Prop 2 [U, V].** For a FIXED σ Thm 1 holds verbatim (successor set instead of one successor): ≤ k(n+1) extensions, least, confluent. The least fixpoint is NOT monotone in σ and no greedy choice works: [V] n = 3, enumerating all 256 selectors, instances exist where a safe selector exists while σ ≡ 0 fails. Existence of a certificate (σ, H) with σ in a poly-size class is Σ2 (∃σ,H ∀z: Init ⊆ C, C closed under universal successors and selected existential successor, C ∩ Reject = ∅; the clock of T68 gives termination); verification is Π1; under H the search is polynomial (T68 Prop 2). The fixpoint per σ is a convenience for the inner step, not a replacement for the σ-search.

## 3. What Thm 1 does NOT give (no free lunch) [U]
**Prop 3.** The class contains every poly-size circuit invariant I: masks m_1 = I (A_1 = 0), m_2 = ¬I (H_2 = ∅). Hence existence of a small masked-affine certificate ⇔ existence of a poly-size circuit inductive invariant, i.e. exactly the T68 sandwich R ⊆ C ⊆ W. The affine part is vacuous when masks are arbitrary; all complexity sits in the mask circuits and in k. Efficient construction for a fixed partition is not evidence that an adequate partition exists (owner's warning confirmed). Under H, finding a certificate of given size is already polynomial (T68 Prop 2), so Thm 1 adds no complexity power; its use is structural: it isolates the choice of partition as the sole free parameter.
Counting [U]: circuits of size s number s^{O(s)}, so most invariants need exponentially many masks; polynomial k needs structure of the computation.

## 5. Composition and elimination [U for the identity, V for the counts]
**Prop 5 (exact piecewise-affine composition).** F_1 = (m_i, A_i, c_i), F_2 = (m'_j, A'_j, c'_j). F_2∘F_1 has pieces (i,j): mask m_i(z) ∧ m'_j(A_i z + c_i), map z ↦ A'_jA_i z + A'_j c_i + c'_j. Mask circuit size |m_i|+|m'_j|+O(n²); pieces multiply, equal (A,c) merge. [V] 200 random compositions, n = 5, k = 3: identity exact.
**Prop 6 (counter, shared relations over exponentially many blocks) [U + V].** F(x) = x+1 mod 2^n is piecewise affine with n+1 pieces (mask: low i bits 1, bit i 0; map: flip bits 0..i). For the dyadic block F^{2^t} (= +2^t) there are exactly n−t distinct affine maps (x ⊕ (x+2^t) takes n−t values), explicit formula checked for all x, n ≤ 10: the SAME relation family shifted by t, so the dyadic hierarchy F^{2^t}∘F^{2^t} = F^{2^{t+1}} costs O(n) pieces per level and all exponentially many steps are covered by n levels. For general T the number of distinct maps of +T is NOT polynomial: max over T = 2, 3, 5, 8, 13, 21, 34 for n = 2..8 (Fibonacci growth). So merging collapses pieces only along dyadic (self-similar) block lengths; binary recursion, not arbitrary iteration counts, is the form in which shared affine relations survive. This is the exact version of "same relations reused over exponentially many blocks".
**Elimination obstruction [U].** Composition is exact for functional (graph-of-map) interfaces. For a relational interface ∃y(R_1(x,y) ∧ R_2(y,w)) with y not an affine function of x on the piece, the projection of a mask m(y) is not of mask-and-affine form (image of a Boolean set under a projection). Eliminating such intermediate relational interfaces is exactly where an NP-oracle (SAT, i.e. H) is needed; T52 elimination handles the affine part only.

## 6. Non-relativizing ingredient (item 6) [partly U, then ?]
In a Boolean circuit every XOR gate is an affine relation z_g = z_a ⊕ z_b; every AND gate is affine UNDER a mask on one input: (a=1 ∧ z_g=b) ∨ (a=0 ∧ z_g=0). So the internal computation of the hypothetical SAT solver S (a concrete poly gate circuit under H) is a conjunction of local masked-affine relations of linear size; these hold at every call of S, i.e. they are persistent relations shared across all recursive blocks that call S (the phase mask selects the block). An oracle gate has no such relation: any argument that uses them is non-relativizing in the sense of T68 Prop 4 (P^A = NP^A, EXPTIME^A ≠ P^A for PSPACE-complete A), and every derivation of an adequate partition from H alone must use these internal relations.
[?] Not proved: that the invariant of the full alternating exponential computation of D factors into gate-local relations with polynomially many masks. Items 4 (indexed witness transport) and 5 (a concrete hierarchy-hard family) are open; the T67 §7 obstruction (counters in the configuration space force exponential GLOBAL dimension) applies with masks only through their count: a counter needs the dyadic partition, which is polynomial (§4), the open point is the interaction of the counter with the simulated program.

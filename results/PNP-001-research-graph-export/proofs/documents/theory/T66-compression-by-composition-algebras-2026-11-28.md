## 1. Toy setting, rigorous [U]
Representation Phi: step maps -> matrices over a ring, Phi(F2∘F1)=Phi(F2)Phi(F1). For an affine step x -> Ax+b on a d-dimensional state, F^T is computed from Phi(F)^T by repeated squaring: O(d^omega log T) operations, instance size poly(d) log T.
Generalization (Hankel/weighted automaton): an observation sequence y_t has linear recurrence of order d iff its Hankel matrix has rank d; then y_T costs O(d^omega log T) (Fiduccia). So "compressible by a composition algebra" = low Hankel rank of the OBSERVED behaviour (behavioural abstraction = minimal weighted automaton, Schuetzenberger).
Structural property responsible: a finite-dimensional faithful-on-the-orbit representation of the transition semigroup, i.e. the quotient of histories by behaviour is finite-dimensional.
Finite groups/monoids (Barrington-type) give depth compression to log T products but size stays T.

## 2. Hierarchy forces large Hankel rank [U]
If L in DTIME(T) \ DTIME(o(T/log T)) were decided by "build Phi(F) in setup s, then T-fold power", then s + d^omega log T = Omega(T/log T). So for hierarchy-hard L the observed behaviour has Hankel rank d >= (T/polylog)^{1/omega} unless the setup itself does the work. Linear compression alone cannot work for hierarchy-hard L (this is the unconditional negative side of the toy setting); H must enter through a NONLINEAR algebra.

## 3. Nonlinear algebra: relational composition, evaluated with H [D]
Phi(F) = the relation {(x,y): y = F(x)} as a circuit; Phi(F2∘F1)(x,z) = ∃m Phi(F1)(x,m) ∧ Phi(F2)(m,z); circuit size additive, so T-fold composition has size ~T (no compression by itself).
Blocking with alternation (Savitch/Williams style): split the T steps into b blocks, S = space (config size). Sigma_2 instance ∃ m_1..m_{b-1} ∀ i: Seg(m_i,m_{i+1}), size N' ~ b S + (T/b + S) polylog; b ~ sqrt(T/S): N' ~ sqrt(T S) polylog.
Cost under H (SAT in n^k): ∃-part is one oracle-free NP machine making ONE call to a coNP check of size N' => time N'^{k^2} (Sigma_2 in P with exponent k^2, accounting: one coNP decision N'^k, then Cook-Levin on a machine of that running time, then N'^{k*k}). [D, not independently checked]
Result [D]: SAT in DTIME(n^k) => DTISP(T,S) in DTIME((T S)^{k^2/2} polylog). For S = T^beta: exponent k^2 (1+beta)/2; < 1 iff k^2 < 2/(1+beta).
j-level alternation (chaining, the "multiplicity" analogue): b^{j+1} S = T, N' ~ S (T/S)^{1/(j+1)}, time N'^{k^{2j}} (each level squares the exponent: cost of chaining, to be recomputed exactly [?]).
So the construction compresses exactly as far as the boundary information b*S allows: instance size >= boundary data across time cuts.

## 4. Where it fails for the target [D]
The diagonal language in DTIME(T) \ DTIME(o(T/log T)) must simulate arbitrary machines of time o(T/log T), including those with space ~T; its own space is therefore ~T (beta ~ 1), N' ~ T, no compression.
Unconditional reason it cannot be repaired by choosing a small-space hard L: a space-S diagonalizer cannot diagonalize against machines with more space. So the obstruction is information across time cuts (crossing sequences / configuration size), the "information conservation" of earlier results, not the gate encoding.
Consistent with the known family of time-space tradeoffs [R] (Fortnow-van Melkebeek, Williams): they give speedups for small-space computation, not for the full class.

## 6. Dynamic observation spaces (owner Bingo 2.0, 2026-11-28) [U unless marked]
Koopman operator K f = f∘F on functions of the state; V_g = span{g, Kg, K^2 g, ...}. Equivalent objects: Hankel rank of the observation sequence over the whole state family, and the minimal weighted automaton of g.
**Theorem 6.1 (linear case).** If dim V_g = r with basis, K|V_g (r x r) and g's coordinates at x constructed, then g(F^T x) costs O(r^omega log T) field operations (repeated squaring). Not affine F needed.
**Theorem 6.2 (nilpotent case, no matrix powering).** If (K-I)^r g = 0 (index r), then for every T: g(F^T x) = sum_{j<r} C(T,j) ((K-I)^j g)(x) in any ring; mod p the binomials come from Lucas in O(r log T) ops. Proof: K^T = (I+(K-I))^T, binomial theorem for commuting operators, truncate by nilpotency. Checked exactly: the owner's system (r=3, T<30) and 200 random unipotent triangular Boolean systems on 5 variables (6 values of T each): 0 violations.
Owner example: p=ab, y'=y+p, z'=z+y over F2: z_T = z_0 + T y_0 + C(T,2) a b (verified for all 16 initial states, T<40; for T=1000000003, a=b=y0=1, z0=0 the formula gives y_T=0, z_T=0).
**Cost account (what 6.1/6.2 do NOT give).** Finite dimension != efficient construction. Needed: (i) closure/basis: g_j=(K-I)^j g as explicit objects, g_{j+1}=g_j∘F-g_j is a substitution; size can double in degree each step; (ii) index r; (iii) evaluating g_j at x. Total = r*(size of g_j, evaluation) + r log T. The compression is real only when r and size(g_j) are T^{o(1)}.
**Where the dimension explodes (exact).** Binary counter c' = c+1 on m bits (unipotent, triangular, Boolean): nilpotency index of the top bit is 2^{m-1}+1 (computed m=2..5: 3,5,9,17). So "compactly described, unipotent, triangular" does not imply small r; the index of a clock alone is ~ the period. Any T-step clock inside the computation costs r ~ T unless the clock enters as the parameter T (binary) rather than as state.
**Consequence for the target [U].** Combined with section 2: for a hierarchy-hard L the Koopman space of its universal step map restricted to the reachable family has dimension >= (T/polylog)^{1/omega}-type bounds when the setup is o(T); so Theorem 6.1/6.2 apply only after a transformation that REMOVES the information that makes the dimension large. The open mathematical question is the class of (F,g) where such a transformation (change of observation, T4 signed cancellation, T38 behavioural quotient, T52 elimination) keeps r small AND the language remains hierarchy-hard. No such class is known.
**Bingo 2.0 candidates.** CONSTRUCTION: V_g (T38 quotient) x T52 signed moments (exact one-sided counts) x T66 relational blocks. AMPLIFICATION: tensor/recursive composition of (F,g) with independent index bounds r_1 r_2; chaining cost k^{2j} (section 3). ## 7. Composition Koopman x Lucas: nilpotent compression is orbit-length reduction (2026-11-28, discovery mode, derived without targeting an obligation)
Object: comp:koopman-lucas-period-duality = Theorem 6.2 (nilpotent binomial expansion) composed with Lucas' theorem (C(T+p^k,j) = C(T,j) mod p for j<p^k).
**Correction 2026-11-28 (owner order): global operator period vs individual trajectory period.** The first version of Thm 7.1 attached the exact period p^ceil(log_p r) to the *global* index r of g and read it as the period of every trajectory. That is false per trajectory (2323 of 3690 random systems had trajectories with strictly smaller period than the global one). Corrected statements follow; all checked exactly (below).
Notation: a_T = g(F^T x), g: X -> F_p, K f = f o F, c_j(x) = ((K-I)^j g)(x) = (Delta^j a)(0) (forward differences, Delta^j a(0) = sum_i (-1)^{j-i} C(j,i) a_i).
**Theorem 7.1a (trajectory form) [U].** The following are equivalent: (i) a is purely periodic (from T=0) with minimal period a power of p; (ii) c_j(x)=0 for all large j. In that case with r_x = 1+max{j : c_j(x) != 0} (r_x = 0 if a = 0) the minimal period is exactly p^ceil(log_p r_x), and a_T = sum_{j<r_x} C(T,j) c_j(x).
Proof. (i)=>(ii): (E-1)^{p^e} = E^{p^e}-1 in characteristic p, so Delta^{p^e} a = 0, hence c_j = 0 for j >= p^e. (ii)=>(i): Newton expansion a_T = sum_{j<r} C(T,j) c_j is exact for all T >= 0 when c_j = 0, j >= r (Thm 6.2 applied along the orbit); Lucas gives C(T+p^e,j) = C(T,j) mod p for j < p^e; so a is purely periodic with period p^e, p^e >= r. Exactness: put s = p^{e-1} with e = ceil(log_p r) (e>=1). By Lucas C(s,i) != 0 mod p only for i in {0,s}, so a_{T+s}-a_T = sum_{j>=s} c_j C(T, j-s); the functions T -> C(T,i), i < p^e, are linearly independent over F_p (unitriangular on T = 0..p^e-1), and the coefficient of C(T, r-1-s) is c_{r-1} != 0 (distinct j give distinct i = j-s), so the difference is not 0: s is not a period; the minimal period divides p^e and is a power of p, hence = p^e. QED.
**Theorem 7.1b (global form) [U].** Let r_g = min{r : (K-I)^r g = 0 as a function on X}. Then max_x r_x = r_g, the sequence of functions T -> g o F^T has minimal period (as a function-valued sequence, i.e. lcm over x) exactly p^ceil(log_p r_g), and every individual trajectory has period dividing that, possibly strictly smaller (r_x < r_g).
**Theorem 7.2 (cycle structure; full function space only) [U].** K acts unipotently on the space of ALL functions X -> F_p iff F is a permutation all of whose cycle lengths are powers of p; then the nilpotency index of K-I on that space equals the longest cycle length exactly (shift on F_p[z]/(z^L-1) = F_p[z]/(z-1)^L when L = p^a). (Earlier text said "at most"; equality holds.)
**Theorem 7.2a (observation-dependent form) [U].** For a given g let V_g = span{g, Kg, K^2 g, ...}. K|_{V_g} is unipotent iff for every x the trajectory a_T = g(F^T x) satisfies (i) of Thm 7.1a. This does not force cycle lengths of F to be powers of p: F = 3-cycle on {0,1,2}, p = 2, g = 1 has (K-I)g = 0 although the cycle length 3 is no power of 2.
Checked (theory/verify-T66/per.py, syn.py; seeds fixed): 41,000+ trajectories over p = 2,3, random maps and permutations with p-power cycles: equivalence (i)<=>(ii) 0 violations (31,181 finite, 10,956 non-finite); exact period p^ceil(log_p r_x) 0 violations; global form 3690/3690; nilpotency index = longest cycle 400/400. **Consequences (derived properties, none aimed at an obligation).**
1. Compression by Theorem 6.2 is exactly reduction of T modulo the trajectory period p^ceil(log_p r_x) (< p*r_x): a T-step simulation becomes a (T mod p^k)-step one (cost r polynomial terms). Nothing beyond period reduction.
2. Genuine compression beyond periodicity needs a NON-nilpotent K on V_g whose minimal polynomial has multiplicative order much larger than its degree: LFSR-type dynamics. ## 8. Four-way composition: Hadamard rank bound x T52 signed elimination x inclusion-exclusion x Koopman observation space (2026-11-28, composition question 18404 / owner order)
Ingredients: (a) rank of a Hadamard (pointwise) product is at most the product of ranks, refined here to the symmetric square; (b) T52: signed extension functions sigma_i over F_3 with sigma_i^2 = indicator(D_i); (c) violation functions v_i = 1 - sigma_i^2 (indicator of the complement of D_i; inclusion-exclusion over violated conditions); (d) Koopman observation spaces (Thm 6.1/6.2).
**Theorem 8.1 (symmetric-square lift) [U; verified].** Let F: X -> X, K f = f o F on F-valued functions (F a field; here F_3), V a K-invariant subspace, dim V = r. Put W = span({1} u {fg : f,g in V}) and d = dim W. Then
(a) d <= 1 + r(r+1)/2 (and d <= |X|); (b) K W <= W; (c) for every h in W and every x in X the sequence a_t = h(F^t x) satisfies the linear recurrence given by the characteristic polynomial chi of K|_W (order d, coefficients in F): sum_j chi_j a_{t+j} = 0; hence a_t = 0 for t < d implies a_t = 0 for all t >= 0; (d) the threshold d cannot be lowered in general (d-1 zeros do not suffice).
Proof. (a) (f,g) -> fg is bilinear and symmetric, hence factors through Sym^2 V, of dimension r(r+1)/2. (b) K(fg) = (Kf)(Kg) because f -> f o F is a ring homomorphism, and K1 = 1. (c) Cayley-Hamilton on K|_W: chi(K)h = 0; evaluating K^t chi(K) h = 0 at x gives sum_j chi_j h(F^{t+j}x) = 0, a monic recurrence of order d; d consecutive zeros force all later terms to vanish. (d) Example below. QED.
**Corollary 8.2 (violation sequences) [U].** If sigma_i in V (i = 1..m) then v_i = 1 - sigma_i^2 in W, and "no violation of condition i during steps 0..T-1" holds iff v_i(F^t x) = 0 for t < min(T, d). All m conditions: m*d evaluations. Randomised single check: u = sum_i lambda_i v_i with lambda_i uniform in F_{3^k}; if any v_i is nonzero at some t then its first nonzero time t* < d (by 8.1), and u_{t*} != 0 with probability >= 1 - 3^{-k}; so d evaluations of u suffice with one-sided error 3^{-k}. Joint product prod_i (1-v_i) lies in the m-fold symmetric power of V, dimension C(r+2m-1, 2m): worthwhile only for bounded m; separate checks (m*d) are cheaper otherwise.
**Proposition 8.3 (linear-algebra form).** With a basis f_1..f_r of V and K f_j = sum_k M_jk f_k, the observation vector o_t = (f_j(F^t x))_j obeys o_{t+1} = M o_t and v_i(F^t x) = 1 - (c_i . o_t)^2 where sigma_i = c_i . f. So 8.1 says: a quadratic functional of an r-dimensional linear system is a linear functional of the r(r+1)/2-dimensional system Sym^2(M); consequently the check costs O(d r^2) = O(r^4) field operations after the data (M, c_i, o_0) are known; it is independent of T.
**Corollary 8.4 (explicit efficient case: affine dynamics) [U; verified].** F affine over F_3 (F x = Ax + b on F_3^n) and sigma_i given as reduced polynomials of degree <= D. The space P_{2D} of reduced polynomials (exponents <= 2) of degree <= 2D is K-invariant (substitution of affine forms does not raise degree), contains all v_i, and has dimension N(n,2D) = #{e in {0,1,2}^n : |e| <= 2D}. Hence absence of violations over T steps is decided by the first min(T, N(n,2D)) steps; the invariant space is explicit, so no search is needed. Example D = 1: N(n,2) = 1 + n + n(n+1)/2.

## 9. Koopman x Hankel x Berlekamp-Massey x Bostan-Mori: exact cost of scalar-observation compression; the halting observation (2026-11-28)
Setting: F: X -> X, phi: X -> K scalar observation (K a field), a_t = phi(F^t x), rank(a) = rank over K of the infinite Hankel matrix H_ij = a_{i+j}. Labels: [U] proved here, [R] recalled standard, [H] consequence of H, [?] open.
**Fact 9.0 [R, Kronecker].** rank(a) = r < infinity iff sum_t a_t z^t = N(z)/D(z) with D(0) = 1, gcd(N,D) = 1 and r = max(deg D, deg N + 1); equivalently the shortest generalised recurrence (nilpotent pre-period allowed) has order r. If phi lies in a K-invariant space V of dimension r_V (sec. 6) then rank(a) <= r_V (Cayley-Hamilton), but r_V is NOT needed by the algorithm below.
**Theorem 9.1 (reconstruction from 2r observations; cost) [U given the cited algorithms].** Promise: rank(a) <= r. Then (i) Berlekamp-Massey on a_0..a_{2r-1} returns the unique minimal recurrence generating the whole sequence (Massey: two recurrences of orders L, L' that agree on L+L' terms are equal; here L, L' <= r); (ii) a_T = [z^T] N/D by Bostan-Mori, valid in every characteristic (in characteristic 2, Q(-z) = Q(z) and V = Q^2 is even, the recursion is unchanged). Cost: 2r*C (the first 2r observations from ONE sequential simulation, C = amortised transition + observation cost) + O(M(r) log r) (BM by half-gcd, Brent-Gustavson-Yun) + O(M(r) log T) (Bostan-Mori), i.e. **O(rC + M(r)(log r + log T))**, M(r) = cost of multiplying degree-r polynomials over K (r log r loglog r field operations; multitape bit cost times the cost of a field operation). No Koopman basis, no matrix, no dimension of the state space enters; r = Hankel rank of the scalar sequence is all that is used. Checked: BM on 2r terms + Bostan-Mori = matrix-power simulation (p = 2,3,5; r <= 31; T up to 10^6; naive polynomial product, so correctness only) in theory/verify-T66/hankel_bm.py.
**Precondition audit (nothing is assumed from existence).**
1. Promise. The algorithm is correct only if rank(a) <= r. If the promise is false BM still returns a recurrence of order <= r matching the 2r terms and the output is silently wrong; checking the recurrence on terms 2r..T costs T. The promise is a certificate that must come from outside (structure of F, e.g. sec. 8 Cor 8.4 or an affine/LFSR description).
2. Field. rank depends on K (an F_2-rank can be smaller or larger than the Q-rank); the promise must be stated for the field in which BM runs; a decision bit is read from a_T in K.
3. Observation access. phi must be readable from the configuration in O(1) amortised (a state bit or the scanned cell), otherwise C grows; the sequence must be generated by in-place sequential simulation (restarting costs t per term).
4. Uniformity. One algorithm A(<F,phi>, x, T, r); the family of reductions is uniform in the code. r is an INPUT.
5. Model. Time-hierarchy statements are for multitape TMs; polynomial multiplication in O(r log r loglog r) bit operations is available there (Schoenhage-Strassen) [R]; RAM costs differ by the Hennie-Stearns logarithmic factor.
**Theorem 9.2 (no free promise; hierarchy accounting) [U modulo the multitape time hierarchy [R]].** Let rho be a uniform algorithm that on (<M>, x, 1^T) outputs r with rank(a^{M,x}) <= r for an observation a determining M(x) from a_T, in time t_rho. Then M(x) is computed in time t_rho + O(rC + M(r)(log r + log T)). Since the diagonal language L is in DTIME(T) and not in DTIME(o(T/log T)), on infinitely many inputs t_rho + rC + M(r)(log r + log T) = Omega(T/log T): either the certified rank is r = T^{1-o(1)} (up to polylog) or computing the promise costs T^{1-o(1)}. Proof: the displayed algorithm is a decider for L. QED. (This is T66 sec. 2 with the promise cost made explicit.)
**Theorem 9.3 (halting observation, exact) [U; verified].** For a_t = [t >= tau] (tau in N) the infinite Hankel matrix has rank exactly tau+1 over every field (tau = infinity, never halting, gives rank 0).
Proof. Row i is the 0/1 vector 1_{j >= tau-i} for i < tau and the all-ones vector for i >= tau. So the row space is spanned by e_s = 1_{j >= s}, s = 0..tau (s = 0 from every row i >= tau). The (tau+1) x (tau+1) submatrix on rows and columns 0..tau is the anti-triangular matrix [i+j >= tau] with ones on and below the antidiagonal: its determinant is +-1, non-zero in every field. Hence rank >= tau+1, and rank <= tau+1 by the spanning set. QED. Checked exactly over Q and F_2,3,5,7,13,101 for tau <= 30.
**Generalisation 9.3a [U; verified on 200 random cases].** If a_t = c for t >= tau and a_{tau-1} != c (tau = length of the pre-period), then rank = tau+1 when c != 0 and rank = tau when c = 0. Proof via Kronecker: with b = a - c and B(z) = sum_{t<tau} b_t z^t (deg B = tau-1, b_{tau-1} != 0) we get N = B(1-z) + c, deg N = tau (leading coefficient -b_{tau-1}), N(1) = c; for c != 0 gcd(N, 1-z) = 1 and D = 1-z, so rank = max(1, tau+1) = tau+1.
**Consequences.** (a) Every recurrence of the halting observation has order >= tau+1; Theorem 9.1 needs >= 2(tau+1) observations, i.e. simulation beyond the halting time: for the natural halting observation the compression of 9.1 is EMPTY (cost >= tau*C), exactly. (b) The limitation belongs to the scalar linear-recurrence representation of this one sequence: it is a property of the sequence a, independent of coordinates, but not a lower bound on the cost of computing a_T. Sec. 10 gives exact counter-examples (a counter machine halts at tau = 2^n, rank 2^n+1, a_T in O(n log T) arithmetic; a pulse of period 2^n-1 has rank exactly 2^n-1). (c) Time-localised events (a pulse in a period, an absorbing change) are invisible to recurrence methods by exactly the number of time points they must separate.

## 10. Nonlinear coordinate change: decoupling, towers, rank-versus-conjugacy separation, and the exact place where the hierarchy enters (2026-11-28; owner construction, extended)
**Theorem 10.1 (shear decoupling; owner's identity) [U; verified].** Let K be a ring, A, B matrices over K, h an arbitrary map. The system u_{t+1} = A u_t, v_{t+1} = B v_t + h(A u_t) - B h(u_t) satisfies w_t := v_t - h(u_t), w_{t+1} = B w_t; hence u_T = A^T u_0 and v_T = B^T (v_0 - h(u_0)) + h(A^T u_0). Proof: w_{t+1} = v_{t+1} - h(u_{t+1}) = B v_t + h(A u_t) - B h(u_t) - h(A u_t) = B (v_t - h(u_t)). QED. Time-dependent matrices A_t, B_t (input-driven systems, products of matrices in the order of the input) satisfy the same identity: v_T = B_{T-1}..B_0 (v_0 - h(u_0)) + h(A_{T-1}..A_0 u_0). In conjugacy form F = Phi^{-1} o G o Phi with Phi(u,v) = (u, v - h(u)), G = diag(A,B); Phi and Phi^{-1} are the elementary (triangular) automorphisms. Cost of F^T x: 2 evaluations of h plus O((n^omega + d^omega) log T) (or two automaton evaluations). Checked on a random table h over F_7, T = 2000 (hankel_bm.py).
**Proposition 10.2 (towers; recursive composition) [U].** Depth-k tower: coordinates (u, v_1, .., v_k), v_i' = B_i v_i + h_i(u', v_1', .., v_{i-1}') - B_i h_i(u, v_1, .., v_{i-1}), i.e. every coupling function depends on the earlier (already decoupled) coordinates only. With w_i = v_i - h_i(u, w_1 + h_1, ..) recursively all w_i evolve linearly, and v_i(T) = B_i^T (v_i(0) - h_i(x_0)) + h_i(x_T) where x_T collects the earlier coordinates at time T. Cost O(k d^omega log T) + sum of the cost of the h_i. Elementary triangular automorphisms compose, so the class is closed under composition of conjugations.
**Proposition 10.3 (cohomological form) [U / R].** For a skew product (u,v) -> (A u, B v + c(u)) the T-th fibre value is B^T v_0 + sum_{t<T} B^{T-1-t} c(A^t u_0); the sum telescopes to h(A^T u_0) - B^T h(u_0) iff c = h o A - B h (c is a coboundary). For polynomial c of degree <= D, A diagonalisable over an extension and B = diag(beta_j): coefficient equations (lambda^alpha - beta_j) h_{alpha,j} = c_{alpha,j}; a resonance lambda^alpha = beta_j with c_{alpha,j} != 0 produces the secular term T beta_j^{T-1} c_{alpha,j} (T read in the characteristic). This is the Poincare-Dulac resonance condition over finite fields [R, standard theory; novelty not claimed]; the carried space has dimension C(n+D, D) + d, the same finite Carleman closure as Cor 8.4, so no new compression for polynomial couplings; the gain is for NON-polynomial h, for which Carleman linearisation is infinite.
**Theorem 10.4 (separation of Hankel rank and computation cost) [U; exact].** Let A in GL_n(F_2) be primitive (order P = 2^n - 1), u_0 != 0, e != 0 a fixed state, h(u) = [u = e] (an n-bit AND with literals, O(n) gates) and a_t = h(A^t u_0). Then a is a periodic pulse with exactly one 1 per period at some t_0 in [0,P), its generating function is z^{t_0}/(1 - z^P) in lowest terms, so **rank(a) = P = 2^n - 1 over every field** (Kronecker, D = 1 - z^P, deg N + 1 = t_0 + 1 <= P); while a_T = [A^T u_0 = e] is computed with O(n^omega log T) operations. Hence BM/Bostan-Mori needs r = 2^n - 1 (2r > T for T < 2^n) while the conjugacy/arithmetic route costs poly(n, log T): an exponential separation for one and the same sequence. The coupled version (u, v) with v_{t+1} = v_t + h(A u_t) + h(u_t) over F_2 has v_T = v_0 + h(u_0) + h(A^T u_0) by Thm 10.1 and a v-observation of rank >= P - 1. Illustration (not an enumeration): n = 12, h = AND of 6 state bits (algebraic degree 6): linear complexity of h(u_t) = 2509 versus 12 for a linear observation; the Key/Groth upper bound sum_{i<=6} C(12,i) = 2510 [R] is attained to within 1.
**Proposition 10.5 (nonlinear output map) [U].** If l_1..l_k are linear observations of total joint rank r (K-invariant space of dimension r) and theta any function computed in time c_theta, then theta(l_1(F^T x), .., l_k(F^T x)) costs O(r^omega log T + c_theta), independent of rank(theta o l). The pulse and the counter-halting event are of this form (theta = threshold/equality test of a linear state). The Hankel-rank method is a sufficient route only; "linear observation + cheap output map" is strictly stronger.
**Theorem 10.6 (where the hierarchy enters; no escape by representation alone) [U modulo the hierarchy; the bound in (c) is H-conditional].** Call a representation of (M, x, T) a triple (Phi, G, Psi) of size s with M's configuration after T steps equal to Psi(G^T(Phi(x))), the maps Phi, Psi computed in time s and G^T in time tau. (a) The cost is s + tau + t_find, where t_find is the time to find the representation from (<M>, x, 1^T). (b) By the multitape hierarchy, for the diagonal language t_find + s + tau = Omega(T/log T) on infinitely many inputs: representation by coordinate changes does not avoid the hierarchy; it relocates the cost into s, tau or t_find. (c) [H] The check "F = Psi^{-1} G Phi-conjugate" is a forall-statement over configurations, the search an exists-forall (Sigma_2) problem; under H it takes time poly(s, S)^{kappa^2} (kappa = SAT exponent), so s + S >= T^{1/kappa^2 - o(1)}: under H every conjugacy/skew-product compression of a hierarchy-hard family has representation size polynomial in T. (d) Consequently the coordinate-change route reduces the compression gap to the same question as before: an UNCONDITIONAL family of hierarchy-hard computations with representation size T^{o(1)} (equivalently, small certificates for the outcome). It is not circular only for special families (clocks, counters, LFSR-driven events, coboundary couplings), where Thm 10.1-10.5 give exact, cheap evaluation although every scalar Hankel rank is exponential.

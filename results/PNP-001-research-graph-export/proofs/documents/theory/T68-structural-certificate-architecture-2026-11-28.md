# T68 — Compact accepting-subgraph certificates (owner architecture 2026-11-28): what it proves, the circularity of the open link, the relativization barrier, and the non-circular research directions (PI)

Status: derivation. P != NP is NOT claimed. Labels: [U] unconditional, [H] under H (uniform P = NP), [?] unproved, [R] recalled (not opened), [V] finite check in `theory/verify-T67/`.
Checked by the PI only (same model family as the proposer); independent verification pending. Shared context for Claude and Codex.

## 1. Setting (owner)
L fixed in EXPTIME \ P (time hierarchy [U]). By Chandra–Kozen–Stockmeyer (APSPACE = EXPTIME [R]) L is decided by an alternating machine M of polynomial space with branching <= 2. Add a polynomial-bit clock counting to 2^{p(n)}: the configuration graph G_x is an acyclic AND/OR graph, configurations have poly bits, G_x has up to 2^{p(n)} nodes.
Certificate: a Boolean function C(z) (z = configuration with clock) with (1) root in C, (2) OR node in C has a successor in C, (3) AND node in C has all successors in C, (4) terminal in C accepting.

## 2. Results
**Prop 1 (soundness and completeness) [U, induction on remaining depth; V `certificate_soundness.py`, 300 random AND/OR DAGs].** (a) If C satisfies (1)–(4) then the root accepts and C ⊆ W, where W is the set of accepting (winning) configurations. (b) W itself satisfies (1)–(4) whenever the root accepts. Hence a certificate EXISTS for every accepting x (as an exponentially large set); the question is only its circuit size.
**Prop 2 (complexity of the certificate predicate) [U].** For a circuit C of size s, "C is a certificate" is a Pi_1 statement (∀z, one-step check with <= 2 successors, polynomial in s and the configuration length). "∃ C of size <= s(n) that is a certificate for x" is therefore Sigma_2^P, and **"every x ∈ L has a poly-size certificate" implies L ∈ Sigma_2^P** (guess C, verify with ∀z).
**Cor 3 (the open link is the whole theorem) [U + hierarchy].** Let P* := "every x ∈ L has a certificate of polynomial size". Then (i) P* ⇒ L ∈ Σ2P. (ii) H ⇒ Σ2P = P, hence H ∧ P* ⇒ L ∈ P, which contradicts L ∉ P. So H ∧ P* is inconsistent — the final steps of the owner's chain are correct. But therefore **any derivation of P* from H is already a proof of ¬H**; the "open link" is not an intermediate lemma but the theorem itself. Unconditionally, P* for an EXPTIME-complete L would give EXPTIME ⊆ Σ2P ⊆ PSPACE, i.e. EXPTIME = PSPACE, which is open (the owner's remark).
**Prop 4 (relativization barrier) [U modulo BGS, hierarchy relativizes, R].** Let A be a PSPACE-complete oracle: P^A = NP^A = PSPACE^A (Baker–Gill–Solovay). The time hierarchy relativizes, so EXPTIME^A ≠ P^A. CKS (APSPACE = EXPTIME) and Props 1–2 relativize. Hence for L ∈ EXPTIME^A \ P^A the hypothesis H^A (P^A = NP^A) holds while P*^A fails (P*^A would give L ∈ Σ2^A = P^A). **No argument that uses H only through "SAT is solvable in polynomial time" as a black box (or any property that holds relative to every oracle) can derive P*.** The derivation of P* must be non-relativizing: it has to use that the algorithm A is itself a uniform polynomial-time computation whose code/transcripts are objects of the argument. [This is the same barrier that makes every T61-type "use A as a subroutine" argument insufficient unless it uses A's own computation structure.]

## 3. What the architecture does give (honestly)
1. A clean reformulation of the target: **find a mathematical reason why, under H, the winning set of one fixed hierarchy-hard alternating game has an inductive invariant of polynomial circuit size.** Note the slack that the exact-compression architectures (T61/T62, T66 Thm 10.6) do not use: C needs only the sandwich R ⊆ C ⊆ W (R = configurations reachable under SOME winning strategy), not W itself. Exact compression of W (or of F^T) has size at least T^{1/κ²} under H (T66 Thm 10.6); the sandwich is weaker and is exactly the inductive-invariant / Craig-interpolant relaxation (IC3-type invariants, feasible interpolation [R]). Whether this relaxation escapes Thm 10.6 is the first obligation.
2. A non-relativizing lever that H DOES supply: the run of A on a coNP instance is a poly-size certificate of unsatisfiability. Under H every Π1 statement "∀z R(x,C,z)" has a poly-size checkable transcript (A's run, length N^κ). Hence under H the pair (C, transcript of A on the check of C) is a poly-size NP-witness for x ∈ L whenever C exists — consistent with L ∈ Σ2P = P, and again requires C.
3. A usable sub-structure: value iteration W_{t+1} = Φ(W_t) (Φ the one-step AND/OR operator) gives circuits with s_{t+1} <= 2 s_t + O(1) (W_t is used on two successor arguments), i.e. tree doubling; minimisation by Σ2-search (poly-time under H) turns this into the compression profile m(t) = min circuit size of W_t. The profile of EXACT value functions is bounded below by the hierarchy (Thm 10.6); the profile of SANDWICH invariants I_t (R_t ⊆ I_t ⊆ W_t) is not.

## 4. Research obligations (constructive; no enumeration, no isolated bound)
O1. Decide whether, for a concrete small alternating game family with exponentially long plays (counters + LFSR + coboundary-shear structure from T66 §10, built so that R is a small structured set), a poly-size sandwich invariant exists although W is large, and extract the mechanism (which identity makes R small?).
O2. Local-to-global composition: invariants I_1 (levels [0,t/2]) and I_2 ([t/2,t]) with the interface predicate chosen inside the slack R_{t/2} ⊆ I ⊆ W_{t/2} (assume–guarantee). Prove or refute that the description size of the composed invariant does not grow with the number of rounds, using T38 equivalent-state merging, T52 elimination, T66 composition. This is the owner's "local certificates composing without keeping intermediate states".
O3. Non-relativizing use of H: build C from A's own transcripts (proof-carrying invariants); identify any property of A (uniformity, self-reducibility, the circuit of A as an instance of SAT) that fails relative to the PSPACE oracle and could force P*.
O4. Prior art: succinct circuit problems and games (Papadimitriou–Yannakakis, Galperin–Wigderson), Σ2-strategies, feasible interpolation (Krajíček), IC3/PDR invariants, hierarchy/relativization surveys; record which of O1–O3 is already a known barrier.

## 1. Setting (owner's Findings D, E, §8 made exact)
X finite; actions A; δ_a : X → X; words act by δ_{a1…ak} = δ_{ak} ∘ … ∘ δ_{a1}; observable F : X → 𝔽_q.
Koopman operators K_a f = f ∘ δ_a are LINEAR on 𝔽_q^X even when δ_a is nonlinear.
Observable space V_F = span{F ∘ δ_w : w ∈ A*} = the smallest subspace containing F and closed under all K_a (owner's §8 object).
d = dim V_F. Behavioural equivalence x ~ x' ⇔ F(δ_w x) = F(δ_w x') for all w; N = |X/~| (exact quotient size, Finding D).
Observation matrix O[x, w] = F(δ_w x); V_F is its column space, so d = rank O (the Hankel/Carlyle–Paz–Fliess rank: classical).

## 3. Proved lemmas
Lemma O1 (sandwich). log_q N ≤ d ≤ N.
Proof. Every f ∈ V_F is constant on ~-classes, so V_F embeds into 𝔽_q^{X/~}: d ≤ N. For a basis f_1..f_d the map x ↦ (f_i(x))_i is
constant on classes and injective on classes (equal values ⇒ all of V_F agrees ⇒ all F∘δ_w agree ⇒ x ~ x'): N ≤ q^d. ∎
The lower bound is attained by affine systems (Finding E). The next theorem shows the upper end is reached up to a factor 2 by a
NONLINEAR system with a trivial decision problem.

Theorem O2 (nonlinear test system: binary counter). X = {0,1}^n ≅ Z_{2^n} (binary digits), one action δ(x) = x + 1 mod 2^n (over 𝔽_2
nonlinear: the carry gives x_2' = x_2 ⊕ x_1 x_0, …), F = most significant bit, q = 2. Then d = 2^{n−1} + 1 and N = 2^n.
Proof. Identify f : Z_{2^n} → 𝔽_2 with Σ_x f(x) y^x in R = 𝔽_2[y]/(y^{2^n} − 1); f∘δ corresponds to multiplication by the unit y^{−1},
so V_F is the ideal generated by g = Σ_{x=2^{n−1}}^{2^n−1} y^x = y^{2^{n−1}} (1 + y + … + y^{m−1}), m = 2^{n−1}. Over 𝔽_2,
y^{2^n} − 1 = (y + 1)^{2^n} and 1 + … + y^{m−1} = (y^m − 1)/(y − 1) = (y + 1)^{m−1}. Hence V_F = ((y+1)^{m−1}) in 𝔽_2[y]/((y+1)^{2^n}),
of dimension 2^n − (m − 1) = 2^{n−1} + 1. For N: the sequence j ↦ F(x + j) is the translate by x of a square wave with exactly one 0→1
step, so distinct x give distinct sequences: N = 2^n. ∎ Computation (two routes: GF(2) rank of the 2^n translates; class count):
d = 2^{n−1}+1 and N = 2^n for every n = 2..12. VERIFIED.
Resource accounting. Direct: F(δ^T x) = top bit of x + T mod 2^n — O(n + log T) bit operations. Via V_F: representation size
d = 2^{n−1}+1, transition = multiplication by y^{−1} (O(d)), extraction = evaluation at x (O(d)): exponentially WORSE than the direct
computation. Note the ring dependence: over Z_{2^n} the dynamics is affine (x ↦ x+1) and the observable is the nonlinear one; over 𝔽_2
the dynamics is nonlinear. Linearity, like state counts (Finding A), is representation-dependent.

Theorem O3 (small observable space, hard evaluation). For all large n there is a bijection φ of {0,1}^n such that the system
δ_a = φ^{−1} ∘ L_a ∘ φ (L_a any linear maps) with F = (φ(x))_1 has d ≤ n + 1, while F itself has fan-in-2 circuit complexity
> 2^n/(4n).
Proof. F ∘ δ_w = e_1^T L_w φ, so V_F ⊆ {v^T φ(x) : v ∈ 𝔽_2^n} + 𝔽_2·1: d ≤ n + 1. There are C(2^n, 2^{n−1}) ≥ 2^{2^n − n} balanced
functions; circuits with s gates number ≤ (16(s+n)²)^s, which for s = 2^n/(4n) is 2^{(1/2 + o(1)) 2^n} < 2^{2^n − n}. So some balanced
g needs more than 2^n/(4n) gates; complete g to a bijection φ (fibres of g have size 2^{n−1}; enumerate each fibre with the remaining
n − 1 coordinates). ∎ (Nonconstructive, Shannon counting.)

Corollary O2/O3 (independence). The dimension of the exact observable space neither upper-bounds nor lower-bounds the cost of exact
decision extraction: exponential d with linear-time decisions (O2), d ≤ n + 1 with exponential circuit complexity (O3).
Hence "compact V_F" and "hard decision" are independent properties; the cost that matters is evaluating a basis of V_F at the
initial state — the original computation.

Lemma O4 (alias tags: exactness forces Nerode information at EVERY step). Let h : X → Y be any abstraction and τ : X → Tags a tag such
that the pair (h, τ) satisfies the exact-quotient criterion of Finding D (equal pairs ⇒ equal F and equal pairs after every action).
Then (h, τ) refines ~, so |(h,τ)(X)| ≥ N and some h-fibre carries ≥ N/|h(X)| distinct tags: tags need ≥ log2(N/|h(X)|) bits. The
bound is attained by τ = behavioural class. **[Correction 2026-11-28: the lower bound is right for static distinguishability. "Attained by τ = behavioural class" is not established: the bound log2(N/|h(X)|) uses the AVERAGE fibre; counterexample 4 classes with fibres {1,2,3},{4}: bound 1 bit, but separating 3 classes inside one fibre needs ⌈log2 3⌉ = 2 bits. Static distinguishability inside a fibre (≥ log2 of the maximum number of classes in a fibre is a valid lower bound) is a different question from a transition-compatible abstraction, i.e. a pair (h,τ) whose combined state has well-defined dynamics under all actions; the additional information that this closure needs is not characterized by either quantity and is not proved here.]**  
Proof. By induction on |w|, (h,τ)(x) = (h,τ)(x') ⇒ (h,τ)(δ_w x) = (h,τ)(δ_w x') ⇒ F(δ_w x) = F(δ_w x'). ∎

**Theorem O4\* (exact minimal tag length; replaces the "attained" claim, 2026-11-28; statement from the owner audit, proof re-derived and brute-force checked).** Let (X, δ_w) be a transition system, F the observable, h an abstraction.
Define x ≡_h y :⇔ ∀ words w: F(δ_w x) = F(δ_w y) and h(δ_w x) = h(δ_w y). For a ∈ h(X) let q_a = number of ≡_h-classes inside the fibre h^{-1}(a) (≡_h refines h, taking w empty). A *transition-compatible exact representation*
is a tag τ : X → {0,1}^b such that (h,τ)(x) = (h,τ)(y) ⇒ F(x) = F(y) and (h,τ)(δ_a x) = (h,τ)(δ_a y) for every action a. Then **b_min = ⌈log₂ max_a q_a⌉.**
*Proof.* (≥) By induction on |w|, equal (h,τ) ⇒ equal (h,τ)∘δ_w ⇒ equal F∘δ_w and h∘δ_w, so equal (h,τ) ⇒ x ≡_h y. Hence distinct ≡_h classes in one fibre need distinct tags: 2^b ≥ q_a for all a.
(≤) ≡_h is a congruence: x ≡_h y ⇒ δ_u x ≡_h δ_u y, because for every w the word uw is a word. Number the classes inside each fibre 0..q_a−1 (numbers reused across fibres) and let τ(x) be the binary number of its class: (h,τ) identifies x with the class of x, which determines F (w empty) and, by the congruence, the class of every successor, hence its (h,τ). ∎
*Relations.* Since ≡_h refines the Nerode relation ~ of F and the static fibre-distinguishability, b_min ≥ ⌈log₂ max_a(#Nerode classes in the fibre)⌉ ≥ ⌈log₂ ⌈N/|h(X)|⌉⌉: the previous lower bounds are all valid, none is attained in general (counterexample above: fibres {1,2,3},{4} give average bound 1, b_min ≥ 2), and the corrected O4 line "tags need ≥ log2(N/|h(X)|) bits" is the weakest of the chain.
*Check:* 300 random finite systems (n ≤ 6 states, 2 actions, random F and h): minimal b by exhaustive search over all tags equals ⌈log₂ max q_a⌉ in 300/300 cases.
*Existence vs cost:* the theorem is an existence/size statement. Computing the classes ≡_h is partition refinement on the transition system (Moore, O(|actions|·|X|²) worst case; Hopcroft O(|actions|·|X| log|X|)) in time polynomial in |X|; it is NOT polynomial in the size of a compressed description of X when X is exponentially large. The construction cost is therefore a separate open question (it is exactly the cost of minimising the abstraction-refined automaton).
Without tags at intermediate steps a final checksum cannot restore exactness: the existential quotient (y →_a y' iff some x ∈ h^{−1}(y)
has h(δ_a x) = y') over-approximates. Counterexample (explicit): X = {0,1,2,3}, δ: 0↦1, 1↦1, 2↦3, 3↦3, F = [x = 3], h merges 1 and 2.
Concretely 0 never reaches 3 (reject), but the abstract system has the path h(0) → {1,2} → 3 (accept): a spurious path; no function of
the final abstract state can tell the two apart.
Consequence for the proposed Alias-Block Transition System: it is exact iff its tags carry the behavioural class (Nerode information)
at every step; then it is not smaller than the exact quotient. The asserted "exponential lower bound on tag size" is TRUE exactly when
N/|h(X)| is exponential — a property of the system, proved by O4, not a complexity lower bound (see O5).

Lemma O5 (finite horizon: dimension is free). For a deterministic single-action system, a set S of initial states (inputs) and
horizon T, V_T = span{(F ∘ δ^j)|_S : 0 ≤ j ≤ T} has dimension ≤ T + 1 and contains the decision F ∘ δ^T|_S. In particular every
language decided in time T has an exact observable space of dimension ≤ T + 1 (even span{1_L} of dimension 1 suffices for the final
decision). So no dimension or quotient-size statement over a single run can separate P from NP; only the cost of EVALUATING the basis
at the input can, and that is time/circuit complexity (T36 Lemma N). ∎

## 3b. Positive result: degree-bounded closure (PI, 2026-11-17, second pass after owner re-brief)
Setting: X = 𝔽_2^n, actions δ_a given coordinatewise in algebraic normal form (ANF), degree ≤ r, ≤ s monomials per coordinate;
F given in ANF. 𝒫_D = multilinear polynomials of degree ≤ D, M_D = dim 𝒫_D = Σ_{i≤D} C(n,i).
Algorithm CLOSE(F, {δ_a}, D): queue ← [F]; echelon basis keyed by leading monomial. Pop f; if deg f > D stop with output
"V_F ⊄ 𝒫_D, witness f"; reduce f against the basis; if non-zero, add it and enqueue K_a f = f∘δ_a (ANF substitution) for every a.
Lemma O6 (exact, constructive, compositional). (i) A witness f lies in V_F, so the stop answer is correct. (ii) Otherwise the output
basis g_1..g_d spans exactly V_F. (iii) The run makes ≤ M_D basis insertions and ≤ 1 + |A|·M_D substitutions.
(iv) h(x) = (g_1(x),…,g_d(x)) satisfies the exact-quotient criterion (Finding D) and its transitions are LINEAR:
h(δ_a x) = C_a h(x), where C_a ∈ 𝔽_2^{d×d} with K_a g_i = Σ_j (C_a)_{ij} g_j; and F = λ^T h for a fixed λ.
Hence F(δ_w x) = λ^T C_{a_k} ⋯ C_{a_1} h(x), exact, with no tags and no checksum.
Proof. (i) Every queued element is F or K_a of an element of span(basis) ⊆ V_F, and V_F is K_a-closed. (ii) Let U be the final span.
F ∈ U. For every inserted g, each K_a g was queued and later either inserted or reduced to 0 against a subset of the final basis, so
K_a g ∈ U; by linearity K_a U ⊆ U. Minimality of V_F gives V_F ⊆ U, and U ⊆ V_F by (i). (iii) Inserted vectors are linearly
independent in 𝒫_D. (iv) g_i ∈ V_F and K_a g_i ∈ V_F give the coefficients C_a; F ∈ V_F gives λ. If h(x) = h(x') then all of V_F
agrees on x, x' (it is spanned by the g_i), so F and h∘δ_a agree: this is the Finding-D criterion (and O1: h(x) = h(x') ⇔ x ~ x'). ∎
Resource accounting (bit operations, all polynomial in n, |A|, s for constant D and r; no 2^n term anywhere):
- Construction: per substitution ≤ M_D monomials × D products of polynomials with ≤ s and ≤ M_{rD} monomials ⇒ O(M_D·D·s·M_{rD}).
  Reduction O(M_D²). Total (corrected 2026-11-28): at most 1 + |A|·M_D substitutions (F itself, then each of ≤ M_D basis polynomials under each of |A| actions), each costing O(M_D·D·s·M_{rD}) for the construction plus O(M_D²) for the reduction, so
  **Total O((1 + |A|·M_D)·(M_D·D·s·M_{rD} + M_D²)).** The exported total O(|A|·M_D·(D·s·M_{rD} + M_D²)) is inconsistent with the per-substitution cost stated one line above it: it drops one factor M_D in the construction term (and the "1+"). Polynomial for constant D, r; the quantitative comparison of procedures must use the corrected formula. (An earlier note of this session calling the finding "not confirmed" was wrong: it compared the text with the audit statement instead of recomputing the product.)
- Representation: d ≤ M_D basis polynomials of ≤ M_D coefficients each, plus |A| matrices of size d×d.
- Transition: one matrix-vector product, O(d²). A word w costs O(|w|·d²) (or O(d^ω log|w|) by squaring for powers).
- Extraction: evaluate h at the input, O(d·M_D·D), then the inner product λ^T(·).
Concrete nonlinear test systems (computed, scratchpad closure.py; CLOSE checked against an independent truth-table closure):
- Quadratic accumulator: x_0..x_{k−1} cyclic shift, h' = h ⊕ x_0x_1, F = h (n = k+1). CLOSE with D = 2 succeeds, d = k+1;
  k = 3..6 agree with brute force. By hand: F∘δ^t = h ⊕ Σ_{j<t} x_j x_{j+1} (indices mod k), so V_F = span{h, x_jx_{j+1}}. This is a
  genuinely nonlinear system with an exact, linear-size, compositional representation.
- Binary counter (O2): CLOSE succeeds iff D ≥ n−1 (computed n = 2..6). Proof for every n: F∘δ ⊕ F = x_0x_1⋯x_{n−2} (the top bit flips
  iff the lower n−1 bits are all 1), which has degree n−1. So the degree condition fails exactly on the system where O2 shows d = 2^{n−1}+1.
- 200 random systems with two quadratic actions, n = 3..6: wherever CLOSE succeeded, its d equals the truth-table d (0 mismatches).
Scope (honest). The method is classical (linearization / Krylov closure over ANF, as in algebraic cryptanalysis and the observability
of polynomial systems); O6 is an assembled, fully proved statement, with no novelty claimed for the method. It answers owner §8/§9
positively for one precisely defined class: exact, compositional, constructible, with no ambiguity because the coordinates carry all of
V_F (O4 is met with equality). It is NOT a lower-bound lever. The degree of the decision is no hardness measure: AND_n has degree n
and lies in P, and parity has degree 1. Low degree is the AC^0[2] restricted-model territory (Razborov–Smolensky). For single runs,
O5 still applies.
Open question (precise, the next one worth testing): for which nonlinear families does V_F have small dimension but unbounded degree
in every basis? (O3 shows that such families exist, non-constructively.) Is there an explicit one with polynomially evaluable basis
outside 𝒫_D?

## 3c. Optimality of linear abstractions and the limit of the degree method (PI, 2026-11-17)
Lemma O7 (linear compositional abstractions have exactly ≥ d coordinates). Let h : X → 𝔽_q^k with h(δ_a x) = C_a h(x) for all a and
F = λ^T h. Then k ≥ d = dim V_F, and k = d is attained (O6(iv), or any basis of V_F).
Proof. Let U = span{h_1..h_k}. h_i∘δ_a = Σ_j (C_a)_{ij} h_j ∈ U, so U is K_a-closed, and F ∈ U. Minimality of V_F gives V_F ⊆ U,
so d ≤ dim U ≤ k. ∎ (Classical: minimal linear representations / Hankel rank, Schützenberger, Fliess, Carlyle–Paz.)
Consequence. For the binary counter (O2) every exact abstraction with LINEAR transitions needs ≥ 2^{n−1}+1 coordinates, while the
abstraction "keep x" with the NONLINEAR transition x ↦ x+1 has n bits. Linearising the transitions costs exponentially here. So
"compact linear representation" is strictly stronger than "compact exact representation". This is a proved separation of the two
notions, not a complexity lower bound.

Lemma O8 (explicit small V_F with unbounded degree; answers the open question of §3b). φ_0 = x_0, φ_i = x_i ⊕ x_0x_1⋯x_{i−1}
(i ≥ 1). φ is a bijection of 𝔽_2^n (triangular; invert coordinate by coordinate). L = cyclic shift, (Ly)_i = y_{i+1 mod n}.
δ = φ^{−1} L φ, F = φ_{n−1}.
Then: d ≤ n (V_F ⊆ span{φ_i}, as in O3); deg F = n−1; F(δ^t x) = φ_{(n−1+t) mod n}(x) exactly. The basis φ_0..φ_{n−1} is
evaluable in O(n) (prefix products); the transition is a coordinate shift; one query costs O(n) after O(log t) index arithmetic.
Proof. φ∘δ = L∘φ, so φ_j∘δ = φ_{j+1}: span{φ_i} is closed and contains F. F∘δ^t = (L^t φ)_{n−1} = φ_{n−1+t mod n}. ∎
Computed (scratchpad o8.py, n = 3..8): φ bijective; d = n exactly; deg F = deg δ = n−1; the degree closure CLOSE (O6) first succeeds
at D = n−1, i.e. it works in a space of dimension M_{n−1} = 2^n − 1, although a basis of size n with O(n) evaluation exists; the
cheap formula agrees with direct iteration for all x and t < 2n.
Consequence. Bounded degree (O6) is sufficient but not necessary for efficient exact compression. Efficient linear compression
⇔ (O7) d is small AND V_F has a cheaply evaluable basis. O3 (cheap fails) and O8 (cheap holds, degree unbounded) show the second
condition is independent of both d and degree. No algorithm is known (or claimed) that finds a cheap basis outside 𝒫_D in general.
Finding one for O8 needs the conjugacy φ, i.e. knowledge equivalent to the change of coordinates.

## 5. Strongest surviving construction and the precise gap
Construction: the Koopman observable space V_F with a basis whose elements are cheaply evaluable at the input, plus the matrices of K_a on
V_F. Exact and compositional; cost = (cost to evaluate the basis at x) + |w|·d² + d. It is efficient exactly when there is a basis of
size poly(n) whose evaluation costs poly(n) — e.g. affine systems (linear functionals), or nonlinear systems conjugate to linear ones by
a cheap φ, or — proved constructive class — closures of bounded ANF degree (O6: h = basis evaluation, linear transitions C_a). Precise gap: for a nonlinear family of interest (TM blocks, CA, circuits) characterise when V_F (or a subspace still containing
the needed F∘δ^T) has a polynomially evaluable polynomial-size basis. By O5 and Lemma N this is, for single runs, the question whether
the decision has small circuits — the original problem; no lower-bound lever, but a clean criterion for ALGORITHMIC compression.

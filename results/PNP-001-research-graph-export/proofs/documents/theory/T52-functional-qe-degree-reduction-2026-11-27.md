## 1. Theorem (owner), checked, with one correction
**Setting.** φ is a positive 1-in-3 formula with external inputs x (Boolean) and internal variables. Over F3,
EXACT1(a,b,c) ⇔ a+b+c = 1 with a,b,c ∈ {0,1}; this is T41 Theorem T. Gauss over F3 parametrizes the affine solutions of the internal
variables as y_i = a_i(x) + ℓ_i(z), with z ∈ F3^d.
**Correction (PI).** The domain factor has to range over **all** internal variables, including the free parameters z_j themselves.
Otherwise z_j = 2 allows additional solutions, uniqueness fails, and cancellations are possible.
So let m = number of all internal variables, let Q(x,z) = Π_{i=1}^m (y_i − 2) (each factor affine in (x,z)), and let F(x) = Σ_{z∈F3^d} Q(x,z).
**(a)** If every Boolean x has at most one Boolean extension (functional encoding), then F(x) = Q(x,z*) = (−1)^{#ones of the extension}
or F(x) = 0. Hence F(x) ≠ 0 ⇔ an extension exists. *Proof:* Q(x,z) ≠ 0 ⇔ all y_i ∈ {0,1}. Each nonzero term is 1 or 2 = −1 per factor,
and there is at most one such term. ∎
**(b)** deg_x F ≤ m − 2d. *Proof:* Σ_{t∈F3} t^k equals −1 if k > 0 and k is even, and 0 otherwise. So a monomial x^α z^β survives only
if every β_j is ≥ 2 and even. deg Q ≤ m, therefore |α| ≤ m − 2d. ∎ This is a Chevalley–Warning-type computation (row 1895); its form
(nonzero indicator, functional) is not in the proofbook. Novelty against the literature is not checked.

## 1′. Correction: input-only rows (2026-11-28; verified by full enumeration of the 16-input example)
Gauss elimination of the internal variables can leave r rows that involve only the inputs: r_j(x) = 0 (affine over F3, j=1..r). The parametrization
y_i = a_i(x) + ℓ_i(z) is a solution family only on {x : r(x)=0}; elsewhere the system has no F3 solution at all, but the polynomial F = Σ_z Q is still defined and can be ≠ 0.
- **Counterexample (exact).** x1+x2+y=1, x3+x4+y=1, y Boolean: r(x) = x1+x2−x3−x4, m=1, d=0, F=y−2 with y = 1−x1−x2 (deg 1 = m−2d). F ≠ 0 on 7 of the 16 inputs where the system is unsatisfiable, e.g. x=(0,0,1,1).
- **(a′)** F_corr(x) := Π_{j=1}^r (1 − r_j(x)²)·Σ_{z∈F3^d} Q(x,z). If every Boolean x has at most one Boolean extension, then F_corr(x) ≠ 0 ⇔ an extension exists (r(x)=0 forces the parametrization to be valid). Matches the satisfiability predicate on all 16 inputs of the example. No affine F3 polynomial equals that predicate (all 243 checked).
- **(b′)** deg F_corr ≤ (m−2d) + 2r =: e*(φ). (b) deg F ≤ m−2d stays true for F as defined; only (a) needed the extra factor.
- **Dependent statements, all replaced by e\* = m−2d+2r:** Prop 3.1 (i) e* ≥ wdeg_3(C); (ii) a satisfying input of weight ≤ e* exists; AND_n: e* ≥ n; §4 below; §6 composition: for the composite, the input-only rows are K2 plus those of φ1, so e* is not additive in general; the §6 formula e = e1+e2+2c (c = rank(K2·L1)) is the change of m−2d only and must be combined with the r-count of the composite.
- **Three different things (do not conflate):** (1) *functional uniqueness* of the Boolean extension: F_corr(x) ∈ {0,±1}; (2) *efficient witness computation*: finding the extension; (3) *propagation completeness*: unit propagation finds it. (1) does not imply (3) or (2): a+b+c=1, a+b+d=1, a+c+d=1 has the unique Boolean solution (1,0,0,0), no unit clause, UP performs 0 steps (F3 has 3 solutions). Whether uniqueness gives efficient search is the unique-SAT/Valiant–Vazirani question (UP vs P), not settled by this theorem.

## 2. Composition: the corrected excess e* is subadditive (rewritten 2026-11-28; replaces Prop 2.1 and §6)
Definitions (all variables counted, T52 §1/§1′): m = # internal variables, d = dim of the affine solution space of the internal variables (given generic inputs), r = rank of the input-only rows, e*(φ) := m − 2d + 2r.
**Proposition 2.1\*.** Compose functional encodings: the outputs u of φ1 are the inputs of φ2. Let K2 = input-only rows of φ2 (rank rk2), L1: z1 ↦ ℓ1(z1)|_u, c := rank(K2·L1). Then
- m = m1 + m2; d = d1 + d2 − c (the c rows with K2L1 ≠ 0 are solvable for z1 given x, so they remove c parameters and are NOT input-only after composition);
- input-only rows of the composite: those of φ1 together with the rk2 − c combinations of K2-rows with K2L1-part 0, hence r ≤ r1 + rk2 − c (equality if independent);
- therefore e*(φ) = m − 2d + 2r ≤ e1* + e2*, with equality iff these input-only rows are independent. The terms ±2c cancel.
*Proof.* Substitute u = a1(x) + ℓ1(z1) into φ2's reduced system: the rows K2·u = κ become K2a1(x) + K2L1 z1 = κ; row-reduce in z1. ∎
(Earlier §2/§6 stated e = m − 2d with e = e1 + e2 + 2c ≥ e1 + e2; that quantity is not the degree bound of the satisfiability polynomial and is superseded.)

**Proposition 2.2 (exact rank form and composition law; derived 2026-11-28, recalculated and checked).** Let A be the full coefficient matrix of a consistent affine system φ over F (columns: inputs and internal variables; the internal variables number m, the fibre dimension is d, r = rank of input-only rows). Then rank A = (m − d) + r (rank of the internal part is m − d; the remaining independent rows are input-only), hence **e*(φ) = 2·rank A − m**. For a composition with disjoint internal variables (u counted once, as an internal variable of φ1), let U_i ⊆ F^{coordinates} be the row spaces embedded in the joint coordinate space. Then rank A_12 = dim(U1 + U2) = rank A1 + rank A2 − dim(U1 ∩ U2) and m = m1 + m2, so
 **e*_12 = e*_1 + e*_2 − 2·dim(U1 ∩ U2).**
Since a vector in U1 ∩ U2 involves only the shared coordinates u, U1 ∩ U2 = (rows of φ1 supported on u) ∩ (input-only rows of φ2, supported on u): its dimension counts the conditions on u imposed by φ2 that φ1 already implies. This gives subadditivity (Prop. 2.1*) and the exact defect: equality e*_12 = e*_1 + e*_2 iff no input condition of φ2 is already a relation of φ1. (Consistency: Prop. 2.1* "equality iff input-only rows independent" is the same statement.) It is an identity of ranks; it says nothing about evaluation cost. Not claimed: that the refined excess e** of Prop. 3.1† below is subadditive (the multilinear reduction of a product of indicators is not controlled by the factors' degrees).

## 3. Lower bound by weak degree (rewritten with e*)
**Proposition 3.1\*.** Let φ_C be a functional encoding with output forced to 1 and F_corr as in §1′. Then F_corr ≠ 0 exactly on C^{-1}(1) and deg F_corr ≤ e*(φ). Hence
- (i) e*(φ) ≥ wdeg_3(C), wdeg_3 = minimal degree of an F3 polynomial whose nonzero set on {0,1}^n is C^{-1}(1);
- (ii) if C is satisfiable it has a satisfying input of Hamming weight ≤ e*(φ).
*Proof (ii).* The multilinear representative of F_corr is ≠ 0; take a minimal monomial S, Möbius inversion gives F̃(1_S) = c_S ≠ 0. ∎
**Proposition 3.1† (refined input contribution; valid, 2026-11-28).** Let P(x) = ∏_j (1 − r_j(x)²) (r_j the independent input-only rows) and ML(P) its multilinear representative on {0,1}^N. Then F_corr = P·Σ_z Q on the cube, and since the multilinear reduction of a product has degree ≤ the sum of the degrees, **wdeg_3(C) ≤ m − 2d + deg ML(P) =: e**(φ) ≤ e*(φ).** deg ML(P) can be far below 2r: for a row x_i − 1 = 0, 1 − (x_i−1)² = x_i on the cube (degree 1, not 2); in general deg ML(P) ≤ number of input variables occurring in the rows. Open: the structure of reduced input rows (e.g. rows of Hamming support ≤ 2 give factors of degree ≤ 2 per row, but rows with large support and coefficients ±1 are the costly case).

By Möbius inversion the coefficient of the monomial x_T is Σ_{U⊆T}(−1)^{|T|−|U|} f(1_U), and f(1_U) ≠ 0 only for U = ∅ or the four 2-sets {1,3},{1,4},{2,3},{2,4}. Degree-3 monomials: T = {1,2,3}: −a−b−d; {1,2,4}: −a−c−e; {1,3,4}: −a−b−c; {2,3,4}: −a−d−e. Degree 4: a+b+c+d+e. So multilinear degree ≤ 2 ⇔ a+b+d = a+c+e = a+b+c = a+d+e = a+b+c+d+e = 0. (1st + 2nd) − 5th gives **a = 0** (any characteristic): every polynomial of degree ≤ 2 vanishing on the 11 unsatisfying inputs also vanishes at 0000, so none has the exact satisfying support. The solution space is then b = −d, c = −e, c = −b ⇒ (b,c,d,e) = s·(1,−1,−1,1): dimension 1 (generated by (x1−x2)(x3−x4)). Degree ≤ 3 only requires a+b+c+d+e = 0: dimension 4. No further enumeration is needed for this example.
**Exact weak degree wdeg_3 = 3 = e* = e** (m−2d+deg ML(P) = 1 + 2): the bound is SHARP in this example.** The retracted claims (wdeg = 2; "P = 1−(x1+x2−x3−x4)² has exactly the required support"; "F_corr can be replaced by P") are false: P is nonzero on (1,1,1,1), and it is the factor Σ_z Q (degree 1) that removes that point, which is why the degree is 1 + 2. Example: C = AND_n: e*(φ) ≥ n for every functional encoding. In particular the encoding-size information carried by e* is at most O(N).

## 4. Efficiency (rewritten)
If e* ≤ D, the coefficients of F̃_corr follow by Möbius inversion from the values F_corr(1_T), |T| ≤ D. Each value needs the unique extension of x = 1_T (or its absence): computable in poly time if unit propagation is complete for the encoding (propagation completeness; uniqueness of the extension alone is not enough, §1′). Cost n^{O(D)}·poly. In general e* ≥ wdeg_3(C) can be Θ(n) (AND_n).

## 7. Selector degree theorem and the excess-zero classification (owner derivation 2026-11-28; checked by the PI, 2026-11-28)
Setting as in §1/§1′ (F_corr = P·Σ_z Q, Q = Π_i (y_i − 2), y = a(x) + ℓ(z)), φ functional (at most one Boolean extension per Boolean x), D = set of inputs with an extension.
**Definition.** For a polynomial w(x,y) over F3: G_w(x) := P(x)·Σ_{z∈F3^d} Q(x,z)·w(x,y(x,z)), σ := G_1 = F_corr.
**Theorem 7.1 (selector degree; proved).** (i) σ(x) ∈ {±1} on D, σ = 0 off D; G_w = σ·w(x,S(x)) on D and 0 off D, hence **σ·G_w = 1_D·w(x,S(x)) and σ² = 1_D** on {0,1}^N.
(ii) deg ML(G_w) ≤ e**(φ) + deg w; (iii) deg ML(σ G_w) ≤ deg ML(σ) + deg ML(G_w) ≤ 2e** + deg w; in particular deg ML(1_D) ≤ 2e**.
*Proof.* (i) On D with r(x)=0 the only z with Q ≠ 0 is the unique extension z*, Q(x,z*) = (−1)^{#ones} (§1(a)), P = 1, so G_w = σ w(x,S). Off D: if r(x) ≠ 0 then P = 0; if r(x) = 0 but no Boolean extension exists, every term has Q = 0. (ii) Q·w has degree ≤ m + deg w in (x,z) (y affine in (x,z)); Σ_{t∈F3} t^k = −1 for even k > 0 and 0 otherwise, so a monomial survives only if every z_j exponent is even and ≥ 2; hence deg_x ≤ m + deg w − 2d. Multiply by P and reduce multilinearly: ≤ deg ML(P) + (m − 2d) + deg w = e** + deg w. (iii) multilinear reduction of a product has degree ≤ the sum. ∎
Remark. The signed observation σ·w(x,S) already has degree ≤ e** + deg w; the unsigned one costs the factor σ again. If σ is constant on D (e.g. #ones of the extension has constant parity) the unsigned bound is e** + deg w.
**Corollary 7.2 (excess zero; proved).** If e**(φ) = 0 and D ≠ ∅, then m = 2d, P ≡ 1, σ is constant ±1, D = {0,1}^N (total), and every internal variable satisfies S_i = ±G_{y_i}, an affine F3-polynomial that is {0,1}-valued on the cube; hence S_i ∈ {0, 1, x_j, 1 − x_j}.
*Proof.* e** = (m−2d) + deg ML(P) with m − 2d ≥ 0 whenever D ≠ ∅ (otherwise Σ_z Q ≡ 0). So m = 2d and deg ML(P) = 0, P ≡ 1 on the cube. deg ML(σ) ≤ 0, σ constant, nonzero on D, so D is the whole cube. S_i = σ·G_{y_i}, deg ≤ 1. An affine a0 + Σ a_j x_j over F3 with values in {0,1} on the cube: restricting all other variables to 0, two variables with nonzero coefficients give the value set containing a0 + a_j + a_k and a0 + a_j, a0 + a_k, a0 — checking the 9 sign/constant cases, one of them is 2; so at most one coefficient is nonzero, and a0 + a x_j ∈ {0,1} forces (a0,a) ∈ {(0,1),(1,−1)}. ∎
**Sharpness.** The class is not empty and not only literals-without-auxiliaries: y1 = z, y2 = z + 1 + x_j (one row y2 − y1 = 1 + x_j, m = 2, d = 1, e** = 0) is total and functional with unique extension y1 = x_j, y2 = 1 − x_j. Checked exactly on both inputs (σ = −1 constant).
**Exact check (two examples, no enumeration beyond 16 + 2 inputs).** For the §3 reference example (x1+x2+y=1, x3+x4+y=1) the identity σ G_w = 1_D·w(x,S) holds for w ∈ {1, y, y²} on all 16 inputs, |D| = 5, σ ∈ {±1} on D.
**What it is and is not.** It bounds the F3-degree of EVERY polynomial observation of the selector (all internal bits, not only the decision bit) by 2e** + deg w; for internal bits 1_D·S_i has degree ≤ 2e** + 1, so e** ≥ (deg_3(1_D S_i) − 1)/2 for each internal variable i. For the decision bit this is weaker than Prop. 3.1† (e** ≥ wdeg_3); its new content is control of internal gate values. It contains no running-time statement: degrees are ≤ N trivially, and a size bound on the encoding follows only through m − 2d + deg ML(P) ≥ (max_i deg_3(1_D S_i) − 1)/2. Novelty against the literature not checked; independent review pending. No contradiction; P ≠ NP not claimed.

## 8. Hereditary 2-sparsity, saturated blocks and exact elimination (owner derivation 2026-11-28; checked by the PI, 2026-11-28)
Setting: Ay + Bx = c over F3 with internal columns y ∈ {0,1}^m (A: k×m), inputs x, and at least one input x0 with exactly one Boolean y (a functional encoding with D ≠ ∅). For J ⊆ [m]: r(J) = rank A_J, f(J) := 2r(J) − |J|. (So f([m]) = m − 2d = the internal excess; e* = f([m]) + 2r_in.)
**Signed fibre count.** D_J(v) := Σ_{z∈{0,1}^J, A_J z = v} (−1)^{|z|} ∈ F3, v ∈ Im A_J. (For J = [m] this is the F of §1, since Q = Π(y_i − 2) = (−1)^{|y|} on Boolean points.)
**Lemma 8.1 (proved).** For v ∈ Im A_J, with h = r(J) independent rows i_1..i_h: 1[A_J z = v] = Π_{t≤h}(1 − ((A_J z − v)_{i_t})²), a polynomial of degree ≤ 2h in z. Since Σ_{z∈{0,1}^J}(−1)^{|z|} z^S = 0 for every proper subset S ⊊ J (a factor Σ_{z_i}(−1)^{z_i} = 0 for i ∉ S), D_J(v) = (−1)^{|J|}·[coefficient of z_J in the multilinear reduction]. Hence: (a) |J| > 2h ⇒ D_J ≡ 0 on Im A_J; (b) |J| = 2h ⇒ D_J is constant on Im A_J (the coefficient of the full monomial has v-degree ≤ 2h − |J| = 0); (c) in general deg_v D_J ≤ 2h − |J|.
**Theorem 8.2 (hereditary 2-sparsity; proved).** If some x0 has exactly one Boolean y*, then for every J: |J| ≤ 2 r(J) (f(J) ≥ 0).
*Proof.* v0 := (c − B x0 − A_R y*_R) lies in Im A_J and its fibre {z : A_J z = v0} is {y*_J} (another z would give a second Boolean solution), so D_J(v0) = ±1 ≠ 0; by (a) |J| ≤ 2h. ∎ (J = [m] is the earlier m − 2d ≥ 0.)
**Corollary 8.3 (Edmonds).** |J| ≤ 2 r(J) ∀J ⟺ the columns partition into two independent sets (Edmonds' matroid partition theorem, k = 2). If f([m]) = 0 both are bases of the column matroid.
**Theorem 8.4 (saturated block elimination; proved).** Let |J| = 2h (tight, f(J) = 0), W = Im A_J, π : F3^k → F3^k/W. Then D_J ≡ D_J(v0) = ±1 on W, every w ∈ W has a Boolean preimage, and for EVERY input x
 ∃ y_J, y_R : A_J y_J + A_R y_R + Bx = c  ⟺  ∃ y_R : π(A_R) y_R + π(B) x = π(c).
(⇒ trivial; ⇐ v := c − Bx − A_R y_R ∈ W has a Boolean preimage.) Moreover Σ_{full Boolean sol.}(−1)^{|y|} = D_J·Σ_{reduced Boolean sol.}(−1)^{|y_R|}, every reduced solution lifts, so uniqueness is preserved: the reduced system is again functional on D, with the same D and the same σ up to the constant sign D_J.
**Recalculation of the invariants.** m' = m − 2h; rank A' = rank A − h (W ⊆ column space), rank A_int' = rank A_int − h; d' = d − h (not unchanged); input-only rows: they are the λ with λ·A_int = 0 ⇒ λ·A_J = 0, hence they survive unchanged, r_in' = r_in, P unchanged. Therefore f([m]), e* = 2 rank A − m and e** are all UNCHANGED (this is the corrected statement: the fibre dimension drops by h, the excess does not).
**Theorem 8.5 (unique maximal tight block; proved).** f is submodular (r submodular, |·| modular) and ≥ 0, so tight sets are closed under ∪ and ∩; there is a unique maximal tight set J*. For J tight and J' ⊆ [m]∖J, the contracted system has f'(J') = 2(r(J∪J') − r(J)) − |J'| = f(J ∪ J'). Hence after eliminating J* the reduced system has NO nonempty tight set (f' ≥ 1 on every nonempty subset): one elimination step is all there is; "successive" elimination yields nothing new. If a set Σ of designated variables (outputs) must be kept, take J* inside [m]∖Σ; the same argument applies, J* is the maximal tight set avoiding Σ. The inputs x are never touched (saturation depends on A_J only).
**What survives, and what does not.** (i) Existence of an extension is preserved exactly; the values y_J(x) are lost: they are the unique Boolean preimage of v(x) under z ↦ A_J z, and recovering them is a (small-block) subproblem of cost ≤ 2^{|J|}·poly, or poly when the block splits into columns parallel up to sign (see below). (ii) The excess, hence e* ≥ wdeg_3(C), and all Prop. 3.1† / §7 bounds are unchanged: elimination removes variables, not degree. (iii) Simplest saturated blocks are pairs {a, ±a} of parallel columns (z1 ± z2 takes every value of F3: a free F3 variable, i.e. ordinary Gaussian elimination); block-diagonal sums of such pairs give D = Π ±1; every column-parallel-up-to-sign pair is eliminable. (iv) Tight sets do not have to be saturated without uniqueness: in 252 random tight blocks over F3 (k ≤ 3, h ≤ 3), D_J was constant in all cases (Lemma 8.1(b) confirmed), nonzero in 124, identically 0 in 128; in the 124 nonzero cases the Boolean cube covered the whole image. The uniqueness hypothesis (D_J(v0) ≠ 0) is what excludes the 128 zero cases.
**Cost.** The maximal tight set is computable in time polynomial in (m,k) by matroid-partition (maximal J with f(J)=0 = union of the "blocking" sets of a maximum 2-partition; one linear-algebra rank oracle over F3 per step); the quotient system costs O(k·m·rank). All of it is poly in the ENCODING size, not in the circuit's truth table. Hypothesis: a unique reference solution must be known to exist (for circuit encodings, evaluate the circuit at one input).
**Limits.** The theorem is silent on how large J* is for encodings of computations; after elimination the core has f' ≥ 1 on every nonempty subset and contains all of the excess e*. Since e* ≥ wdeg_3(C) and e* ≤ m_core + 2N, no lower bound on the core size follows beyond the vacuous m_core ≥ wdeg_3 − 2N. Whether circuit encodings have large tight blocks is open; the examples with y = literal show tight blocks exist (§7 sharpness example is a tight block y1,y2 with h = 1). Novelty not checked, independent review pending; no contradiction; P ≠ NP not claimed.

## 9. Canonical reduction: polynomial-time maximal saturated block, residual strictness, floor, design analysis (owner derivation + PI, 2026-11-28)
Setting and hypothesis (H) as in §8: functional on D ≠ ∅, i.e. at least one input with exactly ONE Boolean y. f(J) = 2r(J) − |J|; Σ ⊆ [m] designated (kept) internal variables; E' = [m]∖Σ.
**Theorem 9.1 (maximal block by partition tests; proved).** Let J* ⊆ E' be the union of all tight sets J ⊆ E'. Then J* is tight (union closure, §8.5). For e ∈ E' let M_e be the column system M|E' with one extra copy e' of column e. Then M_e is NOT partitionable into two independent sets ⟺ e ∈ J*.
*Proof.* By the matroid partition theorem (Edmonds) M_e is partitionable iff |S| ≤ 2 r(S) for all S ⊆ E' ∪ {e'}. Sets without e' are fine by (H) (f ≥ 0). Sets with e' but not e: r(S) = r(S − e' + e), |S| = |S − e' + e|, so f(S) = f(S − e' + e) ≥ 0. Sets S ∋ e, e': S = T ∪ {e'} with e ∈ T, r(S) = r(T), so f(S) = 2r(T) − |T| − 1 = f(T) − 1 < 0 ⟺ f(T) = 0 (integers, f(T) ≥ 0). So a violation exists ⟺ some tight T ∋ e, T ⊆ E'. ∎ Cost: |E'| partition tests, each polynomial in (m,k) with one F3-rank oracle per augmentation. Checked non-circularly (actual 2-partition search, not the rank criterion) on 113 random instances over F3 (k ≤ 4, m ≤ 7): J* = {e : M_e not partitionable} in all 113. Loops (zero columns) violate (H) and are excluded.
**Theorem 9.2 (strict residual; proved).** After eliminating J* (Thm 8.4, taken inside E'), for every nonempty J' ⊆ E'∖J*: 2 r̄(J') > |J'|, because f̄(J') = f(J* ∪ J') ≥ 0 and equality would make J* ∪ J' tight, contradicting maximality. For subsets that contain designated variables no strictness is claimed.
**Theorem 9.3 (size of the removable block; proved).** |J*| = 2h with h = r(J*), and d = m − rank A_int = d_core + h, so **|J*| ≤ 2d**, with equality iff the contracted core columns are linearly independent (d_core = 0). Floor: m_core ≥ rank A_int,core ≥ e_int := m − 2d, since e_int = 2 rank − m_core ≤ rank ≤ m_core. With e** = e_int + deg ML(P) ≥ wdeg_3(C) (Prop. 3.1†): **m_core ≥ wdeg_3(C) − deg ML(P)**; if the inputs are affinely free (no input-only rows, P ≡ 1) then m_core ≥ wdeg_3(C): e.g. any functional encoding of AND_N retains ≥ N internal variables however much is eliminated. This is exactly the statement that elimination removes variables but not degree. (Vacuous when deg ML(P) ≥ wdeg_3, e.g. wdeg_3 ≤ N always: no floor above N can come from degree arguments.)
**The four notions (do not conflate).** (1) Feasibility ∃y: preserved exactly for every x (Thm 8.4), needs only tightness of J* AND (H). (2) Uniqueness: preserved if the FULL system is functional on all x (every reduced solution lifts, so two reduced solutions would give two full ones); (H) alone (one unique input) does NOT give uniqueness elsewhere. (3) Witness reconstruction: NOT preserved; y_J(x) = the unique Boolean preimage of v(x) under z ↦ A_J z, a subproblem of cost ≤ 2^{|J|} poly (poly for blocks that are sums of pairs {a, ±a}). (4) Signed count mod 3: preserved up to the constant sign D_J = ±1.
**(H) cannot be replaced by the rank condition.** Columns (0,1),(1,0),(1,1),(1,2) over F3 (k = 2): partitionable (f ≥ 0 on every subset), tight (4 = 2·2), but D_J ≡ 0 on the image and the Boolean cube reaches only 8 of the 9 image points: the block is NOT eliminable. So f ≥ 0 / tightness is necessary, D_J ≢ 0 (supplied by a unique reference solution) is the part that gives coverage. (Random check: of 252 tight blocks 128 had D ≡ 0.)
**Design analysis (exact, bounded; no campaign).** (a) Exact search over all affine gadgets {2 rows or 3 rows over F3, inputs a,b, output out, t auxiliary Boolean variables, unique Boolean extension for each of the 4 inputs, out = f(a,b)}: AND and XOR have NO gadget with t = 1 (k = 2, 3); with t = 2, k = 2 there are 576 (AND) / 1152 (XOR) gadgets, e.g. AND: out + w1 + w2 = 1 and a + b + w1 − w2 = 2 (the first row is a positive 1-in-3 clause). In every one of them m = 3, rank = 2, e_int = 1, d = 1 and there is NO tight set (max removable block 0). (b) Positive 1-in-3 gadgets only (≤ 5 clauses, ≤ 3 auxiliaries): none functional for AND/OR/XOR (bounded negative result, not a theorem). (c) Consequence: a circuit of s such gadgets has m = 3s, rank ≤ 2s, so e_int = 2·rank − m = 4s − 3s = s if the ranks add (rank ≤ 2s rows; the exact rank of a composite was not computed here); Thm 9.1 finds J* = ∅ on these encodings, although the circuit is "easy": the excess s is paid for by the encoding, not forced by the function (wdeg_3 ≤ N). So the removable block of the standard gadget encodings is empty, and Thm 9.3 says what a redesign can at best achieve: removable ≤ 2d and a core of size ≥ max(e_int, wdeg_3 − deg ML(P)). (d) Padding the encoding with parallel pairs {a, ±a} creates tight blocks but they are removable for free and change neither e* nor the core: "maximising the removable block" by padding is vacuous; the figure of merit is m_core (equivalently e_int and the core's independence), not |J*|. A redesign must therefore lower e_int of the gate gadgets (composition law e*12 = e*1 + e*2 − 2 dim(U1 ∩ U2): needs shared interface constraints U1 ∩ U2 ≠ 0, which none of the found gadgets provide since no gadget has a row supported on its output alone).
**Status.** Theorems 9.1–9.3 and the counterexample are proved/checked; the search results in (a),(b) are exact within their stated bounds. Whether circuit encodings with e_int ≪ s exist (i.e. cancelling interfaces) is OPEN and is now the sharp question. Novelty and independent review pending. No contradiction; P ≠ NP not claimed.

## 10. Affine reconstruction of eliminated blocks (owner derivation + PI, 2026-11-28)
Setting: J tight, |J| = 2h, r(J) = h, hypothesis (H). D_J, M_i are INTEGER signed sums; every identity below holds in F3 (c ∈ F3*).
**Theorem 10.1 (proved).** (a) deg_v M_i ≤ 1: in ML(z_i · Π_t(1 − (r_t z − v_t)²)) the coefficient of z_J collects, from the degree-(2h−1) and degree-2h parts of the indicator polynomial, v-degrees ≤ 1 and ≤ 0 (the same top-coefficient argument as Lemma 8.1). Hence L := c⁻¹M is affine on Im A_J ≅ F3^h.
(b) At v with a unique fibre {z*}: D = (−1)^{|z*|} = c, M_i = c z*_i, so L(v) = z*. (So (−1)^{|z*|} = c is the same for all uniquely attained v.)
(c) A_J L(v) = c⁻¹ Σ_{A_J z=v} (−1)^{|z|} A_J z = c⁻¹ v D_J(v) = v for ALL v ∈ Im A_J (also where the fibre is not unique; there L(v) is not Boolean).
(d) L_i(v + a_i) − L_i(v) = −1 for all v ∈ Im, all i: split the fibre at v + a_i by z_i: the z_i = 1 part is −Σ_{A z' = v, z'_i = 0}(−1)^{|z'|}, and Σ_{z'_i=0} = D − M_i(v); so M_i(v + a_i) = M_i(v) − c. (For j ≠ i no such closed relation exists: the z_j = 0 part of the fibre at v + a_j is not controlled; an attempted symmetry argument that would force equal rows of H is WRONG and was discarded.)
(e) With L(v) = Hv + b (coordinates v ∈ F3^h on Im): A_J H = I_h, A_J b = 0, diag(H A_J) = −1 (from (d)); HA_J is idempotent of rank h with trace −2h ≡ h (mod 3), consistent.
Checked exactly: (a)–(e) on 594 random tight blocks over F3 (k ≤ 3, h ≤ 2): 0 violations; on 980 blocks (k = 2, |J| = 4) the first moments fit a UNIQUE affine map. Example: pair {a, a}: L_1 = L_2 = −v; pair {a, −a}: L_1 = −t − 1, L_2 = −t (checked on all fibres).
**Corollary 10.2 (total functional system; proved).** y_J = L(b(x) − A_R y_R) on D; uniqueness of the reduced system holds (two reduced solutions lift to two full ones); signed count preserved up to c; excess, e*, e** unchanged (§8). If b(x) is affine in x, then y_J ∈ span_F3{1, x, y_R} as functions on D, hence **|R| ≥ dim span(𝒜, y_1..y_m)/𝒜 =: ρ**, where 𝒜 = affine input functions on D. Equivalent form: **|J*| ≤ m − ρ** — only variables whose selector function is an affine combination of inputs and the other internal selector functions can lie in a saturated block. For the AND gadget of §9 (w1, w2 affine in a, b, out = ab) ρ = 1 per gate and m = 3 yet J* = ∅: the bound is necessary, not sufficient. For circuits whose gate functions are linearly independent mod affine, ρ = s and no elimination of any kind reduces the core below s.
**What is NOT established (efficient construction).** The constraints A_J H = I, diag(H A_J) = −1 do not determine L: for h = 2 in the basis form z1 + T z2 = u (B1 = I, T = B1⁻¹B2 invertible) they leave a free parameter, and the natural candidate K = −T⁻¹ (L_{B1} = −B1⁻¹v + const) is FALSE on the checked blocks (e.g. columns (2,1),(2,2),(2,0),(2,2): predicted linear part (0,2) for the first column, true (2,1)). Direct coefficient extraction (c = (−1)^h · perm-type sum over pairings of the 2h columns weighted by the rows r_t, mod 3; M_i similarly) is a permanent-type quantity mod 3; its hardness for tight blocks with D ≢ 0 is not settled, so NO polynomial algorithm from A_J alone is claimed.
**Partial constructions (proved).** (i) Blocks that are sums of parallel pairs {a, ±a}: L is explicit, per pair, O(1). (ii) Interpolation from evaluations: L is affine, so it is determined by its values at affinely independent points of Im A_J; every input x ∈ D with a known evaluation (circuit evaluation: y*(x)) gives such a point v(x) = A_J y*_J(x) with L(v(x)) = y*_J(x). If poly many evaluations produce points whose affine hull equals Aff(V) (V = {v(x)}), L is determined on V, in poly time. Soundness lemma: ANY affine right inverse L̃ (A_J L̃ = id on Im) with Boolean value L̃(v) ∈ {0,1}^J at a given v returns exactly the unique fibre element z*(v) (it is a Boolean preimage, the fibre is a singleton). So a candidate map needs only be verified Boolean on the attained V. Gap: sampling does not certify that rare directions of V are covered, hence this is a candidate, not an algorithm with a guarantee.
**Connections.** T52 §7: S_i = σ·G_{y_i} gives degree control of every internal bit; Thm 10.1 shows that for eliminated bits the selector is even AFFINE in (x, y_R). T55: the fibre-symmetry group acts trivially on D (unique fibres); L is the coordinate-bound decoder restricted to the block. T60/T38: the eliminated block contributes no behavioural classes (its state is an affine function of the interface state): in the T38 quotient picture it adds 0 to the tag length; the remaining core carries all of it. Computation-block architecture: a block is removable iff its selector is affine in the rest AND tight; it is useful only if circuit encodings contain tight blocks, which the §9 gadgets do not (J* = ∅); the sharp open question remains encodings with e_int ≪ s.
Status: Theorem 10.1/Cor. 10.2 proved and checked as stated; efficient construction OPEN; independent review and novelty pending; no contradiction; P ≠ NP not claimed.

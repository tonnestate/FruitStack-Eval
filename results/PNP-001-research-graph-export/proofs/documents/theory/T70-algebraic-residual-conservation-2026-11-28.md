## 1. Mask classes (T69 definition to be read with this section)
(i) Arbitrary circuit masks: contains every poly-size circuit invariant (T69 Prop 3), existence question = COMPRESS itself; the affine part carries nothing.
(ii) Affine masks / cubes: every piece is an affine set (intersection of affine sets); lower bound below.
(iii) Phi-chart: one fixed bijection Phi (circuit, inverse circuit), affine masks in Phi-coordinates. Contains (ii) for Phi = id and strictly more (§3).
**Prop 1 [U, V n = 1,2,3].** Every affine subset S ⊆ G_n = {(x,y,x·y)} has |S| ≤ 2^n; hence a cover of G_n by affine subsets contained in G_n needs ≥ 2^n pieces. Proof: S projects injectively to an affine P = q + W ⊆ F_2^{2n}; x·y restricted to P is affine iff its second difference vanishes: x·y(q+u+v)+x·y(q+u)+x·y(q+v)+x·y(q) = B(u,v) = x_u·y_v + x_v·y_u for u,v ∈ W; so W is totally isotropic for the non-degenerate alternating form B on F_2^{2n}, dim W ≤ n. [V] exhaustive DFS: largest affine subset inside G_n has 2, 4, 8 points for n = 1, 2, 3.
**Consequence.** If reachability and the final check force C = G_n exactly (§2), every certificate with affine masks has ≥ 2^n pieces. Proved, representation-dependent, known type (bent function / isotropic bound).
**Relation to T67 §7 (PI).** Both bounds are rank phenomena of full-rank 2^n×2^n matrices (the triangular matrix [k ≥ j+1] there, the Hadamard communication matrix of x·y here) but they bound different things (dimension of a function span versus the number of affine pieces covering a set); a common theorem is not derived [?]; they are not merged.

## 2. The computation whose checkpoint must be G_n [U, V]
State (x,y,b) ∈ F_2^{2n+1}, start (0,0,0), universal single-bit moves: flip x_i with b ← b + y_i, or flip y_i with b ← b + x_i (the serialisation of x' = x+a, y' = y+c, b' = b + a·y + x·c + a·c). Every state (x,y,x·y) is reachable (flip the bits of x, then of y) and no other: [V] n = 3 reachable set = G_n; the closure under single flips conserves r. Checkpoint check: Bad = {b ≠ x·y}. C must contain Reach = G_n and avoid Bad, hence C = G_n exactly.
**Thm 2 (residual conservation) [U, V].** With r = b + x·y and the general step x' = x+a, y' = y+c, b' = b + a·y + x·c + a·c: b' + x'·y' = b + x·y + (a·y + x·c + a·c) + (x·c + a·y + a·c) = r (char 2). [V] n = 3 exhaustive; 2000 random 12-step single-flip sequences.
**Prop 3 (Phi-chart answer) [U, V].** Phi(x,y,b) = (x,y,b+x·y) is an involution, maps G_n to {r = 0}, and conjugates the step to the translation (x,y,r) ↦ (x+a,y+c,r), an affine map. In the Phi-chart the certificate is ONE piece with ONE linear equation; size O(n) (x·y has 2n−1 gates). The affine-mask lower bound is therefore chart-dependent, as stated.
**What this does not show (owner's warnings, PI).** (a) The chart Phi = (x,y,b+x·y) was supplied; the invariant b = x·y is the definition of what the machine maintains incrementally, so Thm 2 verifies the maintenance rule, not the discovery of an invariant. (b) For any f computed by a circuit, Phi_f(x,y,b) = (x,y,b+f(x,y)) maps the graph of f to {r = 0}: the cost of compressing a graph is exactly |f|, moved into the chart. The Phi-chart class (iii) therefore again contains all graph-of-circuit invariants and is not a restriction until Phi is constrained. (c) Preservation of a known invariant is not construction of an adequate one.

## 3. Residual transport (exact identities)
Residual vectors q_i: F_2^n → F_2^{m_i}, V_i = {q_i = 0}. Want q_{i+1}(F_i z) = M_i(z) q_i(z).
**Prop 4 [U, V].** Such Boolean-matrix M_i exists iff F_i(V_i) ⊆ V_{i+1}. Proof: ⇒ trivial. ⇐: for a component f = q_{i+1,j}∘F_i, which vanishes on V_i, put e = Σ_l q_{i,l} ∏_{t<l}(1+q_{i,t}) (disjoint decomposition of OR, so e = 1 on ¬V_i) and M_l = f·∏_{t<l}(1+q_{i,t}); then Σ_l M_l q_{i,l} = f·e = f. [V] 300 random instances (n = 4, m = 3). So the existence of M_i is exactly inductivity; the content lies only in the SIZE of (q_i, M_i).
**Cocycle (composition) [U, V].** q_{i+2}(F_{i+1}F_i z) = M_{i+1}(F_i z)·M_i(z)·q_i(z); q_0(z_0) = 0 gives q_i = 0 along the whole trajectory without computing intermediate states, if the matrix-valued M_i have compact descriptions. [V] two-block case. For constant M_i (as in Thm 2, M = 1) the product is trivial; for M_i from a small semigroup of matrices the exponentially long product obeys the dyadic composition of T69 Prop 6 (powers M^{2^t} by repeated squaring, n levels).
**Honest status [?].** For the solver circuit S the natural residuals are q_g = w_g + gate_g(w_a, w_b) (degree 2 over F_2); the map Phi_S(x,w) = (x, w + S(x)) conjugates the graph of S to {q = 0} at cost |S|. A single evaluation is therefore trivial. What is NOT constructed: a compact q for the alternating exponential computation of D in which S is called exponentially often, with M_i of polynomial description and a single checkpoint residual forcing the correct answer. Locally simple gate constraints do not imply a compact global invariant. Non-relativizing: the residual q_g uses the gate structure of S and has no counterpart for an oracle gate (T68 Prop 4), but the existence of an adequate global residual is open.

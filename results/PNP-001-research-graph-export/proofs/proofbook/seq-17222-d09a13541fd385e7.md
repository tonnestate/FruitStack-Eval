NONADAPT-LB (owner derivation 2026-11-26, director check; CLAIMED; part of CONV-D seq 17216). b = N^beta, a = b/(10m), m = log2 N, dyadic blocks of size B = Theta(b m) with a large constant. Counting gives y in {0,1}^B with CC(y) > b; x^(I) = y on block I, 0 elsewhere, has CC(x^(I)) >= CC(y) > b (restriction), so every x^(I) is a Gap-MCSP[a,b] NO instance. If a sample J sees <= r = Theta(a/m) positions of I, one equality test of O(m) gates per observed one gives an a-circuit consistent with x^(I) on J, so the partial-consistency test accepts. E_I|J n I| = tB/N, Markov: Pr_I[|J n I| > r] <= tB/(N r) = O(t m^3/N); for J random but independent of the input, averaging gives a fixed NO instance rejected with probability O(t m^3/N). Hence t = Omega(N/(log N)^3) for constant rejection. Director extensions: (i) the bound holds for EVERY non-adaptive tester with perfect completeness (any view consistent with a YES table must be accepted), not only for the consistency rule; (ii) ADAPTIVE one-sided testers: on x^(I) the run equals the run on 0^N (a YES instance) until a query hits I, so t = Omega(N/B) = Omega(N^{1-beta}/log N). Scope: excludes sublinear single-sample consistency for plain Gap-MCSP (consistent with the closed sampling route: tau = Theta(b/m) there needs t = Theta(N m)); does NOT constrain input-dependent anti-checkers or families of anti-checkers (an AND over a family needs total sample size >= N/polylog, below the trivial formula size N).

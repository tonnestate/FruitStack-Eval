Checked steps: (i) Phi restricted to the vertex blocks of X depends only on S_X, so |S_X| >= 2|X| (Hall condition); (ii) Delta = Phi(x') - Phi(x) lies in K_G(A) (subgroup), so a nonzero vertex block has >= 2 nonzero coordinates and two supports in the same 3-block meet; (iii) for an edge uv, i in S_u, j in S_v, either i in S_v or j in S_u (case ii), or both differences vanish on the far block and have >= 2 nonzero coordinates in the 3 edge coordinates, so they meet.

## Statement / proof text (verbatim)

INTERFACE FACTORISATION OF CERTIFICATES (elementary; restated, not claimed new; relation to syntheses SYN-cbdccbd10d82, SYN-fc446364b44d, open G0001). (1) For E1(x,s), E2(s,y) with private x,y and shared set s: exists x,y (E1 and E2) = (exists x E1) and (exists y E2), so union unsat iff proj_s(E1) and proj_s(E2) are disjoint. The failure in SYN-fc4 arises only when a shared auxiliary is projected away separately; the interface must be the FULL shared set. (2) GF(2) affine case: with R_i = {(lambda_i*A_i, lambda_i*b_i)}, union inconsistent iff exists u in rowspace(E1)∩rowspace(E2) with beta1(u)!=beta2(u); u is then supported on s only. Verified by exhaustive span enumeration on 3283 random consistent pairs (nx=ny=2, nz=3), 290 inconsistent unions, 0 mismatches (scratchpad/cert/iface.py); this is Craig interpolation for linear equations (known technique). Certificate then factors through ONE interface polynomial u(s): u-beta1 in (E1) and u-beta2 in (E2) are independent memberships, reusable as a library entry per system. (3) Counterexample to the same factorisation without Boolean axioms: I1=(xz-1), I2=(z): 1 in I1+I2 but 1 not in (I1∩F[z])+(I2∩F[z])=(z). On the Boolean ring all ideals are radical (functions vanishing on a subset), so 1 in I1+I2 iff 1 in elim(I1)+elim(I2) holds, but the interface function can need 2^k size. (4) Positive Exact-One over F3 equals one affine equation sum=1 plus Booleanity (brute force trivial): the linear part has compact interface (affine subspace, O(k^2) bits), all hardness sits in the projection of the cube-constrained solution set, which is an arbitrary NP set. No contradiction with P=NP; open question: classify systems whose cube-projection to the interface has a compact representation (affine closure) and relate its degree to the excess e=m-2d of T52.

## Statement / proof text (verbatim)

MATROID-CUT-RANK for P_B (owner derivation 2026-11-27, director check; CLAIMED, needs review by another model family). (T1) Field F, P(u,v) = prod_i (a_i(u) + b_i(v) + c_i)^2, no factor the zero polynomial. If M (|M| = m) has {a_i}_M and {b_i}_M both linearly independent, then rank_{u|v}(P) >= 2^m (formal coefficient rank). Check: u_s with a_i(u_s) = t_i + s_i d_i, v_r with b_i(v_r) = -t_i - c_i - (1 - r_i) d_i; selected factor = (s_i + r_i - 1) d_i, so P(u_s, v_r) = 0 for s != r. Diagonal: every other factor is a nonzero polynomial in (t, d, free coordinates) (if a_j, b_j lie in the spans with coefficients lambda, mu, identical vanishing forces lambda = mu and lambda_i (2 s_i - 1) = 0, hence a_j = b_j = 0 and the factor is the nonzero constant c_j^2); the product of all diagonal factors and all d_i is a nonzero polynomial, so a good point exists over an infinite field. Over F_3 take an extension field: coefficient-matrix rank is invariant under field extension, and evaluation rank <= coefficient rank. Correct. Same mechanism as Lemma M9b' (seq 5192: diagonal evaluation + generic avoidance of the other factors); new is independence in place of variable-disjointness. (T2) Upper bound: with Edmonds' partition J (a = rk B_L[J], b = rk B_R[I \ J]), rank <= (D+1)^{a+b}; hence 2^kappa <= rank <= (D+1)^kappa, kappa = matroid-intersection number of the two row matroids at the cut. Correct. (T3) Application to K_G (q = 3, dim 2|V|), any basis B, any order pi, p = max over prefix cuts of kappa: for every vertex set S (h = |S|) a prefix cut with dim pi_S(L) = h exists; L' = {l in L : l|_J = 0}, R' = {r in R : r|_{I \ J} = 0}; S_L and S_R are disjoint (two nonzero vectors with coordinate sum 0 in F_3^3 share a support coordinate) and non-adjacent (if v in S_L, w in S_R then L'|_w = 0 and R'|_v = 0, so z_e = -x_v resp. -x_w have >= 2 of 3 nonzero edge coordinates on opposite sides of J: contradiction); |S_L| >= (h-a)/2, |S_R| >= (h-b)/2, separator D = S minus (S_L u S_R) with |D| <= p/2. Correct. CORRECTION (constant): components can still be (h+p)/2 > h/2, while Dvorak-Norin (from memory: every subgraph has a separator leaving components <= |V(H)|/2, of order k => tw <= 15k; verify at source) needs 1/2-balance. One more round on the large component (h >= 3p), else remove ceil(h/2) <= 1.5p vertices, gives order <= 1.5p, so tw(G) <= 22.5 p; the claim tw <= 15 p is not proved as written. RESULT (CLAIMED): min over kernel bases B and orders pi of the formal roABP width of P_B >= 2^{tw(G)/23} (Nisan: width = max prefix coefficient rank). STRENGTH: an unconditional lower bound for 'roABP after an invertible linear change of variables' on one explicit product of squared affine forms; P_B has small depth-3 circuits. w* = 2 tw + 1 (seq 4079) is NOT used in the proof; writing 2^{(w*-1)/46} is substitution only. The shared ingredient is the support lemma of the w* lower bound (seq 4071). Not related to M9 (IPS certificates of Psi_n). Literature novelty of T1/T2 (rank of products of linear forms vs matroid intersection) not checked. No consequence for P != NP.

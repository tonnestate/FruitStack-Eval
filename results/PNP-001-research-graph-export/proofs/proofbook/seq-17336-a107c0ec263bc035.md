VERIFIED BY AUTHOR: (i) sum_y |L_s(y)| <= 2^Lambda, so E_Y log|L_s(Y)| <= Lambda - b (Jensen). (ii) CUT-PASTE-LOCAL: windows = time intervals in which the input head is on segment j (reads of a segment belong to its window); sigma_j = (visited interval I_j, entry/exit contents of I_j, entry/exit control and head positions, duration). If sigma_j agrees, the full configuration at window exit is unchanged, so alternatives in different windows combine by induction even when the I_j overlap; distinct combinations give distinct inputs; prod_j D_j(y) <= |L_s(y)|. (iii) Since pi_j is injective and the window run depends only on (entry part of sigma_j, segment), every y' with sigma_j(y') = sigma_j(y) is an admissible alternative; E log D_j >= H(Y | sigma_j) = b - H(sigma_j), hence sum_j H(sigma_j) >= K b - (Lambda - b) and the average is >= b - O(N^{2mu-1} log N) for b = Theta(s), mu < 1/2. (iv) GRID-LA: b = r^2, row- and column-major orders; every injective arrangement has sum over grid edges of |pi(u)-pi(v)| = Omega(r^3) (each of the ~b/2 balanced cuts cuts Omega(r) edges; this is the classical Theta(r^3) minimum linear arrangement of the grid). In the single-copy static-storage model this gives t = Omega(N sqrt b). STRENGTH: H(sigma_j) <= 2|I_j| log|Gamma| + O(log tN), so (iii) gives only sum_j |I_j| >= Omega(N), no more than the reading time. EXCLUSION (director): let C = {x(y)} (consistent tables). The machine M_C that accepts exactly C satisfies every premise used ((i)-(iii) with L_s replaced by C, budget b - b = 0, the strongest case) and runs in DTIME1[O(N + b^2)]: store the prefix y, build a column-major copy once (O(b^2) naive), then check each repetition by one linear sweep against the copy of its order (O(b) per repetition). For b <= sqrt N (mu < 1/2) this is linear. Hence (1) the transfer of (iv) to arbitrary work-tape encodings is FALSE for this family (two copies beat the N sqrt b bound), and (2) MECHANISM EXCLUDED (on confirmation): a fixed repetition family plus counting of accepted hybrids plus cut-and-paste cannot give a superlinear bound for mu < 1/2. Any continuation must use the correctness of M on YES instances that M_C rejects.

R' are nonzero. Support lemma (seq 4071 argument) gives V_L, V_R disjoint and non-adjacent; dim L' + dim R' >= 2|V| - a - b and dim L' <= 2|V_L| give |D| <= p/2 for D = V minus (V_L u V_R); |V_L n S| <= (h + b)/2, |V_R n S| <= (h + a)/2. So every {0,1}-weighting has a w-balanced separation of order <= p.

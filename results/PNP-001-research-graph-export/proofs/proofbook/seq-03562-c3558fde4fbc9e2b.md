## Statement / proof text (verbatim)

BRIDGE STATUS (owner 2026-11-19, literature-checked): (1) A computation trace is NOT an UNSAT proof by itself (an always-UNSAT program has short checkable traces); it becomes one only together with a proof of the algorithm s correctness. Precise known form: if the correctness of a poly-time algorithm A is provable in the bounded arithmetic PV (S^1_2), then A s UNSAT answers translate into polynomial-size Extended Frege proofs (Cook 1975; Krajicek-Pudlak). An EF lower bound would therefore exclude all poly-time algorithms with PV-provable correctness, not all algorithms. (2) Cook-Reckhow: NP = coNP iff some propositional proof system is polynomially bounded; superpolynomial lower bounds for EVERY proof system give NP != coNP (hence P != NP); a lower bound for one system (PC, EF) does not, since existence of a p-optimal proof system is open. (3) Alekseev, A lower bound for polynomial calculus with extension rule (CCC 2021 version; owner cites 2026 journal version): exponential BIT-SIZE lower bound over Q for the Binary Value Principle 1 + x1 + 2x2 + ... + 2^(n-1)xn = 0 in PC with extension variables (and radical-type rules) - bit-level/coefficient size as the measured resource, not a CNF and not over GF(2). For ALG-BIT-001 (no new assignment): report the coefficient BIT SIZE of certificates alongside degree when working over Q/Z (e.g. integer-sum refutations of blind cores, which relate to the CG certificates).

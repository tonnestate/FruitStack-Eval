## Statement / proof text (verbatim)

JOINT-CONTROL-FLOOR (director, 2026-11-26; extends CHMY-SEED-FLOOR seq 17279 to the owner's proposal 'control the error of the whole state distribution jointly instead of per branching program'; CLAIMED). (1) What is needed is only ONE-SIDED: if M decides MCSP[s] correctly, it accepts every string of CC <= s and Pr_U[M=1] <= gamma := Pr_U[CC <= s] <= 2^{O(s log s) - N}; a contradiction follows as soon as Pr_G[M=1] < 1, i.e. G is a hitting set for the complement of M (density >= 1 - gamma). This is weaker than the two-sided 1/6 condition. (2) FLOOR for every analysis that uses only the decomposition M = OR_{alpha in A} P_alpha with each P_alpha a read-once BP of width <= w (any fixed order per alpha) and Pr_U[M=1] <= gamma: let H be the image of G (all CC <= s, so |H| <= 2^{O(s log s)} and |H| 2^{-N} <= gamma). A width-w ROBP in any fixed order accepts any prescribed set of <= w strings (one path per string, <= w distinct prefixes per level), so H is the union of ceil(|H|/w) such ROBPs; if ceil(|H|/w) <= |A| this OR is a member of the class, has acceptance measure |H| 2^{-N} <= gamma, and accepts all of H. Hence the analysis can succeed only if |H| > w |A|, i.e. s log s >= Omega(log w + log |A|). This holds for joint, one-sided, distribution-level error control (S0258/S0290-type compression of state distributions included) as long as the pieces are treated as generic ROBPs. (3) For CHMY Lemma 19, log(w |A|) = Theta(sqrt t log tq), so again mu >= 0.505 - o(1) at t = N^{1.01}. MECHANISM EXCLUDED (on confirmation): joint/one-sided error control over the Lemma-19 family with generic pieces. REQUIRED for mu = o(1) at the generator level: either a decomposition of O(1)-state time-N^{1.01} one-tape DTMs with log(w |A|) = N^{o(1)}, or an analysis using properties of M beyond 'OR of |A| width-w ROBPs' (its O(1) states / uniformity; by seq 17279 (c) the guarantee must fail at 2^{poly(s)} states). The transfer of the OpenAI Lemma 3.2 functional to TM transition matrices is not proved. The route uses MMW (Theorem 47), so it is not independent of QE*.

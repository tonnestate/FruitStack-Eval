## Statement / proof text (verbatim)

EXISTENCE ELIMINATION IN CLOSED FORM (owner checkpoint 2026-11-27, active focus 'effiziente Existenzeliminierung'; PI derivation; CLAIMED, Claude family). (1) Check of the owner identity. Over F3, (w-2)^2 = 1 for w != 2 and 0 for w = 2. So Q_G(lambda) = prod_i (z0_i + (B lambda)_i - 2)^2 is the indicator of z in {0,1}^N. Reduced forms in R = F3[lambda]/(lambda_k^3 - lambda_k) are the functions on F3^r, so F_E is satisfiable iff Q_G != 0 in R. Correct. Hardness of the target: G is 3-colourable iff prod_{ab in E} (lambda_a - lambda_b)^2 != 0 in R, which is the squared graph polynomial; this is Q-form with z = lambda_a - lambda_b + 2. So deciding Q != 0 in R is NP-complete, and an efficient evaluation is exactly P = NP; there is no weaker sub-target. E_i(Q) = 1 - prod_a (1 - Q|_{lambda_i = a}) is correct for {0,1}-valued Q: it is the OR over the fibre. (2) Closure lemma (proved). Write Q = 1 - 1_U, where U is the union of the affine hyperplanes H_i = {z_i(lambda) = 2}. For any union U of affine subspaces S_j of F3^r, E_i(1 - 1_U) = 1 - 1_{U'} with U' = cap_{a in F3} cup_j T_{j,a}, T_{j,a} = {mu : (mu, a) in S_j}. Each T_{j,a} is an affine subspace or empty. Proof: mu is bad iff every point (mu, a) of the fibre lies in some S_j. Distributing the intersection gives the union of T_{j0,0} cap T_{j1,1} cap T_{j2,2}, which are again affine subspaces. Subspaces with lambda_i-free equations (cylinders) pass through unchanged, which gives bucket locality. Hence SAT(F(G)) = (E_1 o ... o E_r)(Q_G) is computed without any 3^r normal form, as a sequence of unions of affine subspaces (RREF over F3, pruning by inclusion). SAT iff the final union is empty. (3) Machine check, scratchpad/aelim/ae.py and ae_exp.py: 0/200 mismatches against brute force on random 3-colouring instances (n 3..7), and 0/178 on the owner route (positive 1-in-3 SAT -> A z = 1 -> z = z0 + B lambda -> hyperplanes), r <= 9. (4) Cost is exactly the number of subspaces kept. It is bounded below by the affine cover number c(B_t) of the projected bad sets B_t, the partial assignments with no satisfying extension. c(B_t) is a semantic invariant independent of the representation and is the exact place where the method would fail. Measured peaks (4 seeds each; small sizes only, no asymptotic conclusion): random 1-in-3 at m = 0.62N, N = 15..60, peak N up to 3.4N; random 3-colouring at m = 2.3n, n = 8..18, peak <= 8.7n. Random 1-in-3 is believed easy (from memory, unverified), so it is not evidence of hardness or of ease. (5) Algebraic gain over plain variable elimination: subspaces such as {lambda_y = lambda_x + 1, lambda_z = lambda_x + 2} represent all-distinct colour patterns with codimension 2 instead of 6 codimension-3 points; for k = 3 this gives c = 2 instead of 6. OPEN, and the next step: a family where c(B_t) is superpolynomial for every elimination order (exact cause), or a class with polynomial c(B_t) beyond bounded treewidth (constructive gain). No lower-bound premise; no obligation closed.

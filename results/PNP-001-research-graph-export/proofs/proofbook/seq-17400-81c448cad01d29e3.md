## Statement / proof text (verbatim)

REVIEW TARGET W-STAR (owner request 2026-11-27: definition fidelity + novelty; CLAIMED until reviewed by a NON-Claude model family). THEOREM: G finite simple, I = (V x {1,2,3}) u (E x {1,2,3}), K_G subset GF(3)^I given by sum_c k(v,c) = 0 and k(e,c) = -(k(u,c) + k(w,c)) for e = uw; dim K_G = 2|V|. For a basis B = (b_j) of K_G let H_B be the graph on basis indices with j ~ k iff some coordinate i has b_j(i) != 0 and b_k(i) != 0. Then min_B tw(H_B) = 2 tw(G) + 1. Lower bound (proof-state Q-5f55fb62c2:S0009): (L1) nonzero t in GF(3)^3 with sum 0 has >= 2 nonzero entries; (L2) two subsets of {1,2,3} of size >= 2 meet; (i) S_v = {j : b_j nonzero on block v} is a clique; (ii) S_u u S_w is a clique for each edge; (iii) |union_{v in X} S_v| >= 2|X| (projection onto T^X is surjective); (iv) from a width-w decomposition of H_B, beta_G(t) = {v : S_v subset beta(t)} is a decomposition of G (Helly), so w >= 2 tw(G) + 1. Upper bound (S0012): natural basis has H_B = G[K_2], tw(G[K_2]) <= 2 tw(G) + 1.

## Statement / proof text (verbatim)

PI CHECK OF THE 2026-11-27 OWNER SYNTHESIS (elimination identities, lattices, Kempe, prism; CLAIMED, Claude family; Fable's review is also Claude family, so no cross-family review yet). (1) Elimination identities: correct. Q(t,u) = R(u) prod_{j<=d} (t - r_j(u))^2. For d <= 2, exists t with Q = 1 iff R = 1. For d = 3, three elements of F3 are pairwise distinct iff r1+r2+r3 = 0 and r1 != r2. If r1+r2+r3 = 0 and r1 != r2, then r3 = r1 would give r2 = -2r1 = r1. These are the 3-factor case of the closure lemma 17910: the bad set {sum = 0, r1 - r2 = 1} union {sum = 0, r1 - r2 = 2} consists of two codim-2 subspaces instead of six codim-3 points. (2) Union rule: U cup (v+U) cup (2v+U) = U + <v> over F3. Implemented as coset merging {Ax in b + <d>} = {CAx = Cb} with ker C = <d>, to a fixpoint, then pruning (scratchpad/aelim/merge.py). 0/150 mismatches against brute force. Peaks on random 3-colouring at m = 2.3n, n = 8..16, 3 seeds: 17-47 subspaces with merging against 27-115 without, about 2.2-2.9n. Small sizes only; no asymptotic claim. (3) Satz A, arbitrary order (owner strengthening): proof correct. Project to r coordinates injective on the Q-span; generators have entries in {-1,0,1}, so norm <= sqrt r. A rank step multiplies the covolume by at most sqrt r, a same-rank strict extension divides it by at least 2, and the final covolume is >= 1. So k <= (r/2) log2 r, and Fable's two-phase restriction is unnecessary. (4) Satz B, 3L <= M <= L: correct for unpinned graphs only. Fable's pinned counterexample is accepted: pinned prism, ranks 3 and 2 over Q. (5) Lemma F, general form: correct. If S is closed under global colour permutations, x + rho x + rho^2 x = 1 and q is invariant, then an affine q = Bx + b is constant on S in char != 3. (6) Universal prism transformation H(G), |V| = 7n+3, a_v = bottom vertex opposite R0 of prism A_v, b_v = bottom vertex opposite R1 of prism B_v, triangle v a_v b_v. (a) Each colour of v has exactly one extension (table checked by hand), so Col3(H) = 6 |Col3(G)|. (b) PI proof that each colour pair {c,c'} induces a connected subgraph in every colouring. A prism bottom vertex p_i of colour c is adjacent to R_{c'} if i = c'. Otherwise i is the third colour, and its bottom neighbour of colour c' sits at index c, hence is adjacent to R_c. Every original v of colour c has a neighbour in {a_v, b_v} of colour c'. So Kempe swaps are global transpositions and #Kempe classes = |Col3(G)|. (c) [L_H : M_H] = 3^r with r = rank_Q of the one-hot colouring differences of G: verified exactly (integer HNF) on 15 graphs, among them K3, C5, C6 and G = prism, where rank_F3 = 7 < rank_Q = 8 and the index is still 3^8. Upper bound proved: L/M is generated by the image of W ~ L_G (rank r) and killed by 3. Lower bound open: the prism readouts epsilon give only 3^{rank_F3}, which is insufficient for G = prism. The owner's tensor argument L/M ~ W (x) (T/J) has unproved steps (injectivity, the separate summand). So (c) is computational evidence plus a proved upper bound, not a theorem. (7) Relevance: the index is 3^{2n} already for edgeless G, so it carries no hardness. (8) First unproved statement of the strongest chain (Phase 3 of the owner plan): a property that polynomial-time selection S must have and that contradicts a proved theorem. None has been derived. Every consequence derived so far (selection, lattice generators, tropical value, elimination) relativizes (cf. 17590) or also holds for exponential-time algorithms. No obligation closed.

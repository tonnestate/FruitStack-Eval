## Statement / proof text (verbatim)

For every n >= 3 and every nonempty set F of distinct weight-3 clauses over variables 0..n-1: there is a GF(3) vector x with x_a+x_b+x_c = 1 (mod 3) for every clause {a,b,c} in F, taking exactly two distinct values, if and only if F has a 0/1 solution (exactly one variable equal to 1 in every clause). Proof: for distinct values a,b in GF(3) write x = a + (b-a) w with w in {0,1}^n. Then sum over a clause equals (b-a) * sum(w) mod 3, so the clause condition is sum(w) = (b-a)^{-1} = (b-a) mod 3 (sum(w) in {0,..,3}). If b-a = 1, this is 1-in-3 on w. If b-a = 2, sum(w) = 2 on every clause, i.e. sum(1-w) = 1, so 1-in-3 on z = 1-w. Both cases give a 0/1 solution of F. Conversely a 0/1 solution w gives x = w, which takes values {0,1} (exactly two values because each clause contains a 0 and a 1). Hence the set of GF(3) solutions using at most two values is nonempty exactly when F is positive 1-in-3 satisfiable.

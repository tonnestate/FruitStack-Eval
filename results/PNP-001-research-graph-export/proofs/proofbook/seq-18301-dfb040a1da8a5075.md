## Statement / proof text (verbatim)

PRE-CHECK + SUCCINCT TABLEAU (Meyer mechanism, contrapositive form; known technique, restated). Let M be a fixed deterministic exponential-time machine for an EXP-complete L. Call x c-succinct if the tableau function (t,i)->cell of M on x has a circuit of size <= |x|^c. If every x is c-succinct then L is in Sigma2^p: guess circuit C (size <= |x|^c), check forall (t,i) the local rules, the initial row = x and read the acceptance cell; determinism makes a locally consistent C equal to the true tableau. Hence P=NP (Sigma2=P) => EXP=P, contradicting the deterministic time hierarchy, so under P=NP: for every c there is an input x that is not c-succinct (an incompressible computation history). The compressibility needed for the pre-check route is therefore REFUTED under P=NP, not derivable from it; per-instance succinctness (circuit may depend on x) is weaker than EXP in P/poly but yields the same Sigma2 upper bound. No contradiction. A contradiction would need an independent source of succinctness for all instances; the universal Exact-One graph representation of an exponential computation has exponential size and supplies none.

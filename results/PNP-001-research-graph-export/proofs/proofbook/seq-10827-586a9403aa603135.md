## Statement / proof text (verbatim)

BARRIER GATE (target (8), width route). CHOPRS Thm 2 (arXiv:1911.08297, sec 1.3, fetched text): (B1-O) MCSP[2^{n^{1/3}},2^{n^{2/3}}] in Formula-O-XOR[N^{1.01}] with oracles of fan-in <= N^eps in the layer above the XOR leaves; (B3-O) InnerProduct on N bits is not computed by N^{2-3delta}-size Formula-O-XOR circuits with <= N^{2-3delta} oracle gates of fan-in N^delta, for ANY oracle. The locality barrier says lower-bound arguments of the B3/B4 type extend to such oracle circuits. Applied to the width route: the proved identity (Thm 8 eq.22, Lemma 10 eq.26) holds only for an oracle-free fixed linear kernel, and oracle gates remove the linear-overlap structure, so the identity does not transfer. STATUS: OPEN, neither YES nor NO. Not shown: the width argument is a localized argument (it has not been checked against the B3-O hypotheses for this exact method). Perfect-matching control: NOT CHECKED. Natural-measure test: NOT CHECKED. Decisive test: does a lower bound on the width of the restricted kernel survive when each linear gate is replaced by an arbitrary fan-in <= N^eps oracle gate? If it survives, the route is localized and blocked by the locality barrier; if it fails, the route is only as strong as the linear structure.

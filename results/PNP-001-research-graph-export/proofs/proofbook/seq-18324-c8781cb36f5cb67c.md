It separates DTIME(n) from NTIME(n); SAT in n log n with Cook-Levin gives only NTIME(n) in DTIME(n log n), which PPST does not refute; transformation cost must be controlled, as T59 NEW-3 already states. (2) OWNER DERIVATION, hand-checked: given a poly-time correct search algorithm W, define W_M: simulate a Turing machine M for |x| steps; if M has not halted use W, else output an invalid witness on a fixed family of satisfiable instances. W_M is globally correct iff M never halts, and all W_M share W's polynomial time order. Hence global correctness of poly-time search programs is undecidable and no computable N(code) exists such that correctness on all inputs up to N certifies global correctness (else the halting problem is decided). This is the halting argument of the dynamic pre-check discussion restated for search; it uses the hypothesised correct W as a subroutine. It does not contradict using correctness of the assumed W as a hypothesis.

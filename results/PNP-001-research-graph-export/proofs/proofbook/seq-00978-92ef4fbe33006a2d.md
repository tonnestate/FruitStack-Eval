## Statement / proof text (verbatim)

For positive 1-in-3, fixing a single variable never makes a GF(3)-consistent system inconsistent (the solution set is invariant under +lambda*j, so each coordinate takes all values). Hence the least depth of a case-split tree whose leaves are refuted by GF(3) consistency is 0 or >= 2; observed values 0, 2, 3 only (n=4..12). Open: the growth of this depth with n (needs a lower-bound argument, not samples); it is a measure for the algorithm class 'DPLL + GF(3) Gaussian elimination', not for circuits.

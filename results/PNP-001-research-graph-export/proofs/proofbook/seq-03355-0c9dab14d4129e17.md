## Statement / proof text (verbatim)

For every positive 1-in-3 formula F with n variables and at least one clause (each clause a 3-subset of {0..n-1}), with A the clause incidence matrix over GF(3) and b = all-ones: F is 1-in-3 satisfiable iff the affine system A x = b over GF(3) has a solution x in GF(3)^n that takes exactly two distinct values. Proof sketch: (=>) a 1-in-3 solution is a 0/1 vector with both values present, since each clause has one 1 and two 0s. (<=) if x takes values {a,b}, set y=(x-a)/(b-a) in {0,1}; then sum over a clause of x = (b-a)*sum(y) mod 3 = 1, so sum(y) = b-a mod 3, which forces sum(y)=1 if b-a=1 and sum(y)=2 if b-a=2; in the second case z=1-y has sum 1 on every clause.

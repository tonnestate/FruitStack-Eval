## Statement / proof text (verbatim)

For positive 1-in-3 clause sets, sat and cons3 depend only on the set of distinct nonzero incidence-column types. Variables with identical columns (twins, which lie in the same clauses) can be merged into one type variable T with Y_t in {0,1}. cons3: GF(3) solvability of A x = 1 is unchanged by duplicating a column. sat: each clause contains exactly one true variable, so the copies of a type contribute Y_t <= 1, and any copy can carry Y_t = 1. Consequence for Q-49d9cb2e75: multiplicities are irrelevant, so the rank-4 finiteness reduction only needs the set of column types, at most 15 nonzero types in GF(2)^4.

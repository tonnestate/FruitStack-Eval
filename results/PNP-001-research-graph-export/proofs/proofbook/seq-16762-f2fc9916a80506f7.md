## Statement / proof text (verbatim)

AF (conditional, replaces the size budget by a correlation budget): let beta in (0,1), eta>0. Assume (P1) a local PRG fooling De Morgan formulas of size s with error delta <= 2^{-gamma}/10, seed and per-bit circuit size <= N^{beta-eta}; (P2) a pseudorandom restriction rho with >= N^{beta+eta/2} stars such that, w.p. >= 0.9, the principal-formula forest Phi of C|rho (reused-gate leaves kept as never-restricted variables) has size <= s. Then Gap-MCSP[N^beta] has no gamma-almost-formula of size S. Proof: fix such rho; YES = G(z) o rho has circuit size <= N^beta, NO = random fill has circuit size >= N^{beta+eta/2-o(1)} w.p. 1-2^{-N^{Omega(1)}}, so Adv(C|rho) >= 1/2; by D4 some F_a of size <= s has advantage >= 2^{-gamma-1} > delta, contradicting P1. BUDGET: gamma <= log2(1/delta) - 4 instead of r + log2(2S+1) <= 3 beta log2 N; since any PRG needs seed >= log(1/delta), gamma can reach N^{beta-eta} (polynomial) instead of O(log N).

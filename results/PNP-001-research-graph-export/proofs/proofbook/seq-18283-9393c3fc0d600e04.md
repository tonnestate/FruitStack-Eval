## Statement / proof text (verbatim)

CORRECTION OF THE MODEL-TRANSFER STATEMENTS (T58 section D was false in one direction). Four models: (F) formal polynomial circuit over F; (E) evaluation on {0,1}-inputs of an F-circuit, i.e. an F-circuit that only has to agree with the polynomial on the cube; (S) Boolean semiring (or,and) evaluation of the polynomial with N-coefficients, i.e. monotone circuits; (B) general Boolean circuits with negation. Valid implications: F-circuit => E-circuit (same circuit). Over a FIXED finite field F_p: F-circuit of size s => Boolean circuit of size O(s log^2 p) for the F_p-valued function on Boolean inputs (arithmetic mod p simulated gate by gate). Monotone N-circuit (no subtraction, N-constants) => S-circuit via the semiring homomorphism N->B (Held-Karp for HC is of this kind). NOT valid: F-circuit => S-circuit. Counterexample: over F_2 Per_n=Det_n has polynomial-size formal circuits (division-free Berkowitz), while the Boolean-semiring evaluation of Per_n is the perfect-matching indicator whose monotone circuit size is n^{Omega(log n)} (Razborov 1985, EXTERNAL, cited from memory); subtraction/cancellation/char-2 identities have no semiring image. Lower bounds go the other way: LB(B) => LB(E over F_p) => LB(F). A formal lower bound (OpenAI) therefore implies NO Boolean-circuit or semiring lower bound; the missing step is exactly E vs F (circuits may compute g=f+sum(x_i^2-x_i)h_i). T58 statements 'formal upper bound => models 2,3 upper bound' are corrected to: => E yes; => B (finite field value) yes; => S only for monotone circuits.

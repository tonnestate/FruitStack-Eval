## Statement / proof text (verbatim)

QO1 UPPER BOUND UNDER NP in P/poly (derivation of the OPS21 Thm 1.4 mechanism, author Claude family): NP subset SIZE[n^a] => there is K=K(a) such that for EVERY s=s(n) with n <= s <= 2^{n/2}: Gap-MCSP[s/(cn), s] on N=2^n bits has circuits of size N*s^K (a.e.). Proof: s'=s/(cn). Greedy anti-checker: V_0 = all circuits of size <= s', Y_0 = empty. Step i: for every position y in [N] (a fixed wire x_y) evaluate an approximate count of |{C in V_i: C(y) != x_y}|/|V_i| given (Y_i, x|Y_i, y, x_y) - input length L = O(t n), Stockmeyer approximate counting is in BPP^NP subset Sigma_3 subset P/poly (Karp-Lipton chain) so size L^{a'}; a tournament over the N candidates picks the best (y, x_y): N*L^{a'} gates per step. Elimination: if CC(x) > s then for every nonempty V_i some y kills >= 1/3 of V_i (minimax on V_i: otherwise a distribution over V_i is correct w.p. > 2/3 on every input and the majority of O(n) samples computes x with size O(n s') <= s, contradiction); with approximation >= 1/4. Hence V_t = empty after t = O(s' log s') steps. YES (CC(x) <= s'): the circuit for x is never eliminated. Final test 'V_t empty' is coNP on L bits. Total t*N*L^{a'} = N*s^{K}, K = a'+2, independent of s and beta. With s = N^beta: g_beta(N) <= N^{1+K beta} for all beta in (0,1/2]. c is the constant from the majority step (not necessarily 10).

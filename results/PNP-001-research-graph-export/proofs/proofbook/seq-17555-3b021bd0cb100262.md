## Statement / proof text (verbatim)

CONSTANT-TEMPERATURE CORRELATION AMPLIFIER (owner 2026-11-27; PI check of every bound; exact M^3 by fractions; CLAIMED, Claude family). Input: G_phi from the switch-vertex construction (17497/17506), always 3-colourable, n vertices, with a pair (u,v) such that phi in SAT iff some proper colouring has sigma(u) = sigma(v) (the pair (t,T) of 17497 (3)). STEP A: add r = 2n+3 new vertices, each adjacent to u and v. Then Z(0) = 2^r A + B (A, B = colourings with equal or different colours at u, v; A+B <= 3^n). UNSAT: A = 0, so p_r = 0. SAT: p_r >= 2^r/(2^r+3^n) >= 8/9, since 2^{2n+3} >= 8*3^n. STEP B: T = 1/ln 2, so the conflict weight is 1/2 and M = J - I/2. M^3 = (1/8)[[41,42,42],...] (eigenvalues 125/8 and -1/8); M^2 has ratio 9/8 > 1, so an odd length is required. Replace each of the |E| edges of the N-vertex amplified graph by k = 42(2N+4) internally disjoint paths of length 3. The marginal on the original vertices is then proportional to q^{H(tau)} with q = (41/42)^k <= e^{-(2N+4)}. Proper colourings exist, so the conflict mass is <= 3^N q < 0.0075 < 1/16. RESULT: UNSAT gives P(sigma(u)=sigma(v)) <= 1/16; SAT gives >= (15/16)(8/9) = 5/6. The graph has size O(|E| N k) = poly(n). Hence approximating this two-point correlation at fixed T within additive error < 37/96 is NP-hard under polynomial-time many-one reductions. STRENGTH: relative hardness only, with unbounded degree. Known-type: inapproximability of the antiferromagnetic Potts model beyond uniqueness, already for bounded degree (Galanis-Stefankovic-Vigoda; from memory, verify), is stronger. No unconditional lower bound and no obligation closed.

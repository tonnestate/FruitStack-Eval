## Statement / proof text (verbatim)

ACCEPTANCE-TRIE (owner derivation 2026-11-26, director check; CLAIMED). Setting of seq 17306/17314: for an accepting crossing signature alpha (crossing records include state, time and input-head position), R_alpha = prod_j R_{alpha,j}, a_{alpha,j} = |R_{alpha,j}|, sum_alpha prod_j a_{alpha,j} = A (accepted inputs, disjoint by determinism). VERIFIED BY AUTHOR: (i) the trie of R_{alpha,j} has <= a_{alpha,j}+1 nodes per level (reject sink included), so w_{alpha,j} <= min(2^{O(B+log t)}, a_{alpha,j}+1); (ii) the per-alpha ROBP reads the parts J_{alpha,1}, J_{alpha,2}, ... one after another (legitimate: Forbes-Kelley fools arbitrary-order ROBPs) and collapses to accept/reject at part boundaries, so its width is max_j w_{alpha,j}; (iii) splitting each R_{alpha,j} into ceil(a/2^h) pieces of size <= 2^h gives an exact disjoint OR of K'(h) = sum_alpha prod_j ceil(a_{alpha,j}/2^h) ROBPs of width <= 2^h+1, and K'(h) = sum_alpha |R_alpha| 2^{-Phi_h(alpha)} = A E_X[2^{-Phi_h}] (X uniform on accepted inputs), log(w'K') <= h + 1 + log A - P(h). NEW LOWER BOUND (director): ceil(a/2^h) >= 1, so K'(h) >= K_acc := number of accepting signatures with R_alpha nonempty >= 2^{H(alpha(X))} for EVERY distribution X on accepted inputs; hence log(w'K') >= max(h, log K_acc). Replacing prefixes by residual (Myhill-Nerode) classes lowers the width further but leaves K' >= K_acc unchanged. CONSEQUENCES: (1) the trie attacks only point 1 of seq 17306 (width), never point 2 (crossing count); with the floor of seq 17284(2) any success needs s log s >~ log K_acc. (2) With seq 17314 on the Lupanov family: K_acc >= 2^{(rb-L)/(r-1)}, so for multiplicity r > L/b the trie gives no gain over the floor regime. (3) Jensen: P(h) <= E Phi_h <= E sum_j min(h, log a_{alpha,j}) <= E log|R_alpha| = log A - H(alpha(X)). So log(w'K') = N^{o(1)} REQUIRES (a) H(alpha(X)) <= N^{o(1)} and (b) E sum_j min(h, log a_{alpha,j}) >= log A - N^{o(1)} with h = N^{o(1)}: a typical accepted input has >= N^{mu-o(1)} information-carrying parts, each with <= 2^{N^{o(1)}} local completions, while its whole crossing signature has N^{o(1)} bits of entropy, i.e. the accepted set is up to 2^{N^{o(1)}} pieces a union of products with tiny factors and M is almost oblivious on accepted inputs across N^{mu} block visits. (4) The trade-off moves from the block length B to the local acceptance sizes: one block gives K_acc = 1, a = A, log w' = log A, which is exactly seq 17284(2). (5) The folded Cor-17 machine (seq 17279 (c)) is a correct decider, so (a)+(b) fails for it; a proof of (a)+(b) must use q = O(1). PRIOR ART: EXT prefix trie (owner 2026-11-20, seq 5364, 5389), D_t <= |Im|+1 (seq 10124, 17263), global trie decomposition (seq 17284(2)), residual classes (seq 6652, 12810, 13706). New: the per-part application, the K'(h) identity and the bound K' >= K_acc. Not a gap closure.

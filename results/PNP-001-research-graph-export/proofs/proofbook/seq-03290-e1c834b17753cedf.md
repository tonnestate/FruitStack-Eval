## Statement / proof text (verbatim)

For every positive 1-in-3 CNF formula F with at least one clause over variables x_0..x_{n-1} (each clause a 3-element set of variables), let A be the clause-variable incidence matrix over GF(3). Then F is satisfiable (some 0/1 vector has exactly one 1 in each clause) if and only if the affine system A x = 1 over GF(3) has a solution x taking exactly two distinct values.

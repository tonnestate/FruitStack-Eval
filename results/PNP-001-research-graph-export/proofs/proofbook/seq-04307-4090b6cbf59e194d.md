## Statement / proof text (verbatim)

Reduction lemma: an unused variable u in a positive 1-in-3 clause set F on n variables is free in every 0/1 and GF(3) condition. So F is GF(3)-blind with nullity k on n variables iff F restricted to the other n-1 variables is GF(3)-blind with nullity k-1 and covers them. Consequence: the kernel type of every unused-variable blind nullity-2 formula is forced to be (n-1)-1 whenever the reduced nullity-1 kernel vector has full support on the n-1 used variables. This full-support property holds for all 1,350 covering blind nullity-1 formulas at n=6 (m=4..7), which gives the 6-1 type at n=7. Whether full support is forced for all n is open.

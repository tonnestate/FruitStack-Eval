## Statement / proof text (verbatim)

T48 addendum sec.8 (owner's derivation, PI check). CLAIMED; cross-family review pending.
(Owner correction) Prop5.2 was checked against the literature. Second proof: IKW (NEXP in P/poly => NEXP=MA) and P=NP => MA in Sigma2 = P, which contradicts the hierarchy. Q-BD is excluded as a direct route to a contradiction with P=NP.
Thm8.1 (owner, checked): for a circuit D with s gates over F2, D^2-D = sum_i Q_i (x_i^2-x_i) formally, with all Q_i computed by one circuit of size O(s). Proof: e(a)=a^2-a; XOR: e(a)+e(b) (char 2); NOT: e(a); AND: b^2 e(a) + a e(b); backward weight propagation, O(1) per edge. Existence is trivial (I is the vanishing ideal); the content is the size O(s). The table holds only in char 2 and differs in char 3.
Cor8.2: C_n = E AND NOT E = E^2-E gets an O(s) certificate, checked by one formal identity test (coRP). The A2 counterexample of Thm4 is no barrier for A2 + formal identity + defect certificates; the Thm4 barrier still holds for A2.
Classification (search; full texts not read yet): certificates sum g_j f_j + sum h_i(x_i^2-x_i) measured by circuit size are the Grochow-Pitassi Ideal Proof System (FOCS 2014/JACM). It p-simulates Extended Frege; superpolynomial IPS lower bounds for tautologies imply VP != VNP. Thm8.1 is a linear-size IPS certificate for the Boolean defect; novelty is not claimed.
Prop8.3: Cor8.2 uses only the syntactic form E(1+E). For C' = E AND E~ (E~ a structurally different circuit for NOT E), a compact certificate of E+E~+1 in I (circuit equivalence) is needed. A uniform barrier for pieces+IPS would be an IPS lower bound, which implies VP != VNP; so for the extended class neither a saving proof nor an attainable barrier exists without algebraic circuit lower bounds. This is a classification, not a premise.
Q-BD consequence: separate the full normal form (ParityP-hard) from a compact certificate (Thm8.1). A saving needs polynomial-size certificates for the zero pieces on <= 2^n/n^{omega(1)} pieces, and an efficient way to find them (a search problem); this is open.

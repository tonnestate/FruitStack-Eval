## Statement / proof text (verbatim)

QO2 WEAKEST SUFFICIENT QUANTIFIER FORM Q*: if for every K >= 1 there is a size function s_K (n <= s_K <= 2^{n/2}) such that Gap-MCSP[s_K/(cn), s_K] has no circuits of size N*s_K^K for infinitely many n, then NP notsubset P/poly, hence P != NP (contrapositive of QO1). Special cases: Q1 (exists eps, all small beta: g_beta notin O(N^{1+eps})) => Q2 (for all k, delta exists beta < delta: g_beta notin O(N^{1+k beta}); take beta < min(delta, eps/k)) => Q* (s_K = N^beta). Q3 (fixed s = n^c, g notin O(N log^k N) for all k) => Q*. Lower bounds whose exponent ratio eps(beta)/beta is bounded (eps = beta, 2 beta) do NOT suffice since K is unknown; eps = sqrt(beta), beta log(1/beta) or N*(log N)^{omega(1)} at s = polylog do. LOCALITY (CHOPRS20): the QO1 circuits are N*poly(s) wires into fan-in-poly(s) PH predicates, so any proof of Q* must fail against such oracle circuits.

## Statement / proof text (verbatim)

statement: Lemma (restriction-independent gates survive). Let C be a fan-in-2 Boolean circuit on variables X∪Y, and let g be a gate whose computed Boolean function depends only on Y. For every assignment a to X, the gate function after restricting X=a is the same function h(Y). If h is nonconstant, g remains nonconstant. Proof: write the gate function as h(Y). Substitution of a for X changes no argument of h, so the restricted gate still computes h(Y). Since h is nonconstant, it remains nonconstant for every a.

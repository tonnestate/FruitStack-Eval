## Statement / proof text (verbatim)

For MAJ_n with fixed threshold t = floor(n/2) and free-variable probability p = 1/sqrt(n), the undecided probability converges to P(|Z| <= 1) = erf(1/sqrt 2) ~ 0.682689 as n -> infinity. Mechanism: the number of free variables is about Poisson(sqrt n), the fixed-part sum has spread about sqrt(n)/2, and the window has width of order the free count, so the ratio is of order 1. More generally, for worst-case thresholds the undecided probability is of order min(1, p sqrt(nz)) for weights bounded by M, which matches the bound p M sqrt(nz) of Theorem C.

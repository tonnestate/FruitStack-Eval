## Statement / proof text (verbatim)

LOST-RELATIONS QUOTIENT FOR AFFINE ROW SPACES (owner derivation, checked by Claude). V vector space (or module over any commutative ring), R_1..R_m subspaces, pi: V->W linear, K=ker pi. Then ( (sum R_i) ∩ K ) / sum_i (R_i ∩ K) is isomorphic to A/B with A=ker(⊕pi(R_i) -> W, sum), B=(⊕pi)(ker(⊕R_i -> V, sum)). Proof: lift (w_i) in A to r_i, s=sum r_i lies in K; lifts differ by R_i∩K so the map A -> quotient is well defined; surjective since s=sum r_i gives w_i=pi(r_i) with sum w_i=0; kernel: sum r_i = sum a_i (a_i in R_i∩K) iff (r_i-a_i) in ker(sum), i.e. (w_i) in B. m=2 gives pi(R1)∩pi(R2) / pi(R1∩R2). Numerically verified: dimension identity on 3000 random pairs each over GF(2),GF(3),GF(5) (0 mismatches, ~40-50% nontrivial) and on 5000 random m=2..4 families over GF(2),GF(3) (0 mismatches); owner's 3-system GF(2) example: all pairs consistent, triple inconsistent. Status: elementary exactness (Mayer-Vietoris/snake lemma type); NOT searched in literature, novelty unverified. Syzygy reading: decompositions of a fixed s form a torsor under Syz=ker(⊕R_i->V); translation by a syzygy preserves the formal identity, composes (group), inverts, localises (support on chosen rows) and embeds by zero padding when a system is added; the interface vector changes by an element of B, so the obstruction class [A/B] is the invariant of the certificate. Optimisation: for m=2 the minimum number of shared variables touched by a certificate equals min Hamming weight in the coset w+pi(R1∩R2), i.e. nearest-codeword; reduction checked by brute force on 230 random instances (scratchpad/cert/mv3.py); existence/decision is linear algebra (P), optimisation is NCP (NP-hard, RECALLED Arora-Babai-Stern-Sweedyk/Dumer-Micciancio-Sudan, not opened). Nonlinear transfer NOT proved: the proof works verbatim for systems linear in the shared auxiliaries with polynomial coefficients in visible variables (modules over F[x]), but not for ideals with products of auxiliaries.

## Statement / proof text (verbatim)

SHIFT-LEMMA19 (owner derivation 2026-11-26 from Viola's proof behind CHMY Lemma 19, director check; CLAIMED; model DTIME1: one-way read-only input tape, two-way work tape, CHMY l.146). Checked: (1) each work-head move crosses exactly one boundary of exactly one shift class d, so sum_d C_d(x) <= t, E_d C_d <= t/B, Pr_d[C_d > R] <= eta for R = ceil(t/(B eta)). (2) For fixed d a crossing record alpha (time-ordered, all boundaries) with l <= R entries (direction, state with current input symbol, input position) determines the block index (start block from d, then +-1 per crossing); input positions are non-decreasing, so K <= sum_{l<=R} (2q')^l binom(N+l, l), log K = O(R log(2q'(1+N/R))). (3) P_{d,alpha} simulates the block visits block by block, reading the input intervals in the order given by alpha (unknown-order read-once), storing one block (B cells), the state and a pointer into alpha: log w = O(B + log t). (4) F = (1/B) sum_d sum_{|alpha|<=R} P_{d,alpha}; determinism gives at most one consistent accepting alpha per d, so F = M Pr_d[C_d <= R] and 0 <= M - F <= eta pointwise; |E_G M - E_U M| <= eta + K delta. QUANTITATIVE (director): with B = sqrt(t log N), constant eta and q: R = Theta(sqrt(t/log N)), log K = Theta(sqrt(t log N)), log w = Theta(sqrt(t log N)), against Viola/CHMY O(sqrt t log(tq)): a gain of a factor sqrt(log N), so mu >= 0.505 - o(1) remains at t = N^{1.01}. STRUCTURAL CONSEQUENCE: even with zero cost for the input positions, log K >= R >= t/(B eta) while log w >= B (one block content), so max(log w, log K) >= sqrt(t/eta): compressing positions and states can remove at most the log factor; a polynomial gain needs a decomposition that either does not store a whole block content (log w << B) or has far fewer crossings than t/B - i.e. a different decomposition, not a better encoding of the crossing record. Consistent with JOINT-CONTROL-FLOOR seq 17284 (floor log(wK) for term-generic analyses). Novelty not checked; not a gap closure.

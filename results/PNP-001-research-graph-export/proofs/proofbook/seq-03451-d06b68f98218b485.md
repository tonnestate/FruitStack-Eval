## Statement / proof text (verbatim)

If for some fixed t the one-round closure K_t(C) is empty for every UNSAT positive 1-in-3 formula C (any n), then UNSAT has polynomial-size certificates: the cut list (O(n^t) cuts, each with a rounded right-hand side from one LP) plus an LP infeasibility certificate, checkable in polynomial time. Hence NP = coNP. So the n=6 pattern can only persist if the t-bounded closure is a poly-time UNSAT certificate, which would be a very strong structural result. Expectation: it fails at some n, and the smallest failure is the informative object.

## Statement / proof text (verbatim)

Divisibility obstruction: if every variable of a positive 1-in-3 instance lies in exactly d clauses (d-regular), then satisfiability forces d | m. Proof sketch: each clause has exactly one true variable, so the number of (clause, true variable) incidences is m, and it also equals d*|T| for the true set T. Hence d*|T| = m. The condition is necessary, not sufficient.

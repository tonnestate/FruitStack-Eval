## Statement / proof text (verbatim)

For every minimal unsatisfiable positive 1-in-3 family F (any n): blind(F) = 1 iff rank_GF(3)(A_F) = |F|, where A_F is the |F| x n incidence matrix over GF(3). Direction (consistent => full rank) is the lemma in claim:b55c125ec23e (proved by hand: a left-kernel vector d with d^T b = 0 and a minimal-core solution of F minus T0 force the sum over T0 to equal 1). Converse is linear algebra: full row rank makes A surjective, so Ax = b is solvable. Consequence: a minimal core with rank < |F| is GF(3)-inconsistent, and so carries a linear mod-3 certificate d with d^T A = 0, d^T b != 0. The 'blind' cores (no 0/1 point, GF(3)-consistent) are exactly the full-rank minimal cores.

SUPPLEMENT TO 17921: PRISM RANK, BLOCK ENCODING AND EXACT OVERLAP GRAPH (owner derivations 2026-11-27; PI checks and implementation; CLAIMED, Claude family). (1) Rank correction (owner). The prism equations top-sum, bottom-sum, d0 = d1, d1 = d2 are dependent, because (d0-d1) - (d1-d2) = d0+d1+d2 over F3. Normal form: t0+t1+t2 = 0, d0 = d1, d1 = d2, t0 != t1, d0 != 0; 3*2*2 = 12 colourings. 17921 adds all triangle equations and lets rref take the rank. The measured rank deficit equals the number of prisms exactly: K3-H 23 equations, rank 17, 6 prisms; P3-H 22/16/6; C5-H 36/26/10. This confirms the correction; the linearization and solution sets are unaffected. (2) Block encoding (owner). Pinned R = (0,1,2), p = dA, q = dB in {1,2}: a = p, b = 1+q, x = -1-p-q. Exactly (p,q) = (2,1) is forbidden; (1,1) -> 0, (2,2) -> 1, (1,2) -> 2. Edges of G become p_u+q_u != p_w+q_w; all other gadget variables are eliminated by affine substitution. Implementation scratchpad/aelim/block.py; the decoded solution set equals Col3(G) bijectively on 150 random graphs (0 mismatches). Hybrid elimination on the block form (vars 2n; start = 3n + m forbidden subspaces): K3 12 -> peak 12, P3 11 -> 11, C5 20 -> 20 (SAT); K4 18 -> peak 22 (UNSAT, grows). G itself needs only m. The block form is exact and needs no per-node gadget elimination, but it is not smaller than G. Observation (PI): with p' = p-1, q' = q-1 in {0,1}, the forbidden pair is (1,0), so the constraint is p' <= q' and the colour is -(p'+q'). The prism gadget is a thermometer (order) encoding of a ternary variable; the name 'order encoding' is from SAT practice, cited from memory. (3) Overlap theorem (owner). The primal graph of the residual constraints p_v != 0, q_v != 0, p_v - q_v != delta, p_u+q_u != p_w+q_w is H_rest = G[K2] (lexicographic product) for pinned R, and K1 join G[K2] for free delta = R1 - R0. The remaining reference coordinate (global translation) is isolated. Proof: edge constraints give complete bipartite joins between adjacent blocks; the block constraint gives p_v q_v; delta occurs in every block constraint. Check: primal graphs computed from the implemented constraints equal G[K2] and K1 join G[K2] on 200 random graphs with n <= 7, including isolated vertices (scratchpad/aelim/overlap.py; 0 mismatches). Width consequence: a universal vertex raises treewidth and pathwidth by exactly 1, so tw/pw(free) = tw/pw(G[K2]) + 1. From memory, unverified: tw(G[K_t]) = t(tw(G)+1) - 1, giving 2 tw(G) + 1 for pinned R. (4) Meaning: the overlap pattern G K_2 of USCCL-NL (17585) reappears exactly in the reduced prism representation. Two independent routes, the kernel parametrization and the implemented elimination, give the same graph structure. This holds for the stated parametrization before graph-dependent simplifications such as linearizing G's own triangles. USCCL is used only as min_B mu(H_B) = mu(G K_2). Not a computational lower bound; no obligation closed.

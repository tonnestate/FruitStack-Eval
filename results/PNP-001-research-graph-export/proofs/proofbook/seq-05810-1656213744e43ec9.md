## Statement / proof text (verbatim)

SYSTEM ZH-PS (stated exactly): input D_0 = Diag(F), one tensor node per clause of a positive 1-in-3 CNF F over Boolean x (EXACT1 tensor, arity 3; diagram size linear in |F|, so no input blow-up). A ZH-PS refutation is a sequence D_0 -> ... -> D_k where each step applies one rule from a fixed finite rule set R (each rule a tensor identity valid for all values of its open wires, recognisable in polynomial time) and D_k is the scalar 0. Soundness: T(D_0) = indicator of satisfying assignments summed, so D_k = 0 with sound rules implies F unsatisfiable. (a) CONDITIONAL: if ZH-PS is polynomially bounded for all UNSAT CNFs then NP = coNP (Cook-Reckhow). It does NOT give P vs NP. (b) SUB-SYSTEM CONTRACT-PS: R restricted to pairwise contraction along shared wires (bucket/variable elimination). Its minimal refutation length under the maximum-intermediate-tensor-size measure is an exact contraction-width quantity, which is a known treewidth/branchwidth-type measure. Scope: positive 1-in-3 CNFs with n <= 8.

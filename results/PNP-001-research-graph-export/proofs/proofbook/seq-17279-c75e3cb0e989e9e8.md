## Statement / proof text (verbatim)

CHMY-SEED-FLOOR (director, 2026-11-26; owner task 'improve the CHMY/Forbes-Kelley generator'; CLAIMED). Inputs: CHMY (ECCC TR20-103, local literature/sources/eccc-TR20-103) Lemma 19 (l.718: q-state time-t one-tape DTM = sum over alpha in A of ROBPs P_alpha of width exp(O(sqrt t log tq)), |A| <= (tq)^{O(sqrt t)}), Corollary 39 / Theorem 20 (generic ROBP PRG with error eps' = eps/|A|), Theorem 47 (needs MCSP[2^{mu n}] not in DTIME1[N^{1.01}] for a SMALL mu > 0), Corollary 17 (l.657, unconditional: MCSP[s] in DTIME1^O[N poly(s)] for some O in Sigma3^P, queries of length poly(s)), Lemma 21 (oracle queries of length l and fixed coins folded into q 2^l t states); SEED-FLOOR seq 17150 (support M => some AND of floor(log2 M)+1 literals has error >= 2^{-t}). (a) LEMMA: every distribution whose samples all have CC <= s and which eps'-fools all n-input ROBPs of width >= 2 satisfies s log s >= Omega(log(1/eps')). Proof: support <= #circuits of size s = 2^{O(s log s)}; an AND of literals is a width-2 ROBP; apply SEED-FLOOR. (b) In the CHMY architecture eps' = eps/|A| = eps (tq)^{-Theta(sqrt t)}, hence s >= Omega~(sqrt t log(tq)). For t = N^{1.01}, q = O(1): s >= N^{0.505-o(1)}, i.e. mu >= 0.505 - o(1), while Theorem 47 needs mu below the small constant of MMW. Forbes-Kelley (Theorem 38: seed O~(log(nw/eps')) log^3 n = O~(sqrt t log tq)) is already optimal in this architecture up to polylog factors. MECHANISM EXCLUDED (on confirmation): improving the generator recursion G_{i+1} = D_i xor (T_i and G_i), or any generic ROBP PRG, inside the Lemma-19 union-bound architecture, as a route to small mu. (c) Further unconditional constraint from Corollary 17 + Lemma 21 (deterministic Sigma3 oracle machine, no coins): no distribution on strings of CC <= s fools all (2^{poly(s)})-state DTMs of time N poly(s) (the folded Corollary-17 machine accepts all of them and rejects almost all uniform strings). Hence any improved generator for small mu must have a guarantee that FAILS at q = 2^{poly(s)} states, i.e. it must use that the attacked machine has few states. SURVIVING constructive directions (not lanes, recorded for the owner task): (i) a decomposition of time-N^{1.01} one-tape DTMs into <= 2^{N^{mu}} pieces (replacing Lemma 19's (tq)^{sqrt t} crossing-sequence guesses), or (ii) an analysis that fools the specific machine without the union bound over A (cancellations among P_alpha), in both cases exploiting q = O(1).

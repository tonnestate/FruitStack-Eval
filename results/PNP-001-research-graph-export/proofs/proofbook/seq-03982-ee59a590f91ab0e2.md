## Statement / proof text (verbatim)

Exact lemma (short proof): for a positive 1-in-3 clause set S, sat(S)=1 iff the GF(3) affine solution set of A x = 1 contains a 0/1 vector. Proof: a 0/1 solution of the integer system satisfies the GF(3) system. Conversely, a 0/1 vector with every clause sum congruent to 1 mod 3 has clause sum 1, because a sum of three bits lies in {0,1,2,3}. So the non-linear question is membership of {0,1}^n in an exact affine GF(3) space. For n=6 with rank3=5 the solution set has exactly 3 points, so the 0/1 test is a 3-candidate check. Mechanism for the counterexamples: cons3=1 and sat=0 occur exactly when none of the 3 points is 0/1.

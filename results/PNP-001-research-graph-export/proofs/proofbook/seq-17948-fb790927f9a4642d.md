## Statement / proof text (verbatim)

T48 (theory/T48-gate-algebra-simultaneous-linearization-cancellation-2026-11-27.md). CLAIMED, Claude family; cross-family review pending.
Thm1 (owner's simultaneous linearization) checked: min cover of a layer g_i=a_i b_i with all gates affine = 2^{r_*}, r_* = min dim span{l_i in {alpha_i,beta_i,alpha_i+beta_i}}. Lemma 1.1: ab is affine on p+W iff alpha|W, beta|W are dependent; the case alpha=beta uses the Boolean identity a^2=a. r_*<=k is an NP predicate; efficient computation is open.
Prop2.2: the polar-form characterization (B_Q|W=0) is exact only for deg<=2. For deg>=3 the condition depends on the coset (x1x2x3, W=<e1,e2>). Prop2.3: multiplicative depth 1 is solved in poly time by Dickson, so linearization pays off only from depth 2 onward.
Thm3 (cancellation dichotomy): formal zero test in coRP (Schwartz-Zippel over F_{2^{s+2}}); Boolean zero test (mod x^2+x) is coNP-complete; coefficient of x1...xn in NF(C) = parity of #SAT, so the exact normal form is ParityP-hard; deg NF(C|P)<=k is coNP-hard (C*y1..y_{k+1}). Direct output analysis = Boolean ideal membership on pieces = Q-BD itself.
Thm4 (limit of A2): Li ECCC TR23-023 Thm1.7, VERIFIED AT THE SOURCE: for every constant eps there is an explicit affine extractor for entropy >= c log n; eps=1/4 gives an affine disperser with d=c log n. This closes the literature item of 17938. For C_n = E AND NOT E (unsatisfiable, poly size), every A2 algorithm (affine pieces, every gate of degree <=2, any adaptive/simultaneous/merging cover) needs >= 2^{n-2c log n-1} pieces. Hybrid pieces A minus union of B_j are open. This is a statement about an algorithm class, not a general lower bound; it is consistent with P=NP.
Prop5.1: Q-BD with propagation-complete backdoor <=> Circuit-SAT in 2^n/n^{omega(1)} poly(s) for poly-size circuits (Williams' hypothesis); direction <= by a unit-propagation circuit. Q-BD is therefore not an easier intermediate problem.
Prop5.2: P=NP => NEXP not in P/poly (Sigma2=P; Meyer/Karp-Lipton: EXP in P/poly => EXP=Sigma2; time hierarchy; classical, from memory). So the Williams route can never supply the contradicting consequence K.
Sec6: under P=NP the gate algebra yields only relativizing NP-predicate consequences (r_*, minimal covers, Boolean membership), which hold in the AW world (17590). The chain 'Thm4 + simulation of all poly-time algorithms in A2' has a premise S that is equivalent to P!=NP (vacuous if P!=NP), so it is an equivalent formulation and a forbidden transfer, not a route.
Open: (Q-BD) a saving mechanism for Boolean ideal membership outside A2 and outside formal identity (= Williams' hypothesis); (P!=NP) unchanged from 17920/17929: a consequence K of P=NP with a non-relativizing step whose negation is proved unconditionally. P!=NP has not been proved.

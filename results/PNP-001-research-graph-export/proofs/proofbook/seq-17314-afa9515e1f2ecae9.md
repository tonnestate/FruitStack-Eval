ENTROPY-BALANCE (owner derivation 2026-11-26, director check; CLAIMED). Setting: Y uniform on {0,1}^b, x_j = Y_{l(j)} (l surjective, Lupanov-type addressing so that CC(x) <= s for every Y, b = Theta(s log s)); M a correct MCSP[s] DTIME1 machine, accepted set of size <= 2^L, L = O(s log s); A = crossing signature (seq 17306 decomposition), R_alpha = accepted inputs with signature alpha = product of R_{alpha,j} over the block-visit parts J_{alpha,j} (cut-and-paste for a fixed blocking), disjoint over alpha. VERIFIED: (i) x|_{J} <-> Y_{l(J)} is a bijection, so log|R_{alpha,j}| >= H(Y_{I_{alpha,j}} | A = alpha); (ii) chain rule and monotonicity give >= sum_{i in I} h_i(alpha), h_i = H(Y_i | Y_{<i}, A = alpha); (iii) Z = (alpha ~ A, then uniform on R_alpha): H(Z) = H(A) + E log|R_alpha| <= L; (iv) H(Y|A) = E sum_i h_i = b - H(A). Hence L >= b + E sum_i (c_i(alpha) - 1) h_i(alpha) and, with multiplicity c_i >= r, H(A) >= (r b - L)/(r - 1). CEILING (director): since H(A) <= H(Y) = b, the balance can force at most H(A) close to b = Theta(s log s); a contradiction with a machine needs a blocking whose crossing record carries fewer than b bits (log K < b = N^{mu+o(1)}) while every information bit has multiplicity r > L/b (a constant, about 2 for Lupanov counting). Multiplicity >= 2 requires the copies of each Y_i to be read in >= 2 distinct blocks, so a machine whose work head stays in one block (block length >= its work space) has r = 1 and the balance reduces to the trivial L >= b. Generic time-t bound: log K = Theta(sqrt(t log N)) (seq 17306), so the balance reproduces exactly the CHMY regime s log s >~ sqrt t (mu > ~0.505 at t = N^{1.01}). NECESSARY USE OF q = O(1): for the folded Corollary-17 machine (seq 17279 (c); Sigma3-oracle answers folded into 2^{poly(s)} states, a correct MCSP[s] decider) every crossing entry carries poly(s) >= b bits and zero crossings give r = 1, so the balance yields no contradiction for it - any successful use must exploit that crossing entries of an O(1)-state machine carry O(log N) bits. PRECISE FORM of the owner's next step (recorded, not a new obligation): an address map l such that every O(1)-state time-N^{1.01} DTIME1 machine admits a blocking with fewer than N^{mu+o(1)} / log N crossings and multiplicity > L/b. Type: an information-complexity form of the crossing-sequence / rectangle (cut-and-paste) argument; novelty not checked. Not a gap closure.

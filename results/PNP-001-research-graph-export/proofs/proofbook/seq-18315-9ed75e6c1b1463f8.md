## Statement / proof text (verbatim)

NONLINEAR/BOOLEAN FORM OF THE QUOTIENT IDENTITY (owner derivation, checked). (i) S=F[x], R=S[z], ideals I_i of R: the module theorem of 18308 applies with pi:R->R/S (S-linear, kernel S); (sum I_i)∩S / sum(I_i∩S) = A/B, i.e. it compares the elimination ideal of the sum with the sum of the elimination ideals, for arbitrary (nonlinear) ideals. Only additivity of pi is used. (ii) Boolean ring on X x Z: ideals <-> subsets, I_i=functions vanishing on V_i, P_i=proj_X V_i, Q=proj_X(intersection V_i); (sum I)∩S = functions on X vanishing on Q, sum(I_i∩S)=functions vanishing on the intersection of the P_i; hence A/B = F2^L with L=(intersection P_i)\Q = {x: every fibre Y_i(x) nonempty, intersection of fibres empty}, dim = |L|. Checked by explicit F2 linear algebra: 740 random families (|X|,|Z| in {(2,3),(3,2),(2,4),(4,2),(3,3)}, 2-4 systems), dim A/B = dim of the elimination quotient = |L| in all, L nonempty in 421 (scratchpad/cert/nl.py). (iii) Owner's NCP reduction R1=(C x 0)+<(w,1)>, R2=(C+<w>) x 0: all decompositions of e are (w+c,1)+(w+c,0), c in C; checked on 222 instances; NP-hardness of nearest codeword per Berlekamp-McEliece-van Tilborg 1978 (owner checked the original, not re-read by Claude). (iv) Own consequences: (a) if the shared auxiliaries are functionally determined by the visible variables and every system contains the same defining constraints (circuit/gate encodings), then Y_i(x) subset {Z(x)}, so L is empty and separate elimination is exact; the obstruction needs genuinely free shared auxiliaries. (b) Under P=NP: x in L is a difference of NP sets (DP) hence decidable in P, 'L nonempty' is Sigma_2-type hence in P, so the obstruction class is no source of a contradiction. Novelty vs literature unchecked.

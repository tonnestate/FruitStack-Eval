## Statement / proof text (verbatim)

AC-FAMILY-LB (owner derivation 2026-11-26, director check; CLAIMED; novelty vs. literature not confirmed - CHOPRS Cor 61 refutes the OPS Anti-Checker Hypothesis by a different route). b = N^beta, a = b/(10m), constants beta, zeta > 0. Let J_1..J_l be a FIXED (input-independent) family with |J_i| <= N^{1-zeta}. Uniform table with exactly R = D b ones (NO w.p. 1-o(1), as in ADAPT-LB seq 17227). By ADAPT-LB (i) any r = Theta_beta(b/m) ones have an a-circuit, so J_i is an anti-checker only if X_i = |J_i n ones| >= r. Hypergeometric tail: Pr[X_i >= r] <= (e|J_i|R/(N r))^r = (O_beta(m N^{-zeta}))^r = 2^{-Omega_{beta,zeta}(b)}. Union bound: for l <= 2^{c b} (c small) some NO instance has no anti-checker in the family. So a fixed family needs l >= 2^{Omega_{beta,zeta}(N^beta)} members. Any rule using only the family's consistency bits sees on that NO instance exactly what it sees on 0^N (a YES instance), so it accepts; an AND-of-tests formula over such a family has >= l leaves. MECHANISM EXCLUDED (on confirmation): fixed families of sublinear anti-checker candidates, any polynomial (even 2^{c N^beta}) size. NOT excluded: input-dependent anti-checkers; sets of size N^{1-o(1)}. CORRECTION of the scope note in seq 17222 ('does NOT constrain families'): fixed families are constrained by this count.

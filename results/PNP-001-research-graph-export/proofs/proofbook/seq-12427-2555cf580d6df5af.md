## Statement / proof text (verbatim)

The Stage D language gap can be bridged if and only if there exists a P^NP-uniform two-sided family for Gap-MCSP[s,s'] where the YES side has circuit size <= s and the NO side has circuit size >= s', and the reduction from the E^NP language produces both sides without collapsing the hardness. Current candidates: (1) Korten 2021 / Chen-Hirahara-Ren 2024 range avoidance reductions use pseudodeterminism and multiple input lengths; (2) Ren-Williams TR26-118 uses a different regime. Need to check whether any published reduction produces a two-sided family at the Gap-MCSP threshold with N^{eps} blow-up.

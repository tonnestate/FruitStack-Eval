## Statement / proof text (verbatim)

D6 REUSE COLLAPSE UNDER RESTRICTION (repair of the D5 limit): let d_g be the number of input variables gate g depends on. Under a truly random p-restriction, a reused gate stays a non-literal, non-constant reused gate only if >= 2 of its d_g variables stay live, so Pr <= C(d_g,2) p^2 <= p^2 d_g^2/2 (union over pairs) and E[gamma(C|rho)] <= sum_{g reused} min(1, p^2 d_g^2/2). With p = N^{beta+eps/5-1}: reused gates with d_g <= N^{1-beta-eta} contribute <= N^{-2 eta}, so only WIDE reused gates (d_g > N^{1-beta-eta}) can survive. Combined with AF: if P1, P2 hold, Gap-MCSP[N^beta] has no De Morgan circuit of size N^{1+eps} with at most N^{beta-2eta} wide reused gates (Markov over rho). Sanity check (dual-rail parity): the tree has ~N/2^j reused nodes with d_g = 2^j; sum_j (N/2^j) min(1,p^2 4^j) = Theta(pN) = Theta(k) survivors, matching counterexample 1 - those survivors are exactly the wide nodes (d_g >= 1/p). REMAINING OBLIGATION (unrestricted circuits): circuits computing Gap-MCSP[N^beta] with more than N^beta wide reused gates.

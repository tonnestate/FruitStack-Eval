## Statement / proof text (verbatim)

MMW-SWEEP (owner construction 2026-11-26, director check; CLAIMED). VERIFIED BY AUTHOR: a one-pass streaming algorithm with space S and update time U is simulated by a one-tape machine with one-way input whose head pattern is input-independent (read one bit at the left end, then exactly U full forward/backward sweeps over the O(S)-cell configuration, one local cellular update per sweep pair, padded): T = O(N S U). With MMW Thm 1.3 and s(n) = n^2: P = NP implies MCSP[n^2] in sweep-DTIME1[N (log N)^{O(1)}]. This is CHMY Thm 47 (proof via MMW Thm 1.3 + Lemma 9, any time-constructible s) at s = n^2 plus an oblivious normal form. LOGICAL STRENGTH: a sweep machine with time T does r sweeps of W cells per bit, T >= N r W, so it is a one-pass streaming algorithm with space O(W) and update O(rW); conversely the construction above. Hence 'MCSP[n^2] not in sweep-DTIME1[N (log N)^{omega(1)}]' is polynomially equivalent to 'MCSP[n^2] has no deterministic streaming algorithm with polylog space and polylog update', which is MMW's own headline target (mmw19 paper.txt l.100-104: an N poly(log N)-time lower bound on poly(log N)-space streaming for MCSP[n^c] is as hard as P != NP) and the QE*/L* target of seq 10055 (G0004/G0012). It is a normal form of the existing target, not a gap shrink; restricting to oblivious machines yields no easier model here. CORRECTION ACCEPTED (owner): obliviousness fixes crossing times, positions and directions, not the transmitted states; condition (a) of seq 17318 is not automatic (the director's earlier remark was wrong). BARRIERS that apply unchanged: (i) MMW Thm 1.2 / CHMY Lemma 16 give unconditionally a streaming algorithm with O~(s) space, O~(s^2) update and Sigma3-oracle queries of length O~(s) = polylog N, and it has the same sweep form, so any proof must fail for sweep machines with polylog-length Sigma3 queries; (ii) seq 17328 checker ceiling: family-plus-counting arguments give at most N s^{c_F} = N (log N)^{O(1)} with a fixed exponent, while the target needs exponent omega(1). Not a gap closure.

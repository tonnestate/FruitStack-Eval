## Statement / proof text (verbatim)

T52 (theory/T52-functional-qe-degree-reduction-2026-11-27.md): the owner's functional QE theorem over F3, with PI check, correction and composition analysis. CLAIMED.
Thm (owner, checked): 1-in-3 = affine F3 system plus Boolean domain (T41 Thm T); Gauss gives y_i = a_i(x) + l_i(z), z in F3^d. CORRECTION (PI): Q must cover ALL internal variables, including the free z_j, otherwise z_j=2 adds solutions and uniqueness fails. Q = prod_{i<=m}(y_i-2), F(x) = sum_z Q. (a) For a functional encoding, F(x) = +-1 if an extension exists, else 0. (b) deg F <= m-2d, because sum_t t^k = -1 for even k>0 and 0 otherwise, so every summed z_j uses at least 2 degrees. This is a Chevalley-Warning-type computation (row 1895); distinct from rows 2199/2200 (Ax-Katz on the slice never applies); novelty against the literature unchecked.
Prop 2.1: the excess e = m-2d is additive under substitution composition (d = d1+d2 with no new equations; m = m1+m2).
Prop 3.1: e >= wdeg_3(C) (weak/nonzero F3 degree); if C is satisfiable it has a satisfying input of weight <= e (minimal monomial plus Moebius). Example (proved): AND_n has e >= n. So the excess is a function invariant bounded below by the weak degree, not a new structure measure; no transformation removes it.
Efficiency: if e <= D, the coefficients come from F(1_T) with |T| <= D (unique propagation) in n^{O(D)} poly, with no sum over z. In general e can be Theta(n).
Relation to T51 T-D: the excess is additive and poly-bounded, but composition is F1(x)*F2(u(x)) (substitution, not a product of children); the degree comes from summation, not multiplication, so it gives no VSBR balanced product decomposition (E2 stays open). Contradiction test: all statements are unconditional; P=NP is not used; they are representation statements; no contradiction. First failing implication: 'low excess for general poly-size circuits' is false (AND_n).

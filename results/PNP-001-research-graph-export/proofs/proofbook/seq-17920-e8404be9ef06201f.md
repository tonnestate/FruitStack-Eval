It does not cover polynomial degree, lattice quotients or affine representation size; Gemini's wider reading is not recorded (cf. 17915). (1) Statement checked. S_G = {x : exists y R_G(x,y)}, R_G polynomial-time; the question is acn(S_G) <= k for k <= poly. It is exists A_1..A_k [forall x,y: R_G(x,y) -> x in union A_i] and [forall x: x in union A_i -> exists z R_G(x,z)], which is Sigma_3^P. P = NP collapses PH to P, so the question is decidable in polynomial time, and self-reduction constructs the A_i. Proof correct. (2) The property is equivalent to P = NP. Take k = 0: acn(S_G) <= 0 iff S_G is empty, i.e. G (with the projected variables) has no solution, which is coNP-complete. So it joins Proposition E (Fable review: selection S, lattice generators, affine hull, decision) as another equivalent form of the hypothesis. Refuting it restates P != NP. (3) The proof uses only 'NP predicate, hence decidable' and therefore relativizes. Relative to a PSPACE-complete oracle A (17590, AW world), P^A = NP^A and every row of the owner table holds simultaneously. Rows: decision, monomial extraction (a nonzero monomial of U_G = a colouring), lattice generators, exact cover check, optimal compression for poly-bounded k. Their conjunction with any unconditional identity (U_H = U_G perm, Theorem H, rigidity, K, USCCL) is consistent. A contradiction needs a step that fails relative to A. (4) Link to rigidity (17915 R2/R3): for the full colouring set, acn(Col3(G)) = |Col3(G)| / 3^{c}. So 'acn <= k' with poly k is a bounded-count question, decidable under P = NP by enumerating k*3^c + 1 solutions. For projections P = pi_T(Col3(G)), acn(P) >= |P| / 3^{c(G[T])}. Exact covers of polynomial size exist only for solution sets of polynomial size up to component shifts. The theorem is non-vacuous only for projections with few solutions modulo shifts. (5) Admissibility test for the next step (Fable correction 5): a candidate consequence K needs (i) a derivation from P = NP containing a non-relativizing step, and (ii) an unconditional proof of not-K. No row of the current table satisfies (i). First unproved statement unchanged. No obligation closed.

## Statement / proof text (verbatim)

SEP-ELIM-LB (director, 2026-11-26; CLAIMED; generalises D2/T07). (a) Owner's recursive separator elimination: for a De Morgan circuit C (S gates, gamma reused gates) and a rooted decomposition of the reuse-variable dependency graph with separator sets Z_v such that every principal-formula consistency condition [z_i <-> P_i(x,z)] is placed at a node whose ancestors (inclusive) carry all z it mentions, H_v = OR_sigma (R_v^sigma AND AND_children H_u^sigma) computes C and L(C) <= sum_v w_v 2^{sum_{u<=v}|Z_u|} <= (S+gamma) 2^{W_path}. Correct; standard tree-decomposition-to-formula construction; one node holding all gamma reused gates gives T07 (seq 16758). (b) UNCONDITIONAL (from (a) + CJW20-GAP seq 17198): every De Morgan circuit of size S for Gap-MCSP[N^beta/(10 log N), N^beta] has W_path >= (2+beta-xi) log2 N - log2(S+gamma) - O(1) for EVERY such decomposition; for S = N^{1+K beta}: W_path >= (1-(K-1)beta-xi) log2 N - O(1). This is the separator form of COV1 class K1 (seq 16799), with r replaced by W_path. (c) LOGICAL STRENGTH of the owner's hypothesis H-sep ('under NP subset P/poly some QO1/MMW/OPS circuit of size N^{1+K beta} has W_path <= (1-delta) log2 N'): by (b) it is false for every circuit that exists unconditionally, and under QO1 it implies NP not subset P/poly directly; it is a reformulation of CONV-D with d(beta) = delta, not a reduction. Any separator analysis of the MMW/OPS architecture that does not use the internals of the hypothesis-supplied oracle circuits is therefore excluded. (d) Book search (reviewer item 1): no treewidth/separator analysis of MMW or OPS in the book; separator rows 60, 61, 9481, 3600-3659 concern other questions. Reviewer item 2 is answered by (b) quantitatively (about log N) and by SEP-MERGE-LB (witness-length scale) for block-faithful architectures.

## Statement / proof text (verbatim)

The intrinsic prefix-distinguishing complexity D_t for Search-MCSP[m^c] grows as 2^{Omega(s)} for some cut t, but any one-pass algorithm maintaining exact equivalence classes requires update time that is exponential in s, because the equivalence relation depends on global circuit minimisation. The MMW oracle algorithm avoids this by using an oracle that solves the minimisation in one step (charged as O~(s^2) time). Without the oracle, a deterministic update must either do expensive minimisation or maintain a super-polynomial number of states.

## Statement / proof text (verbatim)

Boundary of the nullity-parameter route to 1-in-3 SAT. For a positive 1-in-3 formula, nullity_3(A) = n - rank_3(A) >= n - m, since rank <= m. The affine enumeration over GF(3) therefore costs 3^(nullity) * O(nm) after elimination. It is polynomial only when nullity = O(log n), which forces m >= n - O(log n). Hypothesis: on random or threshold-density positive 1-in-3 formulas with m/n < 1 - eps, nullity grows linearly in n, so the 9-point (3^k-point) check is exponential exactly where the non-linear two-value condition is hard to avoid (D-018).

T48 addendum sec.9: certificate transfer (owner's derivation, PI check plus 9.3-9.5). CLAIMED; cross-family review pending.
Thm9.1 (owner, checked): E_v = z_v - f_v(X); AND: g_v + z_a E_b + f_b E_a; XOR: g_v + E_a + E_b; NOT: g_v + E_a; inputs E=0. Backward weights give z_o - f = sum R_v g_v with joint size O(s). This holds over every field and for every constant-arity gate polynomial (divided differences).
Cor9.2 (owner, checked): f = sum Q_i(x_i^2-x_i) => 1 = (1-z_o) + sum R_v g_v + sum Q_i(x_i^2-x_i), extra cost O(s).
Prop9.3 (reverse direction, PI): from a refutation A(1-z_o) + sum B_v g_v + sum C_i(x_i^2-x_i) + sum D_v(z_v^2-z_v), substitute z_v := f_v and multiply by f, using f(1-f) = -(f^2-f). Linear overhead holds only if Thm8.1 is run ONCE with initial weights D_v at all gates jointly (the propagation is linear); separate runs would cost O(s^2). So the certificate sizes for f in I and for the gate system agree up to additive O(s).
Prop9.4 (PI): reductions built from functional constant-size gadgets over a finite domain S (domain axioms prod(y-sigma)) preserve the minimal IPS size up to additive O(#gadgets), in both directions. Reason: the local ideal with domain axioms is radical (zero-dimensional, square-free), so polynomials that vanish locally have constant-size coefficients (grid Nullstellensatz, Alon CN Lemma 2.1, from memory). Covered: Lemma-B 1-in-3 images (domain {0,1}) and functional circuit->3COL gadgets over GF(3) (y^3-y). Not covered: the U_G<->U_H p-equivalence (17913), which concerns generating functions.
Prop9.5: (a) under P=NP, PIT is in P (BPP in Sigma2 cap Pi2) and finding certificates of size <= k takes poly(k,s) when they exist (NP predicate plus self-reduction); (b) poly-size IPS certificates for all unsatisfiable circuits => coNP in MA (Merlin sends the certificate, Arthur runs PIT); (c) P=NP does not, by any known argument, imply that such certificates exist (Cook-Reckhow is about some system, not IPS). All of these consequences of P=NP are relativizing NP predicates (AW world 17590), so there is no K candidate; the first unproved implication is unchanged from 17920/17929.

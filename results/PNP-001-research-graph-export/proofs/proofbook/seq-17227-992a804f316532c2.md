## Statement / proof text (verbatim)

ADAPT-LB (owner derivation 2026-11-26, director check; CLAIMED; strengthens NONADAPT-LB seq 17222). b = N^beta, a = b/(10m), beta fixed. (i) Small YES circuits: split the m index bits into q = O(1/beta) groups of beta m/2 bits, decode every group completely (O_beta(N^{beta/2}) = o(a) gates); each one-position is then an AND of q decoded lines, so ANY set of r = a/(2q) = Theta_beta(b/m) ones has an a-circuit (previously r = Theta(a/m)). (ii) A uniform table with exactly R = C_beta b ones is a NO instance with prob 1-o(1): C(N,R) = 2^{Omega(R log(N/R))} against 2^{O(b log(b+m))} circuits. (iii) A one-sided algorithm (YES always accepted) cannot reject while it has seen <= r ones, since the table with exactly the observed ones is a YES instance consistent with every answer. Each new adaptive query hits a one with prob <= R/(N-t), so E X_t <= tR/(N-t) and Pr[reject] <= Pr[X_t > r] <= O_beta(t m/N); averaging over the NO-heavy distribution gives a fixed NO instance, so t = Omega_beta(N/log N) for adaptive and non-adaptive one-sided algorithms. Director scope note: CJW20 and CONV-D allow TWO-SIDED error; for two-sided algorithms the same distributions (YES: uniform r-subset, NO: uniform R-subset) give only t = Omega(N/R) = Omega_beta(N^{1-beta}) (views are all-zero with prob >= 1 - tR/N under both). Query bounds of order N/polylog do not constrain CONV-D, whose formulas have size >= N anyway; they exclude only bit-selection (sampling) as the conversion mechanism.

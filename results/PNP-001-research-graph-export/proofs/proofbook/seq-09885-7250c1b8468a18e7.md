## Statement / proof text (verbatim)

Thm 4.1, Thm 5.4, Cor 6.2 of the owner's paper (as stated there). PAPER SETTING: G=(V,E) finite graph, F field, K subspace of F^I, blocks I_v; pi_X: K -> prod_{v in X} F^{I_v}. (R) rank pi_X >= d|X| for all X subset V; (L) z,z' in K with z|v != 0 != z'|v => supp z cap supp z' != empty; (E) uv in E, z|u != 0, z'|v != 0 => supports intersect. THM 4.1: R+L+E => for every finite spanning family B of K there is an injection V x [d] -> J mapping every edge of G[K_d] to an edge of the support-overlap graph H_B (adjacent iff supports intersect); spanning if dim K = d|V| and B a basis. Proof: S_v={j: b_j|v != 0} are cliques (L), S_u cup S_v cliques (E), Hall from (R). THM 5.4: colouring kernel K_G(F) = {z in F^{(VxC) u (ExC)}: sum_c z_{v,c}=0, z_{u,c}+z_{v,c}+z_{e,c}=0}, blocks {v}xC, d=2: G[K_2] subset H_B for every field and every spanning family. COR 6.2: min_B tw(H_B) = 2tw(G)+1. PAPER'S OWN LIMITS: Remark 6.4 - a parameter statement, NOT a running-time lower bound; Prop 6.5 - K_n has min overlap tw 2n-1 but constant-size Resolution refutations, so width alone gives no lower bound; Prop 5.5 - for q>=4 colours (L) fails and the analogue is false. Lean (F3 only) covers Cor 6.3 and the lower bound, NOT Thm 4.1 / Thm 5.4 as subgraph statements.

## Statement / proof text (verbatim)

PARTIAL-MCSP-LB (owner derivation 2026-11-26, director check step by step; CLAIMED, corollary of the CJW20 Thm 5.5 mechanism). For EVERY set J of t = Theta(N^u) distinct positions, u = 1+beta-gamma, a = N^beta/(10 log N): H_{J,a}(z) = [some a-circuit C has C(j_r) = z_r for all r] has no probabilistic De Morgan formulas of size N^{2u+beta-xi} = t^{2+beta/u-o(1)}. Proof check: (A) view F as F'(x) = F(x_{A(j_1)},...,x_{A(j_t)}) over N variables, A a random invertible affine map of F_2^m (AGL(m,2) is 2-transitive, so images of distinct pairs are uniform distinct pairs; A costs O(m^2) gates). (B) CJW20 Thm 3.2 shrinkage E L(F'|rho) <= p^2 L + p sqrt(L) N^{C/loglog N} holds for any formula (no AF hypothesis P2); with p = N^{beta+eta-u}, 0 < eta < min(u-beta, xi/3): p^2 L = N^{3beta+2eta-xi}, p sqrt L = N^{3beta/2+eta-xi/2} (smaller). (C) Conditional on |rho^{-1}(*)| >= pN/2 (prob > 2/3), Chebyshev over A gives >= pt/4 = Omega(N^{beta+eta}) free positions inside A(J); fix A, rho by Markov as in CJW20. (D) NO: random completion; each a-circuit is consistent with prob 2^{-k}, union over 2^{O(N^beta)} circuits: o(1). (E) YES: x = G(seed) o rho with the CKLM PRG fooling size s' = N^{3beta+2eta-xi+o(1)}; z = x o A on J has the circuit j -> A(j) -> rho or g_seed, size O(m^2)+polylog+s'^{1/3+o(1)} = N^{beta+(2eta-xi)/3+o(1)} < a since 2eta < xi. Contradiction as in CJW20. Holds for all J (not only almost all, as from ROBUST-GAMMA + sampling). READING: for beta fixed and gamma -> 1 the exponent 2+beta/u -> 3, so the target L(H_{J,a}) = O(t^{3-delta}) is UNCONDITIONALLY FALSE there. This is the lower-bound half of the decoupled route (what a contradiction needs), NOT a mechanism exclusion: deriving that false bound from NP subset P/poly would prove NP not in P/poly. The open obligation is unchanged and by DECOUPLE-ACCOUNTING (seq 17208) not easier than in the old regime. Links: seq 17204 (replaces retracted 17185), Theorem R seq 5259, QO2 seq 16796 (general circuits, separate).

## Statement / proof text (verbatim)

DYNAMIC-CUT + DYNAMIC-CUT-AMORTIZED + FAMILY-CHECKER-CEILING (owner derivations 2026-11-26, director check; CLAIMED). VERIFIED BY AUTHOR: (1) DYNAMIC-CUT: in an input-free phase, H(R^1 | R^0, C_c) = 0 (each side evolves from its own content and the crossing states), so H(R^1|R^0), H(L^1|L^0) <= H(C_c) = O(E m_c + 1) for O(1) states, and E T >= Omega(F) - O(|cuts|). Transposition r x r on one tape: F = (r-1) r (r^2-1)/3, T = Omega(b^2). (2) Two-phase check (tape holds y row-major and nothing else, then z is read column-major, accept iff z = y^T): combining the left half of one accepting run with the right half of another with the same crossing protocol (incl. input positions) gives an accepting run on a mixed input, so the left-stored bits read on the right are a function of C; from b = H(Y) <= H(C) + E[b - |S(C)|] follows E|S| <= H(C), both directions E D_c <= 2 H(C_c), H(C_c) = O((E m_c + 1) log b); for every cut in the middle half every column has >= r/4 - O(1) bits on each side, so E m_c = Omega(r) and E T = Omega(b^{3/2}). Section 6 (false acceptances, + 2 lambda) not checked in detail. (3) DYNAMIC-CUT-AMORTIZED: with the same protocol, every left alternative combines with every right alternative to an admissible window alternative, D_j >= a^L a^R, E log a^L >= H(Y_{J^L} | L^0, L^1, C) (injectivity of pi_j; log of the class value count >= conditional entropy), so sum_j (E^L_j + E^R_j) <= Lambda - b. Type: classical crossing-sequence / information-flow arguments (Hennie-type); novelty not checked. STRENGTH (director): the deficits condition on whole half-tape contents; a machine that writes every read input bit onto the tape (O(1) per bit) has L^1, R^1 containing the read bits, so E^L = E^R = 0 for every window and cut. The amortized balance is therefore satisfied at linear cost and yields no time bound by itself; only the flux bound (1) with a forced storage layout gives time, and in the one-way-input model the layout is chosen by the machine (two orders prepared once, 17325). FAMILY-CHECKER-CEILING (director, generalises the exclusion of seq 17325): let F = {x(y)} with x(y)_i = y_{a(i)} for an explicit address map a computable by a size-<=s circuit (every construction used so far: Lupanov addressing seq 17314, permuted repetitions seq 17325, grids). The machine M_F reads y, writes it and the address circuit on the tape, and for each i evaluates a(i) and walks to y_{a(i)}: DTIME1[N (b + poly(s))] = DTIME1[N poly(s)], deterministic, no oracle; it accepts exactly F, |F| = 2^b <= 2^Lambda, and rejects every hybrid. Hence every argument whose premises are 'M accepts F and accepts few inputs / few hybrids' plus machine structure (cut-and-paste, crossing protocols, static or dynamic information flow, any choice of cuts and permutations) proves at most t <= time(M_F) = N s^{c_F}. CHMY Thm 1 needs N^{1.01} for every mu > 0 (its footnote), and N s^{c_F} < N^{1.01} for mu < 0.01/c_F. MECHANISM EXCLUDED (on confirmation): explicit hard-input families with polynomially checkable decoders plus counting plus any cut-and-paste/information-flow analysis, as a route to the magnification hypothesis. A continuation must use acceptance of YES instances outside every such family, i.e. a family whose membership is itself not decidable in DTIME1[N^{1.01}], which is a lower bound of the same kind. PRECISION to seq 17318 (owner): the bound log(w'K') >= max(h, log K_acc) concerns the width budget w' = 2^h+1 and the count of that construction, not the width of every realised ROBP; the entropy bound K_acc >= 2^{H(alpha(X))} is unrestricted. Not a gap closure.

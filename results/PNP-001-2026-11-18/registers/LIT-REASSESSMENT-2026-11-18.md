LIT-SUPPORT: representation dependence proved - Tseitin needs linear PC degree over char != 2, trivial over GF(2); {+-1} basis gives poly-size proofs.
LIT-LIMIT: best explicit circuit lower bound ~3.1n; three barriers (relativization, natural proofs, algebrization); small-instance experiments can refute, never establish lower bounds.
LIT-GAUSS-A: XOR systems in P (Schaefer); PC over GF(2) simulates elimination, over GF(3) not; random k-CNF need linear degree in every characteristic.
LIT-GAUSS-B: single quadratic form over GF(2): sum of (-1)^f in {0, +-2^(n-h)} (Dickson, Arf), poly time; system of m quadratics: count = 2^-m sum_lambda sum_x (-1)^(lambda.f(x)), 2^m poly(n); degree >= 3 #P-hard (Ehrenfeucht-Karpinski); 3-SAT needs Theta(n) quadratic equations. Identity checked by the reviewers on 300 random systems (n<=7, m<=4).
LIT-GAUSS-C: Gaussian processes: experiment design only (Bayesian optimisation for expensive runs); trees/symbolic regression better on discrete exact data.
LIT-GAUSS-D: char 2 removes signs (Pfaffian counts perfect matchings mod 2 in any graph; Bjoerklund); Valiant #7Pl-Rtw-Mon-3CNF mod 7 in P vs mod 2 parity-P-complete (from knowledge); Wick/Gaussian integrals need division by 2; collapse theorems (Cai-Lu, Cai-Fu, Chen): larger bases add nothing.
LIT-WILLIAMS: faster SAT algorithms for a class C => NEXP not in C (done for ACC); strongest route from algorithm search to lower bounds; avoids all three barriers.
LIT-PATTERNS: six recovery patterns - refutation becomes tool; change field/characteristic/ring; drop or use symmetry; average->worst case; weaker variant; better analysis of the same object. Negative filter: a hardness argument must fail on XOR-SAT and 2-SAT.

LIT-H1: pencil rank spectrum - for quadratic encodings of hard SAT families no poly-small subset of lambda determines the count (refuted by a family where few lambda suffice = new algorithm).
LIT-H2: min PC degree over GF(2), GF(3), GF(5), {+-1} grows linearly for random 3-CNF near threshold already at small n (mostly known: calibration).
LIT-H3: exact circuit sizes for n<=7 suggest gate-elimination bound above 3.1n.
LIT-H4: explicit GF(2) matrix families whose exact rigidity for small n escapes the Hadamard failure pattern (MaxSAT).
LIT-H5: further realizable matchgate signatures over small Z_p beyond symmetric ones.

## LIT-ATLAS round 2 (owner, 2026-11-18): theorem / proof core / validity limit per entry; original texts for some, published statements or abstracts for others (owner-declared). Mostly KNOWN mathematics.
LIT-ATLAS2-Q: owner's four questions per mechanism - which theorem makes the algorithm possible; how does its proof work; at which hypothesis does validity end; which other family uses a comparable mechanism. The HYPOTHESES THEMSELVES are the comparison object.
LIT-ATLAS2-MECH: nine mechanism classes - implicit generation (cutting stock, crew pairing, VRP); implicit restriction (Benders, branch-and-cut, separation); exchange/augmentation (matroids, assignment, set packing); state equivalence (DP, suffix tree/array); algebraic aggregation (subset sum, exact cover, subset convolution); block stability (n-fold IP, Graver bases, scheduling); relaxation+rounding (bin packing, SDP, Lagrange); structural characterisation (matroids, submodularity, graph decomposition); proof by exclusion (cutting planes, ILP, combinatorial lower bounds).
LIT-ATLAS2-I: column generation / Benders / separation share a certificate that no unseen variable or inequality improves the result (reduced cost c_p - lambda^T a_p; Groetschel-Lovasz-Schrijver optimisation <=> separation under their oracle/representation hypotheses). Limit: if the pricing/separation oracle is NP-hard, hardness is only moved.
LIT-ATLAS2-II: local rules in three regimes - local step guarantees global optimum (matroid greedy/Rado-Edmonds, Johnson 1954 two-machine flow shop by exchange); guarantees an approximation (k-set packing local search, Hurkens-Schrijver; metric nearest/cheapest insertion 2-approx, Rosenkrantz-Stearns-Lewis 1977); no useful global bound (general local search, TSP 2-opt local optima). Open object: the exact combinatorial property separating the regimes. Edmonds: max |I in I1 cap I2| = min_A r1(A)+r2(E\A); three partition matroids encode 3D matching (NP-complete).
LIT-ATLAS2-III: three ways to avoid redundant work - shared text structure (suffix tree, Ukkonen 1995; suffix arrays Manber-Myers 1993, Kaerkkaeinen-Sanders 2003), shared future states (DP, Held-Karp), algebraic aggregation (subset convolution (f*g)(S)=sum_{T subset S} f(T)g(S\T), naive O(3^n), ranked zeta + Moebius O(n^2 2^n), Bjoerklund-Husfeldt-Kaski-Koivisto 2007). A common theory requires a precise equivalence/representation relation that provably preserves the result.
LIT-ATLAS2-IV: Graver bases - elementary integer kernel directions of A; n-fold IP polynomial for fixed blocks (De Loera-Hemmecke-Onn-Weismantel), the number of non-zero blocks of a Graver element bounded independently of the number of repetitions. Question: which other families have improvement directions bounded independently of the number of repeated components?
LIT-ATLAS2-V: branch-and-cut is a proof system - Chvatal-Gomory rounding (sum lambda_i a_i)^T x <= floor(sum lambda_i b_i); derivation of 0 <= -1 refutes; Cook-Coullard-Turan 1987 cutting-plane proof length, relations to resolution / extended resolution. Long proofs in one calculus are not long proofs in all.
LIT-ATLAS2-VI: representation/proof-system lower bounds are not algorithm lower bounds - Rothvoss 2014 (matching polytope), Schoenebeck (Lasserre fails on random 3-XOR, XOR-SAT in P by Gaussian elimination). Control question for every negative result: property of the PROBLEM or limit of the METHOD?
LIT-ATLAS2-RIVER: river-crossing (Ito-Langerman-Yoshida): general variants polynomial without a trip bound, NP-hard with a bound on the number of trips; "Ferry Cover with Connectivity Constraints" (2026, UNVERIFIED): Boat-1 graphs characterised via block-cut tree. Complexity set by transition shape + resource bound + graph decomposition.
LIT-ATLAS2-MISC: GLS ellipsoid/separation; branch-price-and-cut label dominance (ESPPRC pricing NP-hard); bin packing APTAS (Fernandez de la Vega-Lueker, Karmarkar-Karp); Lenstra 1983 fixed-dimension ILP; Benders 1962; Held-Karp 1-trees; Chvatal 1979 greedy set cover H_n, Feige ln n hardness; Bjoerklund 2010 exact cover via inclusion-exclusion/determinants; Dantzig-Fulkerson-Johnson 1954; Goemans-Williamson 0.87856; submodular minimisation strongly polynomial (Schrijver; Iwata-Fleischer-Fujishige); Bringmann 2017 O~(t) subset sum; Kuhn 1955 Hungarian method (3D matching NP-complete).

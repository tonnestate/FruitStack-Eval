proof texts. Generated by `pnp_graph.syntheses export` from the PNP-001 research graph (DuckDB).

Coverage of this interim snapshot (2026-11-26):
- dependency extraction (two-pass, Haiku): 2,419 of 2,425 proof-state records (6 rejected by the loader checks);
  proof-book records (5,147 math-bearing) not yet extracted.
- synthesis classification: 80 of 2,425 proof-state records (pilot batches 000 and 030), 0 proof-book records.
  The classification is a pilot and has not been audited. 0 rows means "not yet classified", not "no synthesis".

Status meaning: proof_status CLAIMED = no validated inference rule exists yet in the graph (no row is "proved");
validation_status SURVIVED_INDEPENDENT_REVIEW = an agent review from another session and model family that received the full
step text found no error - it is not a proof.
